# frameact store — Implementation Plan (plan 3 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `frameact/store` — model B of spec §3.5, a *signal-way tree store*: a tree of plain objects whose properties become slim core signals lazily on their first tracked read, path writes that mutate in place and notify one leaf, `reconcile`/`produce`/`merge`, and **cause-tagged parking**: store-driven frame effects wait for the heavy animations of their scope while every other cause runs at once and reads the current store — preceded by one DOM-hardening task (DOM clobbering outside event delegation, carried from plan 2's appsec review) and the plan-2 zombie-rows core fix.

**Architecture:** Every raw object read through the store has a `StoreNode` in a `WeakMap`, which is both its `Proxy` handler and its table of leaf signals (plus a shape signal for keys/length); nothing is written on user objects. `setState(...path, value)` walks the raw tree, replaces the value at the end of the path (`merge()` merges, `undefined` deletes) and calls `writeStoreNode`, a core write that runs a **store walk**: the nodes it dirties are tagged `F_STORE`. Plain walks (local signals, `mapArray` item writes, plain-caused memo results) clear the tag on their way down and descend through tagged nodes, so a plain change always reaches the effects below. When a frame effect's run executes with `F_STORE` set and a scope in its chain animates (sampled once per drain), it is **parked** — left dirty with no run booked — until a plain walk unparks it, a plain child run unparks it (ancestor rule) or the scope's animation ends (release re-books the parked effects in order, into the next frame). `live()` readers are relayed around store walks; `use:value`/`use:checked` bindings are live and pinned; tickEnd logic is never parked; `ungated()` writes run plain walks. `mapArray` reads `$TRACK` on store arrays (one shape link, rows wake only on their own leaves). Actions are typed plain functions with a FIFO cascade. The approach was validated by a prototype (`.superpowers/store-b-prototype.md`, branch `scratch/store-b-proto`, 807 tests + fuzz) and is ported here to production quality: no `STORE PROTO` instrumentation, no versioned-leaves variant, no `mode` switch, the gate split into core primitives (`effects.ts`) and the scope-level policy (`src/store/gate.ts`), parking lists in a `WeakMap` instead of scope fields, an iterative `updatePath`, tickEnd effects not gated.

**Tech Stack:** TypeScript 7 (strict), pnpm, Vite 8 + vitest 5 + jsdom 30, oxlint. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-11-frameact-design.md` — §3.5 (`store`, authoritative, model B with the user's decisions: replace-on-write + explicit `merge()`, `undefined` deletes a key, tickEnd logic not gated, `snapshot()` O(n)), §3.2 (run rule, `mapArray`), §3.3 (clobbering paragraph, Task 1), §4 (`./store` export, store files), §5 (store tests). 2. **Zombie rows (Task 2) is a core fix, before the store, in every keyed mode.** The rows' owner scope gets an **optional** `_mapMemo` set only by `map.ts`. Initialising it in `initScope` for every node — the obvious "keep one hidden class" move — measured **+4…7 %** on plain-signal propagation (the extra field changes every node's in-object layout); the optional field on three scope objects costs nothing outside lists (`bench/store/core`'s four plain scenarios: within noise) but **about +6–7 % per empty row run** on a list of 1000 `mapArray` rows each with an effect (measured 76.3 → 81.7 µs for 1000 row runs) (the extra property load and the polymorphic map-scope shape in `runEffect`'s owner walk; the `rows` scenario of `bench/store/core.bench.ts` reports it). In a real row the DOM work dominates by an order of magnitude; accepted. `runEffect` pulls a dirty `_mapMemo` like a dirty memo ancestor, and the pre-flight's B2 is in: an ancestor that is booked but not yet run when a plain child bails onto it loses its `F_STORE` tag, so the child's plain change never waits for an animation.

3. **The gate is split:** the core (`effects.ts`) decides whether a run is a *candidate* (`F_STORE` set, a store-gated schedule, not `F_LIVE`/`F_LIVE_PIN`) and owns the parking primitives; `src/store/gate.ts` (spec §4) decides *where* it waits and releases on the scope's `isAnimating.once`. Parked lists live in a `WeakMap<scope, EffectNode[]>` — no `_storeParked`/`_sampleId` fields on scope objects (no-underscore-dangle in `src/scheduler`, and no prototype instrumentation); an effect unparked and parked again is listed twice and a disposed one stays listed until the release (bounded by one animation; m10 of the pre-flight, accepted). **Sampling is by animation-begin epoch** (pre-flight I1): a drain takes an epoch when it opens (saved and restored around nested drains), and a scope counts for that drain only if it animates now and began before the epoch — a scope begun mid-drain does not split the frame even while an unrelated scope animates, and a scope that ended mid-drain is skipped with the chain checked further up (an inner scope that ended does not hide an outer one that still animates). No per-drain cache allocation.

4. **tickEnd logic is not gated (user decision).** Store-gated schedules are the three frame queues and `gateOnHeavyAnimation` wrappers (`markStoreGated`); the Effect node carries `_storeGated` from its constructor (one hidden class for all effects). So `flushTickEnd` opens no gate sample and `schedulers.ts` is untouched (the prototype's `gateSampleHooks` cycle hack is gone). The prototype test "a global animation gates tickEnd effects too" becomes "tickEnd effects are not gated, frame effects are".

5. **`setState` semantics (user decisions):** the value at the end of a path **replaces**; `merge(partial)` is the only merge (shallow; `undefined` inside deletes); `undefined` at the end of a path **deletes** the key — at an **array index** the path form throws (`use produce(a => a.splice(i, 1))`: a hole is never wanted), `produce` keeps JS semantics (`draft[i] = undefined` stores the value, `delete draft[i]` leaves a hole), `reconcile` writes an explicit `undefined` element as a value; the root accepts only `merge`/`produce`/`reconcile` (an updater that returns the root object) — a plain value or an updater returning another object at the root is a `TypeError`, because the root proxy is bound to its raw object. `merge()` returns a function typed as a non-callable marker `Merger<P>` so that (a) inline updaters `(n) => n + 1` keep their contextual typing and (b) the partial is checked against the path (`Updater<V>` lists `Merger<Partial<V>>`). A user updater is typed `(prev: Store<V>) => V` (m5: `l => { l.push(x); return l }` — a mutation nobody would be notified of — does not type-check); `produce`/`reconcile` take `prev: unknown` (only their return type is checked against the path, so an `as const` chunk fits). Paths are typed up to **7 keys** (I5). `updatePath` is iterative over plain keys (the prototype's `path.shift`/spread allocation, its limitation 12, is gone); fan-out (key arrays, filter functions) recurses.

6. **`Store<T>` is the deep read-only view** (spec: `state: DeepReadonly<GlobalState>`), with a typed `$TRACK` key on arrays (`StoreArray<U>`). `createStore<T>(initial: T): [Store<T>, SetStoreFunction<T>]`; `unwrap`/`snapshot` keep the type they are given.

```ts
/**
 * Simulate what a browser does to a `<form>` with a descendant named `name` (`<input name>` or any
 * `<img id>`): jsdom does not implement form named properties, so the test defines what
 * `[LegacyOverrideBuiltIns]` presents — an own, non-writable, non-enumerable data property (an
 * assignment to it throws in strict mode).
 */
export function clobber(form: HTMLFormElement, name: string, value: unknown = document.createElement('img')): void {
  Object.defineProperty(form, name, { value, writable: false, enumerable: false, configurable: true });
}

/** A `<form>` whose listed built-ins are all shadowed by one `<img>` child. */
export function clobberedForm(...names: string[]): HTMLFormElement {
  const form = document.createElement('form');
  const img = document.createElement('img');
  form.appendChild(img);
  for (const name of names) clobber(form, name, img);
  return form;
}
```

```ts
type NodeOp = 'insertBefore' | 'appendChild' | 'replaceChild' | 'removeChild';

/**
 * Spies on the DOM writes the runtime makes on `parent`. The runtime calls the prototype natives
 * (`Node.prototype.insertBefore.call(parent, …)`, see `src/dom/natives.ts`), so an instance spy
 * (`vi.spyOn(parent, 'insertBefore')`) never fires; this wraps the cached natives and records only
 * the calls whose receiver is `parent`. Restored by `vi.restoreAllMocks()`.
 */
export function spyNodeOps<M extends NodeOp>(parent: Node, ...methods: M[]): Record<M, ReturnType<typeof vi.fn>> {
  const natives = getNatives() as unknown as Record<string, (...args: unknown[]) => unknown>;
  const out = {} as Record<M, ReturnType<typeof vi.fn>>;
  for (const method of methods) {
    const recorder = vi.fn();
    const original = natives[method];
    vi.spyOn(natives, method).mockImplementation(function (this: Node, ...args: unknown[]) {
      if (this === parent) recorder(...args);
      return original.apply(this, args);
    });
    out[method] = recorder;
  }
  return out;
}
```

```ts
function median(xs: number[]) {
  return [...xs].sort((a, b) => a - b)[xs.length >> 1];
}

function mount() {

  document.body.appendChild(ul);
  const [list, setList] = createSignal<Row[]>(Array.from({ length: N }, (_, i) => ({ id: i, text: `t${i}` })));

      createComponent(() =>

          get each() { return list(); },
          keyed: (r: Row) => r.id,
          children: (item: () => Row) => {
            const li = document.createElement('li');
            insert(li, () => item().text);
            return li;
          },
        }), {}),
    ),
  );
  flushSync();

    const next = untrack(list).slice();
    next[(k * 37) % N] = { id: (k * 37) % N, text: `e${k}` };
    setList(next);
  },
  'remove-1-add-1': (list, setList) => {
    const next = untrack(list).slice(1);
    next.push({ id: nextId++, text: 'new' });
    setList(next);
  },
  'swap-2': (list, setList, k) => {
    const next = untrack(list).slice();

    setList(next);
  },
  'prepend-5-drop-5': (list, setList) => {
    const prev = untrack(list);
    const fresh = Array.from({ length: 5 }, () => ({ id: nextId++, text: 'p' }));
    setList([...fresh, ...prev.slice(0, N - 5)]);
  },
```

```ts
// DOM clobbering. `HTMLFormElement` has `[LegacyOverrideBuiltIns]`: a descendant form control with
// `name="X"` or ANY descendant with `id="X"` (an `<img id>`) shadows the form's own property `X`, built-ins
// included: `form.parentNode` is then the control, `form.remove` / `form.insertBefore` are not functions,
// `form.nodeName` is an element. Content-derived names and ids inside a form (an emoji id, a file name,
// a poll option) would let a message freeze a list or crash a render. So the runtime reads structure
// and calls the DOM methods it depends on through the prototype natives below, cached on first use
// (`.call(node, …)`: the same monomorphic call V8 makes for `node.method(…)`).
//
// Covered: structure getters, insertion/removal, identity getters, `textContent`, the attribute
// methods. Not covered: `classList`, `style`, `addEventListener`, `value`, `data` and other
// per-feature APIs of a form whose descendant takes exactly that name. That case fails loudly, not
// silently, and stays local to the element: the binding's effect throws on every run (its `_applied`
// never advances, so the error repeats), and because the compiler groups an element's dynamic
// attributes into one effect and `spread` applies its props in one pass, the OTHER props of that
// same effect or spread are not applied either. Other elements, the list and the frame are unaffected.
// Also not covered: `document` has `[LegacyOverrideBuiltIns]` too — a `<form name="addEventListener">`
// or `<img name="addEventListener">` in the document shadows `document.addEventListener`, which
// `delegateEvents` and the controlled-input listeners call (a `name`, not an `id`, is needed: low
// risk; `querySelectorAll` is already taken from the prototype for the same reason). Both are
// follow-ups (plan 3, "Follow-ups").
export interface Natives {
  parentNode: (this: Node) => Node | null;
  firstChild: (this: Node) => ChildNode | null;
  nextSibling: (this: Node) => ChildNode | null;
  nodeType: (this: Node) => number;
  /** Upper-case for HTML elements (`'FORM'`), the same as `tagName` there. */
  nodeName: (this: Node) => string;
  ownerDocument: (this: Node) => Document | null;
  localName: (this: Element) => string;
  namespaceURI: (this: Element) => string | null;
  /** `Node.prototype.textContent` setter. */
  setTextContent: (this: Node, text: string | null) => void;
  insertBefore: <T extends Node>(this: Node, node: T, child: Node | null) => T;
  appendChild: <T extends Node>(this: Node, node: T) => T;
  replaceChild: <T extends Node>(this: Node, node: Node, child: T) => T;
  removeChild: <T extends Node>(this: Node, child: T) => T;
  contains: (this: Node, other: Node | null) => boolean;
  shadowHost: (this: ShadowRoot) => Element;
  setAttribute: (this: Element, name: string, value: string) => void;
  removeAttribute: (this: Element, name: string) => void;
  setAttributeNS: (this: Element, namespace: string | null, name: string, value: string) => void;
  removeAttributeNS: (this: Element, namespace: string | null, localName: string) => void;
  /** `HTMLFormElement.prototype.elements` (`<input name="elements">` shadows `form.elements`). */
  formElements: (this: HTMLFormElement) => HTMLFormControlsCollection;
  /** `querySelectorAll` of a document / shadow root / element (a form named `querySelectorAll` shadows it on `document`). */
  querySelectorAll: {
    document: Document['querySelectorAll'];
    fragment: DocumentFragment['querySelectorAll'];
    element: Element['querySelectorAll'];
  };
}

let natives: Natives | undefined;

function getter<T extends object>(proto: T, name: string): (this: T) => any {
  return Object.getOwnPropertyDescriptor(proto, name)!.get!;
}

export function getNatives(): Natives {
  return (natives ??= {
    parentNode: getter(Node.prototype, 'parentNode'),
    firstChild: getter(Node.prototype, 'firstChild'),
    nextSibling: getter(Node.prototype, 'nextSibling'),
    nodeType: getter(Node.prototype, 'nodeType'),
    nodeName: getter(Node.prototype, 'nodeName'),
    ownerDocument: getter(Node.prototype, 'ownerDocument'),
    localName: getter(Element.prototype, 'localName'),
    namespaceURI: getter(Element.prototype, 'namespaceURI'),
    setTextContent: Object.getOwnPropertyDescriptor(Node.prototype, 'textContent')!.set!,
    insertBefore: Node.prototype.insertBefore,
    appendChild: Node.prototype.appendChild,
    replaceChild: Node.prototype.replaceChild,
    removeChild: Node.prototype.removeChild,
    contains: Node.prototype.contains,
    shadowHost: getter(ShadowRoot.prototype, 'host'),
    setAttribute: Element.prototype.setAttribute,
    removeAttribute: Element.prototype.removeAttribute,
    setAttributeNS: Element.prototype.setAttributeNS,
    removeAttributeNS: Element.prototype.removeAttributeNS,
    formElements: getter(HTMLFormElement.prototype, 'elements'),
    querySelectorAll: {
      document: Document.prototype.querySelectorAll,
      fragment: DocumentFragment.prototype.querySelectorAll,
      element: Element.prototype.querySelectorAll,
    },
  });
}
```

`ownedBy` is the reconciler's hottest call (once per kept row in the prefix scan): it caches the native `parentNode` getter in a module variable instead of calling `getNatives()` each time (the pre-flight measured `swap-2` at +10% without this, within noise with it). `spyNodeOps` spies only mutators, which are still fetched through `getNatives()` at call time; the getter is never spied.

```ts
// Adapted from solidjs/solid packages/web/src/reconcile.ts (MIT, © 2016-2025 Ryan Carniato),
// itself a modified https://github.com/WebReflection/udomdiff (ISC, © 2020 Andrea Giammarchi).
// frameact: structure is read and written through the prototype natives (natives.ts): a row that is
// a <form> with a descendant named `remove`, `parentNode` or `nextSibling` must not break the diff.
import { getNatives } from './natives';

/** Nodes inserted under a marker are tagged with it: a node that migrated to another slot of the same parent is not ours. */
export const SLOT: unique symbol = Symbol('frameact.slot');

/**
 * Tag a node with the slot that inserted it: its marker, or `null` for the last slot (and for root
 * mode). Always written, so a node that migrates between slots never keeps a stale tag.
 */
export function tagSlot(n: any, marker: Node | null | undefined): void {
  n[SLOT] = marker ?? null;
}

/** The native `parentNode` getter, cached on first use: `ownedBy` runs once per kept row in the prefix scan. */
let parentOf: ((this: Node) => Node | null) | undefined;

/** `undefined` tag = never inserted by a slot (static template nodes): owned by whoever holds it. */
export function ownedBy(n: any, parentNode: any, marker: any): boolean {
  if (!n || (parentOf ??= getNatives().parentNode).call(n) !== parentNode) return false;
  const tag = n[SLOT];
  return tag === undefined || tag === (marker ?? null);
}

/** Diff `a` (current nodes) → `b` (next nodes) inside `parentNode`, minimal moves. `a` must be non-empty. */
export function reconcileArrays(parentNode: any, a: any[], b: any[], marker?: Node | null): void {
  const { nextSibling, insertBefore, replaceChild, removeChild } = getNatives();
  const bLength = b.length;
  let aEnd = a.length,
    bEnd = bLength,
    aStart = 0,
    bStart = 0,
    map: Map<any, number> | null = null;
  const tail = a[aEnd - 1];
  const after = ownedBy(tail, parentNode, marker) ? nextSibling.call(tail) : marker || null;

  while (aStart < aEnd || bStart < bEnd) {
    // common prefix
    if (a[aStart] === b[bStart] && ownedBy(a[aStart], parentNode, marker)) {
      aStart++;
      bStart++;
      continue;
    }
    // common suffix
    while (a[aEnd - 1] === b[bEnd - 1] && ownedBy(a[aEnd - 1], parentNode, marker)) {
      aEnd--;
      bEnd--;
    }
    if (aEnd === aStart) {
      // append
      let node: any;
      if (bEnd < bLength) {
        if (bStart) {
          const prev = b[bStart - 1];
          node = ownedBy(prev, parentNode, marker) ? nextSibling.call(prev) : after;
        } else node = b[bEnd - bStart];
      } else node = after;
      while (bStart < bEnd) {
        const n = b[bStart++];
        insertBefore.call(parentNode, n, node);
        tagSlot(n, marker);
      }
    } else if (bEnd === bStart) {
      // remove
      while (aStart < aEnd) {
        const n = a[aStart++];
        if ((!map || !map.has(n)) && ownedBy(n, parentNode, marker)) removeChild.call(parentNode, n);
      }
    } else if (a[aStart] === b[bEnd - 1] && b[bStart] === a[aEnd - 1] && ownedBy(a[aStart], parentNode, marker)) {
      // swap backward: walk inward with a stable front anchor
      const anchor = a[aStart];
      do {
        const n = a[--aEnd];
        insertBefore.call(parentNode, n, anchor);
        tagSlot(n, marker);
        bStart++;
        if (aStart >= aEnd - 1 || bStart >= bEnd) break;
      } while (a[aStart] === b[bEnd - 1] && b[bStart] === a[aEnd - 1]);
    } else {
      // fallback to map
      if (!map) {
        map = new Map();
        let i = bStart;
        while (i < bEnd) map.set(b[i], i++);
      }
      const index = map.get(a[aStart]);
      if (index != null) {
        if (bStart < index && index < bEnd) {
          let i = aStart,
            sequence = 1,
            t: number | undefined;
          while (++i < aEnd && i < bEnd) {
            if ((t = map.get(a[i])) == null || t !== index + sequence) break;
            sequence++;
          }
          if (sequence > index - bStart) {
            const head = a[aStart];
            const node = ownedBy(head, parentNode, marker) ? head : after;
            while (bStart < index) {
              const n = b[bStart++];
              insertBefore.call(parentNode, n, node);
              tagSlot(n, marker);
            }
          } else {
            const oldNode = a[aStart++];
            const newNode = b[bStart++];
            if (ownedBy(oldNode, parentNode, marker)) replaceChild.call(parentNode, newNode, oldNode);
            else insertBefore.call(parentNode, newNode, after);
            tagSlot(newNode, marker);
          }
        } else aStart++;
      } else {
        const n = a[aStart++];
        if (ownedBy(n, parentNode, marker)) removeChild.call(parentNode, n);
      }
    }
  }
}

/**
 * Marks a node array as manually ordered (`For order="manual"`): `insertExpression` then applies it with
 * `reconcileManual` (insert-only) instead of `reconcileArrays`. The value is the set of rows that must
 * be (re)inserted at their array position even though they are already in the DOM (changed `orderKey`).
 * A non-enumerable symbol property, so it is invisible to spreads and `Object.keys`.
 */
export const MANUAL_ORDER: unique symbol = Symbol('frameact.manualOrder');

export function tagManualOrder(array: any[], moved: ReadonlySet<unknown>): void {
  Object.defineProperty(array, MANUAL_ORDER, { value: moved, configurable: true });
}

/** The set of rows to move if `array` is tagged as manually ordered. */
export function manualOrderOf(array: any[]): ReadonlySet<unknown> | undefined {
  return (array as any)[MANUAL_ORDER];
}

/**
 * Insert-only counterpart of `reconcileArrays`. `next` lists the slot's nodes in DOM order, except
 * for new nodes (placed at their list index) and the `moved` ones. Kept, unmoved nodes are never
 * touched (no `remove`, `replaceChild` or `insertBefore`); a contiguous run of nodes to insert goes
 * before one anchor (the next kept node, else the marker); a `moved` node is moved exactly once.
 * `prev` must be non-empty. A kept node that is out of DOM order despite not being listed in `moved`
 * (the memo ran ahead of the applied DOM) is moved too: correctness first.
 */
export function reconcileManual(
  parentNode: any,
  prev: any[],
  next: any[],
  marker: Node | null | undefined,
  moved: ReadonlySet<unknown>,
): void {
  const { insertBefore, removeChild } = getNatives();
  const nextSet = new Set<any>(next);
  const prevIndex = new Map<any, number>();
  for (let i = 0; i < prev.length; i++) {
    const n = prev[i];
    if (!nextSet.has(n)) {
      if (ownedBy(n, parentNode, marker)) removeChild.call(parentNode, n);
    } else if (ownedBy(n, parentNode, marker)) prevIndex.set(n, i);
  }
  // Stable nodes: already in the DOM, not moved, in increasing DOM order. Walking backwards gives
  // every position the anchor to insert before.
  // The `at > last` test is the safety branch for a `next` that is not in DOM order (the memo ran
  // ahead of the applied DOM): theoretical for `For`, and greedy, not an LIS, so it may move more
  // nodes than the minimum. `moved` carries the intended moves.
  const length = next.length;
  const stable: boolean[] = [];
  let last = -1;
  for (let i = 0; i < length; i++) {
    const n = next[i];
    const at = prevIndex.get(n);
    stable[i] = at !== undefined && at > last && !moved.has(n);
    if (stable[i]) last = at!;
  }
  const anchors: (Node | null)[] = [];
  let anchor: Node | null = marker ?? null;
  for (let i = length - 1; i >= 0; i--) {
    anchors[i] = anchor;
    if (stable[i]) anchor = next[i];
  }
  for (let i = 0; i < length; i++) {
    if (stable[i]) continue;
    const n = next[i];
    insertBefore.call(parentNode, n, anchors[i]);
    tagSlot(n, marker);
  }
}
```

```ts
// Adapted from solidjs/solid packages/web/src/client.ts (MIT, © 2016-2025 Ryan Carniato) and
// dom-expressions packages/dom-expressions/src/client.js (MIT, © 2018-2019 Ryan Carniato).
// frameact: `insert` is a two-phase render effect — compute = normalize (pure; creates subtrees on
// detached DOM), apply = insertExpression (the DOM write: synchronous at creation, mutate phase later).
// Structure is read and written through the prototype natives (natives.ts): a parent or a child that
// is a <form> with a descendant named `insertBefore`, `firstChild`, `textContent`… must not break a slot.
import { DEV } from '../env';
import { createRenderEffect } from '../core/frame';
import type { EffectOptions } from '../core/effects';
import { getNatives } from './natives';
import { manualOrderOf, ownedBy, reconcileArrays, reconcileManual, tagManualOrder, tagSlot } from './reconcile';

// No `Document`: lib.dom types its `textContent` as a read-only `null`, and mounting into a Document is meaningless anyway.
export type MountableElement = Element | ShadowRoot | DocumentFragment;

export interface InsertOptions {
  /** Portal: the slot's logical host. Inserted top-level nodes are registered for event retargeting (`portalHostOf`). */
  host?: () => Node | null;
  /** Dev label from the compiler's sourceNames (`div.children`). */
  name?: string;

/** Returned by the outer insert compute when a nested effect owns the slot (its apply then does nothing). */
const INNER_OWNED: unique symbol = Symbol('frameact.innerOwned');
/** Text nodes created by this module. Only these are reused as positional text slots; a Text node handed in by the user is a plain node. */
const ownText = new WeakSet<Text>();

function createOwnText(data: string): Text {
  const node = document.createTextNode(data);
  ownText.add(node);
  return node;
}

/**
 * Resolve nested accessors and arrays. Functions with parameters (row mappers) are values, not
 * accessors. `doNotUnwrap`: keep a top-level function (and any function inside an array — the
 * array then resolves to a wrapper function) so the caller can give it its own effect.
 */
export function flatten(children: any, skipNonRendered: boolean, doNotUnwrap: boolean): any {
  if (typeof children === 'function' && !children.length) {
    if (doNotUnwrap) return children;
    do children = children();
    while (typeof children === 'function' && !children.length);
  }
  if (skipNonRendered && (children == null || children === true || children === false || children === '')) {
    return undefined;
  }
  if (Array.isArray(children)) {
    const results: any[] = [];
    // The copy keeps the manual-order tag (`For order="manual"`); a For nested inside a larger array
    // is flattened into it and loses the tag: it then falls back to the ordinary reconcile.
    const manual = manualOrderOf(children);
    if (manual) tagManualOrder(results, manual);
    if (flattenArray(children, results, skipNonRendered, doNotUnwrap)) {
      return () => {
        const nested: any[] = [];
        flattenArray(results, nested, skipNonRendered, false);
        return nested;
      };
    }
    return results;
  }
  return children;
}

let warnedNestedManual = false;

function flattenArray(children: any[], results: any[], skipNonRendered: boolean, doNotUnwrap: boolean): boolean {
  let needsUnwrap = false;
  for (let i = 0; i < children.length; i++) {
    let child = children[i];
    if (typeof child === 'function' && !child.length) {
      if (doNotUnwrap) {
        results.push(child);
        needsUnwrap = true;
        continue;
      }
      do child = child();
      while (typeof child === 'function' && !child.length);
    }
    if (Array.isArray(child)) {
      if (DEV && !warnedNestedManual && manualOrderOf(child)) {
        warnedNestedManual = true;
        console.warn('[frameact] <For order="manual"> nested in a larger array loses its manual order (it needs its own slot); the ordinary diff is used');
      }
      needsUnwrap = flattenArray(child, results, skipNonRendered, doNotUnwrap) || needsUnwrap;
    } else if (skipNonRendered && (child == null || child === true || child === false || child === '')) {
      // not rendered
    } else results.push(child);
  }
  return needsUnwrap;
}

/** Compute-half value shape: primitives stay raw (text nodes are materialised in the apply, reusing positional ones). */
export function normalize(value: any, multi: boolean, doNotUnwrap: boolean): any {
  value = flatten(value, true, doNotUnwrap);
  // Only a zero-parameter function is an accessor that gets its own effect. A function with parameters
  // (a row mapper) is a value: it falls through to insertExpression, which renders it as nothing.
  if (doNotUnwrap && typeof value === 'function' && !value.length) return value;
  if (multi && !Array.isArray(value)) value = [value != null ? value : ''];
  return value;
}

/**
 * Compiler primitive. `marker === undefined`: the hole is the element's only content (root mode:
 * textContent fast path). `marker` a node or `null`: multi mode, content lives before the marker
 * (`null` = at the end).
 */
export function insert(
  parent: MountableElement,
  accessor: unknown,
  marker?: Node | null,
  initial?: unknown,
  options?: InsertOptions,
): void {
  const multi = marker !== undefined;
  const host = options?.host && { parent, host: options.host };
  if (multi && !initial) initial = [];
  if (typeof accessor !== 'function' || (accessor as (...args: unknown[]) => unknown).length) {
    const value = normalize(accessor, multi, true);
    if (typeof value !== 'function' || value.length) {
      const inserted = insertExpression(parent, value, initial, marker);
      if (host) tagHost(inserted, host);
      return;
    }
    accessor = value;
  }
  if (multi && (initial as unknown[]).length === 0) {
    const placeholder = createOwnText('');
    getNatives().insertBefore.call(parent, placeholder, marker ?? null);
    initial = [placeholder];
  }
  let current: any = initial;
  const effectOptions: EffectOptions | undefined = options?.name === undefined ? undefined : { name: options.name };
  const read = accessor as () => unknown;
  createRenderEffect<any>(
    () => {
      const value = normalize(read(), multi, true);
      if (typeof value !== 'function') return value;
      // A function value (a For's row accessor, a memo, a fragment holding one) gets its own effect:
      // the outer tracks only what produced the function. Owned by this compute → disposed when the
      // outer recomputes.
      createRenderEffect<any>(
        () => normalize(value, multi, false),
        (inner) => {
          current = insertExpression(parent, inner, current, marker);
          if (host) tagHost(current, host);
        },
        effectOptions,
      );
      return INNER_OWNED;
    },
    (value) => {
      if (value === INNER_OWNED) return;
      current = insertExpression(parent, value, current, marker);
      if (host) tagHost(current, host);
    },
    effectOptions,
  );
}

/**
 * Apply half: write `value` into the slot described by `current`, return the new `current`.
 * Note: when `value` is an array it is mutated in place (primitives and non-renderables are replaced
 * by text nodes). `insert` always passes a fresh copy (see `flatten`); direct callers must too.
 */
export function insertExpression(parent: MountableElement, value: any, current: any, marker?: Node | null): any {
  if (value === current) return value;
  const { firstChild, nodeType, parentNode, insertBefore, replaceChild, removeChild, setTextContent } = getNatives();
  const t = typeof value;
  const multi = marker !== undefined;

  if (t === 'string' || t === 'number') {
    const text = String(value);
    if (multi) {
      // Direct callers only: insert() wraps primitives into an array in multi mode.
      let node = Array.isArray(current) ? current[0] : undefined;
      if (node && ownText.has(node)) {
        if (node.data !== text) node.data = text;
      } else node = createOwnText(text);
      return cleanChildren(parent, current, marker, node);
    }
    const tc = typeof current;
    const first = firstChild.call(parent);
    if ((tc === 'string' || tc === 'number') && current !== '' && first && nodeType.call(first) === 3) {
      (first as Text).data = text;
    } else setTextContent.call(parent, text);
    return value;
  }
  if (value == null || t === 'boolean') return cleanChildren(parent, current, marker);
  if (t === 'function') {
    if (value.length) {
      // Same as an array item: a row mapper is not renderable. Renders as nothing, old content cleared.
      if (DEV) console.warn('[frameact] Unrecognized child value. Rendered as nothing', value);
      return cleanChildren(parent, current, marker);
    }
    if (DEV) console.error('[frameact] insertExpression: unexpected function value (normalize first)', value);
    return current;
  }
  if (Array.isArray(value)) {
    const currentArray = Array.isArray(current);
    for (let i = 0; i < value.length; i++) {
      const item = value[i];
      const ti = typeof item;
      if (ti === 'string' || ti === 'number') {
        const text = String(item);
        const prev = currentArray ? current[i] : undefined;
        if (prev && ownText.has(prev)) {
          if (prev.data !== text) prev.data = text;
          value[i] = prev;
        } else value[i] = createOwnText(text);
      } else if (item == null || !item.nodeType) {
        // Not renderable: a function with parameters (a row mapper is a value, not an accessor), a plain
        // object, a stray null. Placing it into the DOM would throw `insertBefore: not of type Node`, so it
        // renders as nothing (Solid 2.0's client.ts has no such guard and throws).
        if (DEV) console.warn('[frameact] Unrecognized child value. Rendered as nothing', item);
        value[i] = createOwnText('');
      }
    }
    if (value.length === 0) {
      cleanChildren(parent, current, marker);
    } else if (currentArray) {
      if (current.length === 0) appendNodes(parent, value, marker ?? null);
      else {
        const manual = manualOrderOf(value);
        if (manual) reconcileManual(parent, current, value, marker, manual);
        else reconcileArrays(parent, current, value, marker);
      }
    } else {
      if (current != null && current !== '') {
        if (!multi) setTextContent.call(parent, '');
        else if (current.nodeType && parentNode.call(current) === parent) removeChild.call(parent, current);
      }
      appendNodes(parent, value, marker ?? null);
    }
    return value;
  }
  if (value.nodeType) {
    if (Array.isArray(current)) {
      cleanChildren(parent, current, multi ? marker : null, value);
    } else if (current != null && current.nodeType) {
      if (parentNode.call(current) === parent) replaceChild.call(parent, value, current);
      else insertBefore.call(parent, value, marker ?? null);
    } else if (current != null && current !== '' && firstChild.call(parent)) {
      // a sole text child holds the previous primitive (`0`/`NaN` are falsy, hence `!= null`)
      replaceChild.call(parent, value, firstChild.call(parent)!);
    } else insertBefore.call(parent, value, marker ?? null);
    tagSlot(value, marker);
    return value;
  }
  if (DEV) console.warn('[frameact] Unrecognized value. Skipped inserting', value);
  return current;
}

/** Remove the slot's nodes (optionally replacing them with one node). Returns the new `current`. */
function cleanChildren(parent: MountableElement, current: any, marker?: Node | null, replacement?: any): any {
  const { insertBefore, replaceChild, removeChild, appendChild, setTextContent } = getNatives();
  if (marker === undefined) {
    setTextContent.call(parent, '');
    if (replacement) {
      appendChild.call(parent, replacement);
      tagSlot(replacement, marker);
    }
    return replacement ?? '';
  }
  const list: any[] = Array.isArray(current) ? current : current != null && current !== '' ? [current] : [];
  if (list.length) {
    let inserted = false;
    for (let i = list.length - 1; i >= 0; i--) {
      const el = list[i];
      if (replacement !== el) {
        const owns = ownedBy(el, parent, marker);
        if (replacement && !inserted && !i) {
          if (owns) replaceChild.call(parent, replacement, el);
          else insertBefore.call(parent, replacement, marker);
        } else if (owns) removeChild.call(parent, el);
      } else inserted = true;
    }
  } else if (replacement) insertBefore.call(parent, replacement, marker);
  if (replacement) tagSlot(replacement, marker);
  return replacement ? [replacement] : [];
}

function appendNodes(parent: MountableElement, array: any[], marker: Node | null): void {
  const { insertBefore } = getNatives();
  for (let i = 0; i < array.length; i++) {
    const n = array[i];
    insertBefore.call(parent, n, marker);
    tagSlot(n, marker);
  }
}

interface HostTag {
  parent: MountableElement;
  host: () => Node | null;
}

/** Portal content node -> its insert call's tag. A WeakMap, not a property: nothing on the node can clobber or throw. */
const portalHosts = new WeakMap<Node, HostTag>();

/**
 * The logical parent of a portal's top-level content node, or null. Reported only while the node's
 * native `parentNode` (prototype getter: a `<form>` control named `parentNode` shadows the property) is
 * that insert's mount, so a node moved out of the portal, or removed, stops reporting the old host.
 * Limitation: a node moved by hand elsewhere under the SAME mount (the default, `document.body`) keeps
 * its host; only leaving the mount is detected.
 */
export function portalHostOf(node: Node): Node | null {
  const tag = portalHosts.get(node);
  return tag !== undefined && getNatives().parentNode.call(node) === tag.parent ? tag.host() : null;
}

/**
 * @internal Test seam: register `node` as portal content hosted by `host` while it is a child of
 * `parent` (default: its current native parent).
 */
export function tagPortalHost(
  node: Node,
  host: () => Node | null,
  parent: MountableElement = getNatives().parentNode.call(node) as MountableElement,
): void {
  portalHosts.set(node, { parent, host });
}

/** Portal content: top-level nodes learn their logical host (delegated events bubble through it). */
function tagHost(value: any, tag: HostTag): void {
  if (Array.isArray(value)) {
    for (let i = 0; i < value.length; i++) tagHost(value[i], tag);
  } else if (value && value.nodeType && portalHosts.get(value) !== tag) portalHosts.set(value, tag);
}
```

```ts
import { DEV } from '../env';
import { createRoot } from '../index';
import { insert, type MountableElement } from './insert';
import { getNatives } from './natives';
import { strictHooks } from './strict';

/**
 * Mount `code()` into `element` (appended after existing children). Synchronous: the root insert's
 * first apply runs at creation; the write into an attached container goes through the stricterdom
 * seam.
 *
 * The returned disposer depends on the container at mount time. Empty container: root mode (the
 * `textContent` fast path), and the disposer clears the WHOLE container. Non-empty container: render
 * brackets its nodes with its own pair of empty text markers and the disposer removes only what is
 * between them (plus the markers), leaving pre-existing and later-appended siblings alone.
 * The container is read and written through the prototype natives: a `<form>` container with a
 * descendant named `firstChild`, `append` or `textContent` mounts and unmounts like any element.
 */
export function render(code: () => unknown, element: MountableElement, init?: unknown): () => void {
  if (DEV && !element) {
    throw new Error("[frameact] render(): the container element doesn't exist. Make sure it is in the document.");
  }
  const { firstChild, nextSibling, parentNode, appendChild, removeChild, setTextContent } = getNatives();
  let disposer!: () => void;
  const bounded = firstChild.call(element) !== null;
  const start = bounded ? document.createTextNode('') : null;
  const end = bounded ? document.createTextNode('') : null;
  strictHooks.forceMutation(() => {
    if (start && end) {
      appendChild.call(element, start);
      appendChild.call(element, end);
    }
    createRoot((dispose) => {
      disposer = dispose;
      insert(element, code(), end ?? undefined, init);
    });
  }, element);
  return () => {
    disposer();
    strictHooks.forceMutation(() => {
      if (!start || !end) {
        setTextContent.call(element, '');
        return;
      }
      if (parentNode.call(start) === element) {
        if (parentNode.call(end) === element) {
          for (let n = nextSibling.call(start); n && n !== end; ) {
            const next: ChildNode | null = nextSibling.call(n);
            removeChild.call(element, n);
            n = next;
          }
        } else if (DEV) {
          console.warn('[frameact] render(): the end marker is gone; only the start marker was removed.');
        }
      }
      start.remove();
      end.remove();
    }, element);
  };
}
```

```ts
// Adapted from dom-expressions packages/dom-expressions/src/client.js (MIT, © 2018-2019 Ryan Carniato):
// event delegation on `document`; handlers live on nodes under the compiler's `_$$<event>` keys.
import { DEV } from '../env';
import { portalHostOf } from './insert';
import { getNatives } from './natives';

/** Compiler contract: `el._$$click = handler`, `el._$$clickData = data` (accessed as strings: oxlint no-underscore-dangle). */
export const EVENT_KEY = '_$$';

const delegated = new WeakMap<Document, Set<string>>();
const clearHooks = new Set<(doc: Document) => void>();

/** Compiler primitive: attach one document listener per event type (idempotent). */
export function delegateEvents(eventNames: readonly string[], doc: Document = window.document): void {
  let names = delegated.get(doc);
  if (!names) delegated.set(doc, (names = new Set()));
  for (const name of eventNames) {
    if (!names.has(name)) {
      names.add(name);
      doc.addEventListener(name, eventHandler);
    }
  }
}

/** Tests/teardown: remove every delegated listener (and whatever registered through `onClearDelegated`). */
export function clearDelegatedEvents(doc: Document = window.document): void {
  const names = delegated.get(doc);
  if (names) {
    for (const name of names) doc.removeEventListener(name, eventHandler);
    delegated.delete(doc);
  }
  for (const hook of clearHooks) hook(doc);
}

/** Modules that add their own document listeners next to delegation (controlled inputs) clean up here. */
export function onClearDelegated(fn: (doc: Document) => void): void {
  clearHooks.add(fn);
}

/** A native listener or a listener object: the only things `addEventListener` accepts. */
function isListener(value: unknown): value is EventListenerOrEventListenerObject {
  return typeof value === 'function' || (typeof value === 'object' && value !== null && typeof (value as { handleEvent?: unknown }).handleEvent === 'function');
}

function refuseHandler(where: string, name: string, handler: unknown): void {
  if (DEV) console.error(`[frameact] ${where}${name}: the handler must be a function, a [fn, data] tuple or an object with handleEvent; got`, handler);
}

/** `[fn, data]` as a listener calling `fn.call(node, data, e)`; `undefined` when `fn` is not a function. The tuple is never written to (it may be shared). */
export function tupleListener(node: Element, tuple: readonly unknown[]): EventListener | undefined {
  const fn = tuple[0] as (data: unknown, e: Event) => void;
  const data = tuple[1];
  return typeof fn === 'function' ? (e: Event) => fn.call(node, data, e) : undefined;
}

/**
 * Write the two delegation expandos. On a `<form>` whose descendant is named `_$$click` the property is
 * a non-writable named property: the assignment throws in strict mode (DOM clobbering), which must not
 * cut the spread or the component short — reported in DEV, the handler is simply not attached.
 */
function setDelegated(node: Element, name: string, handler: unknown, data: unknown): void {
  const target = node as unknown as Record<string, unknown>;
  try {
    target[EVENT_KEY + name] = handler;
    target[EVENT_KEY + name + 'Data'] = data;
  } catch (error) {
    if (DEV) console.error(`[frameact] on${name}: could not store the delegated handler on`, node, '(a form control or <img id> named "' + EVENT_KEY + name + '" shadows it)', error);
  }
}

/** Compiler primitive: `addEvent(el, name, handler, delegate)`; tuple handlers carry bound data. */
export function addEvent(node: Element, name: string, handler: unknown, delegate?: boolean): void {
  if (delegate) {
    if (Array.isArray(handler)) {
      if (!isListener(handler[0])) return refuseHandler('onX=', name, handler);
      setDelegated(node, name, handler[0], handler[1]);
    } else {
      if (handler != null && !isListener(handler)) return refuseHandler('onX=', name, handler);
      setDelegated(node, name, handler, undefined); // a plain handler replaces a tuple's data
    }
    return;
  }
  if (Array.isArray(handler)) {
    const listener = tupleListener(node, handler);
    if (!listener) return refuseHandler('onX=', name, handler);
    node.addEventListener(name, listener);
  } else if (handler == null) {
    // nothing to attach
  } else if (isListener(handler)) {
    node.addEventListener(name, handler, typeof handler === 'function' ? undefined : (handler as AddEventListenerOptions));
  } else refuseHandler('onX=', name, handler);
}

const listeners = new WeakMap<Element, Map<string, EventListenerOrEventListenerObject>>();

/**
 * `on:name` / `oncapture:name`: a native listener per element and name, replaced or removed on update.
 * `slot` namespaces the key, so a second owner (a spread's `onX`) never displaces `on:name`.
 */
export function setListener(node: Element, name: string, value: unknown, capture: boolean, slot = ''): void {
  let map = listeners.get(node);
  const key = slot + (capture ? `c:${name}` : name);
  const prev = map?.get(key);
  if (prev) {
    node.removeEventListener(name, prev, capture || (typeof prev === 'function' ? undefined : (prev as EventListenerOptions)));
    map!.delete(key);
  }
  if (!value) return;
  if (!isListener(value)) return refuseHandler(capture ? 'oncapture:' : 'on:', name, value); // never stored: later updates stay valid
  if (!map) listeners.set(node, (map = new Map()));
  map.set(key, value);
  node.addEventListener(name, value, capture || (typeof value === 'function' ? undefined : (value as AddEventListenerOptions)));
}

// Structure is read through the prototype getters (natives.ts); portal hosts live in a WeakMap (insert.ts),
// so neither a named form control nor an expando can redirect the walk. Only the handler expandos
// (`_$$click`, `_$$clickData`) must be read off the node, and on a <form> either may be shadowed by a
// descendant named like the expando (`<img id="_$$keydownData">`). The shadowing is recognised by its
// descriptor — a form's named property is an own NON-WRITABLE data property, the runtime's expandos are
// always writable — so bound data that legitimately is a Node is still delivered.
const MAX_PORTAL_HOPS = 64;

/** Own, non-writable data property: what `[LegacyOverrideBuiltIns]` presents for a descendant's name/id. */
function isShadowed(node: object, key: string): boolean {
  const d = Object.getOwnPropertyDescriptor(node, key);
  return d !== undefined && d.writable === false;
}

function reportClobberedHandler(node: unknown, key: string): void {
  if (DEV) console.error(`[frameact] delegated handler skipped: "${key}" or "${key}Data" on`, node, 'is shadowed by a form control or <img id> of that name (DOM clobbering)');
}

function eventHandler(e: Event): void {
  const { parentNode, contains, shadowHost, nodeName } = getNatives();
  let node: any = e.target;
  const key = EVENT_KEY + e.type;
  const oriCurrentTarget = e.currentTarget;
  const retarget = (value: unknown) => Object.defineProperty(e, 'target', { configurable: true, value });
  /**
   * A portal's logical parent, from the registry insert.ts keeps (nothing on the node itself is read, so
   * DOM clobbering cannot fake a host). The host must also be a Node outside the portal's own subtree.
   */
  const portalHost = (n: any): Node | undefined => {
    const h = portalHostOf(n);
    return h instanceof Node && !contains.call(n, h) ? h : undefined;
  };
  let hops = 0; // safety net: portals nest a handful of levels, a longer chain is a cycle
  const handleNode = (): boolean => {
    const handler = node[key];
    if (handler && node.disabled !== true) {
      if (nodeName.call(node) === 'FORM' && (isShadowed(node, key) || isShadowed(node, `${key}Data`))) {
        reportClobberedHandler(node, key);
      } else {
        const data = node[`${key}Data`];
        if (typeof handler === 'function') {
          if (data !== undefined) handler.call(node, data, e);
          else handler.call(node, e);
        } else if (typeof handler.handleEvent === 'function') handler.handleEvent(e);
      }
      if (e.cancelBubble) return false;
    }
    if (node instanceof ShadowRoot) {
      const host = shadowHost.call(node);
      if (!portalHost(host) && contains.call(node, e.target as Node)) retarget(host);
    }
    return true;
  };
  const walkUpTree = () => {
    while (handleNode()) {
      const host = portalHost(node);
      if (host && ++hops > MAX_PORTAL_HOPS) break;
      node = host || parentNode.call(node) || (node instanceof ShadowRoot ? shadowHost.call(node) : null);
      if (!node) break;
    }
  };
  // simulate currentTarget
  Object.defineProperty(e, 'currentTarget', {
    configurable: true,
    get() {
      return node || document;
    },
  });
  try {
    if (e.composedPath) {
      const path = e.composedPath();
      retarget(path[0]);
      for (let i = 0; i < path.length - 2; i++) {
        node = path[i];
        if (!handleNode()) break;
        const host = portalHost(node);
        if (host) {
          node = host;
          walkUpTree(); // bubble up from the portal's logical position
          break;
        }
        if (parentNode.call(node) === oriCurrentTarget) break; // never above the delegation root
      }
    } else walkUpTree();
  } finally {
    // Back to the native values for whoever listens after us (Task 8's document-level checks).
    // The shadowing own properties are deleted, so the prototype getters answer again.
    delete (e as any).target;
    delete (e as any).currentTarget;
  }
}
```

**Files:**

- Create: `test/core/zombieRows.test.ts`

**Interfaces:**
- Consumes: `mapArray`, `createEffect`, `createSignal`, `createRoot`, `onCleanup`, `flushSync` (`src/index.ts`); `For`, `insert`, `createComponent` (`src/dom`); `useDomHarness`, `container` (`test/helpers/dom.ts`).
- Produces: `Scope._mapMemo?: Computation` — an OPTIONAL field that only `map.ts` sets, on the three map scopes (a property added after construction: those few objects change shape, every other node keeps its hidden class and its in-object layout — measured: putting the field into `initScope` for every node cost 4–7 % on plain-signal propagation, the optional field costs nothing); `runEffect` treats a dirty `_mapMemo` on an ancestor scope like a dirty memo ancestor (pulled top-down before the row computes). No public API changes.

The defect. A row created by `mapArray` is owned by its item node, which is owned by the map's private scope, which is owned by whoever created the map — the map's **memo** is a sibling, not an ancestor. A row that looks its entity up by id (`<For each={ids}>{id => entities()[id].title}`) is dirtied by the entity write and runs before the list's reader pulls the memo that would dispose it: it reads a deleted entity (a TypeError in the row). The ancestor rule (spec §3.2, run step 3) pulls dirty memo *ancestors* only. Fix: the rows' scope knows its map memo and the run pulls it first when it is not CLEAN — the memo recomputes, disposes the gone row, and the run exits. Found by the store prototype (`.superpowers/store-b-prototype.md`, "зомби-строки"); it is independent of the store and is fixed before it.

Mechanics (spec §3.5 req. 6, proven by the prototype and its fuzz):
- a store leaf write runs a **store walk**: every node it dirties (CLEAN → dirty) gets `F_STORE`;
- any **plain walk** (a `createSignal` write, a `mapArray` item write, the result write of a memo dirty for a plain reason) reaching a node clears `F_STORE` and descends below it even if it is already dirty, so a plain change always reaches the effects below (the "mixed memo" mutation check);
- the result write of a memo recomputed because of store writes only is itself a store walk (`update()` remembers the cause on entry);
- when an effect's run executes (in its drain) with `F_STORE` set, on a **frame schedule** (`frameMeasure`/`frameMutation`/`frameForcedReflow`) or a `gateOnHeavyAnimation` schedule, not live-marked, and a scope in its chain animates (sampled once per drain by animation-begin epoch: a scope that began mid-drain does not count, a scope that ended mid-drain does not count and the chain is checked further up), the effect is **parked**: it stays dirty (CHECK/DIRTY, so the usual dirty checking still applies at release) with no run booked. `tickEnd` and `idle` effects are never parked (user decision: logic is not gated; `idle` waits for animations on its own);
- a plain walk reaching a parked effect unparks it (books the run): it runs now and reads the current state, store included — no computation ever reads two moments of the store;
- a plain run of a descendant effect unparks its parked ancestor first (ancestor rule) — and an ancestor that is booked but not run yet when the descendant bails onto it loses its `F_STORE` tag, so its run cannot park either (the descendant's plain change would otherwise wait for the animation);
- when the scope stops animating, its parked effects (still parked, not disposed) are re-booked in park order and land in the next frame; a nested still-animating scope parks them again;
- a live reader (`F_LIVE` from `markLiveRead()` in its last compute, or `F_LIVE_PIN` for its lifetime) reached by a store walk is not marked by it: it is **relayed** — re-delivered by a plain walk right after the store walk — so it and everything below it are never tagged or parked.

```ts
// The store gate (spec §3.5 req. 6, "парковка по причине"): a frame effect whose run is due to store
// writes only waits for the end of the heavy animations in its scope chain. Installed into the core's
// runEffect hook when `frameact/store` is imported; without a store nothing carries F_STORE and the
// hook is never consulted. The core decides WHETHER a run is a candidate (F_STORE, store-gated schedule,
// not live); this module decides WHERE it waits and releases it.
import { effectScopeOf, parkEffect, rebookParked, setStoreGate, type EffectNode } from '../core/effects';
import { firstAnimatingScopeSampled, isAnyScopeAnimating, type HeavyAnimationScope } from '../scheduler/heavyAnimation';

/**
 * Effects parked on a scope, in park order. A list exists exactly while a release is armed on its
 * scope. An effect unparked by a plain walk and parked again later is listed twice (the second
 * rebook finds it already clean and skips it), and a disposed effect stays listed until the release:
 * both are bounded by one animation of that scope.
 */
const parked = new WeakMap<HeavyAnimationScope, EffectNode[]>();

function release(scope: HeavyAnimationScope) {
  const list = parked.get(scope);
  if (list === undefined) return;
  parked.delete(scope);
  // Re-booked in park order; each lands in the next frame through its own schedule. An effect that
  // ran meanwhile (unparked by a plain walk) or was disposed is skipped; one whose chain still
  // animates (a nested scope) parks there again at its run.
  for (let i = 0; i < list.length; i++) rebookParked(list[i]);
}

setStoreGate((node) => {
  if (!isAnyScopeAnimating()) return false;
  // (a scope that ended mid-drain is not returned: it animates no more, and its `once` has fired)
  const scope = firstAnimatingScopeSampled(effectScopeOf(node));
  if (scope === null) return false;
  let list = parked.get(scope);
  if (list === undefined) {
    parked.set(scope, (list = []));
    scope.isAnimating.once(() => release(scope));
  }
  parkEffect(node);
  list.push(node);
  return true;
});
```

```ts
export function median(xs: number[]) {
  return [...xs].sort((a, b) => a - b)[xs.length >> 1];

/** Median over `batches` batches of `ops` calls of fn(k), after `warm` calls; ns per op. */
export function nsPerOp(fn: (k: number) => void, { ops = 1000, batches = 9, warm = 2000 } = {}) {
  let k = 0;
  for (; k < warm; k++) fn(k);
  const samples: number[] = [];
  for (let b = 0; b < batches; b++) {
    (globalThis as any).gc();
    const t0 = performance.now();
    for (let i = 0; i < ops; i++) fn(k++);
    samples.push(((performance.now() - t0) * 1e6) / ops);
  }
  return median(samples);
}
```

**Interfaces:**
- Consumes: `createSignalNode`, `getObserver`, `trackNode`, `writeStoreNode` (`src/core/core.ts`, Task 3); `TRACK` (`src/core/symbols.ts`); `src/store/gate.ts` (Task 3, imported for its side effect).
- Produces (`src/store/store.ts`, re-exported by `src/store/index.ts`):
  - `createStore<T extends object>(initial: T): [Store<T>, SetStoreFunction<T>]`; `type Store<T>` (deep read-only view); `type SetStoreFunction<T>` (path overloads up to 4 keys; a path part is a key, a `readonly` array of keys, or `(item, index) => boolean` on arrays; the last argument is a value, `undefined` (deletes the key) or an updater `(prev) => next`);
  - `merge<P extends object>(partial: P): Merger<P>` — shallow merge, the only way to merge (`Merger<P>` is accepted where `Updater<V>` lists `Merger<Partial<V>>`: the partial's keys and value types are checked against the path); `produce<T>(fn: (draft: T) => void): (prev: unknown) => T` (`T` comes from the path: the contextual return type); `unwrap<T>(value: T): T` (live raw tree, O(1)); `snapshot<T>(value: T): T` (`structuredClone(unwrap(value))`); a user updater is typed `(prev: Store<V>) => V` (it receives the raw value at run time; the read-only type keeps `l => { l.push(x); return l }` — a mutation the store would not see — from type-checking; `produce`/`reconcile` take `prev: unknown`, so a narrower chunk type still fits a path by its return type);
  - `$RAW`, `$TRACK` (= core `TRACK`); `isWrappable(v)` (plain objects and arrays that are NOT frozen; a frozen object is an immutable value: returned raw, replaceable, never written into), `setProperty(raw, key, value, deleteOnUndefined = true)` (internal, used by `reconcile.ts` in Task 5; adopts new objects deeply — no proxy ever enters the raw tree), `nodes` (internal `WeakMap`); `storeStats` (`@internal`, DEV counters for tests: `leafSignals`, `nodes`).
  - `ungatedDepth` plumbing in `setProperty` (Task 6 adds the `ungated()`/`live()` facades).

Semantics (spec §3.5, the user's decisions): the value at the end of a path **replaces** the previous one (objects too); merging is only explicit, `merge()`; `undefined` at the end of a path **deletes** the key (`in` and `Object.keys` are honest) — at an **array index** the path form throws a `TypeError` (`use produce(a => a.splice(i, 1))`), `produce` keeps JS semantics (`draft[i] = undefined` stores the value, `delete draft[i]` leaves a hole); the root cannot be replaced (`setState(merge(…))`, `setState(produce(…))`, `setState(reconcile(…))` only; a plain value or an updater returning another object at the root is a `TypeError`). Writes go into the raw object in place; identity is kept everywhere; only the leaves that exist (were read under tracking) are notified, and the leaf of a deleted key is dropped from its table after the notification. A proxy written into the store (a spread copy, `merge({ y: state.a.b })`) is **adopted**: unwrapped deeply, so the raw tree never holds a proxy. Frozen objects are immutable **values** (not wrapped; readable; replaceable; a frozen root is rejected; `produce` on a frozen value is a DEV `TypeError`); writing into one is a DEV `TypeError` with a clear message (in production the strict-mode assignment throws the native one). Snapshots are explicit and O(n). No service fields on user objects; the proxy is read-only (`TypeError` on write).

```ts
// frameact/store — model B, the "signal-way" tree store (spec §3.5), in the spirit of Solid's
// createStore (MIT, © 2016-2025 Ryan Carniato). State is a tree of plain objects and arrays; every
// property becomes a slim core signal lazily, on its first TRACKED read; a path write mutates the raw
// object in place and notifies that leaf only. No service fields on user objects: the per-object
// bookkeeping (proxy, leaf signals, shape signal) lives in a WeakMap'd StoreNode, which is also the
// Proxy handler of that object (the traps reach its fields through `this`: no lookup on the read path).
import { DEV } from '../env';
import { createSignalNode, getObserver, trackNode, writeStoreNode } from '../core/core';
import { TRACK } from '../core/symbols';
import type { Computation } from '../core/types';

/** Read on a store proxy: the raw object behind it (see unwrap). */
export const $RAW: unique symbol = Symbol('frameact.store.raw') as any;
/**
 * Read on a store ARRAY proxy: subscribes to the array's shape with one link and returns a plain
 * array of its items (wrapped). `mapArray`/`For` read it, so a list never subscribes per index.
 */
export const $TRACK: typeof TRACK = TRACK;

/** The read-only view of a store value: properties and arrays readonly, functions as they are. */
export type Store<T> = T extends (...args: any[]) => any
  ? T
  : T extends readonly (infer U)[]
    ? StoreArray<U>
    : T extends object
      ? { readonly [K in keyof T]: Store<T[K]> }
      : T;

/** A store array: a readonly array of store items with the `$TRACK` key (`mapArray`/`For` read it). */
export interface StoreArray<U> extends ReadonlyArray<Store<U>> {
  readonly [$TRACK]: readonly Store<U>[];
}

/** @internal DEV counters for tests. */
export const storeStats = { leafSignals: 0, nodes: 0 };

/** raw object → its node. Only objects that were ever read through a proxy have one. */
const nodes = new WeakMap<object, StoreNode>();

/**
 * Plain objects (incl. null-prototype) and arrays become store nodes; class instances, Dates, Maps…
 * are values. A frozen object is a value too: it cannot be mutated (the store writes in place), and a
 * proxy over it could not honour its non-configurable properties — it is returned raw and replaced whole.
 */
export function isWrappable(v: unknown): v is object {
  if (v === null || typeof v !== 'object') return false;
  if (Object.isFrozen(v)) return false;
  if (Array.isArray(v)) return true;
  const proto = Object.getPrototypeOf(v);
  return proto === Object.prototype || proto === null;
}

function readOnly(): never {
  throw new TypeError('[frameact/store] the state is read-only: write through setState (merge, produce, reconcile)');
}

/**
 * Leaf-signal table: instances of a constructor whose prototype has no properties (no inherited
 * `constructor`/`toString` keys) — fast-mode objects that share hidden classes across objects of one
 * shape (all messages read the same fields), unlike `Object.create(null)` dictionaries (measured:
 * -80 B per row, -12 ns per read).
 */
const SigTable = function SigTable() {} as unknown as { new (): Record<PropertyKey, Computation> };
SigTable.prototype = Object.create(null);

/** The node of one raw object — and the Proxy handler of its proxy. */
class StoreNode {
  readonly raw: any;
  readonly proxy: any;
  /** key → leaf signal (slim core signal node), created on the first tracked read */
  sigs: Record<PropertyKey, Computation> | null;
  /** shape signal: arrays — any index/length change; objects — a key added or removed (ownKeys, $TRACK) */
  self: Computation | null;
  /** the shape signal's value: bumped by every shape change */
  shape: number;

  constructor(raw: object) {
    this.raw = raw;
    this.sigs = null;
    this.self = null;
    this.shape = 0;
    this.proxy = new Proxy(raw, this as ProxyHandler<any>);
    nodes.set(raw, this);
    if (DEV) storeStats.nodes++;
  }

  get(target: any, key: PropertyKey): any {
    const value = target[key];
    if (value === undefined) {
      // (the service keys are never on the target)
      if (key === $RAW) return target;
      if (key === $TRACK) return Array.isArray(target) ? trackedItems(this) : undefined;
    }
    if (getObserver() !== null && typeof key !== 'symbol' && (typeof value !== 'function' || Object.hasOwn(target, key))) {
      trackKey(this, key, value);
    }
    if (typeof value === 'object' && value !== null) return wrap(value);
    return value;
  }

  has(target: any, key: PropertyKey): boolean {
    if (getObserver() !== null && typeof key !== 'symbol') trackKey(this, key, target[key]);
    return key in target;
  }

  ownKeys(target: any): ArrayLike<string | symbol> {
    trackSelf(this);
    return Reflect.ownKeys(target);
  }

  getOwnPropertyDescriptor(target: any, key: PropertyKey): PropertyDescriptor | undefined {
    const desc = Reflect.getOwnPropertyDescriptor(target, key);
    if (!desc || desc.get || desc.set || !desc.configurable) return desc;
    // An accessor: Object.keys / spread check enumerability without reading (tracking) the value.
    const proxy = this.proxy;
    delete desc.value;
    delete desc.writable;
    desc.get = () => proxy[key];
    return desc;
  }

  set(): boolean {
    return readOnly();
  }
  deleteProperty(): boolean {
    return readOnly();
  }
  defineProperty(): boolean {
    return readOnly();
  }
}

function trackKey(node: StoreNode, key: PropertyKey, value: unknown) {
  let sigs = node.sigs;
  if (sigs === null) sigs = node.sigs = new SigTable();
  let s = sigs[key];
  if (s === undefined) {
    s = sigs[key] = createSignalNode(value);
    if (DEV) storeStats.leafSignals++;
  }
  trackNode(s);
}

function trackSelf(node: StoreNode) {
  if (getObserver() === null) return;
  let s = node.self;
  if (s === null) {
    s = node.self = createSignalNode(0);
    if (DEV) storeStats.leafSignals++;
  }
  trackNode(s);
}

/**
 * `$TRACK` read: subscribe to the shape only and return a plain array of the items, wrapped, built
 * from the raw array (no per-index trap: an index read through a Proxy stringifies the index, ~80 ns).
 */
function trackedItems(node: StoreNode): unknown[] {
  trackSelf(node);
  const raw = node.raw as unknown[];
  const n = raw.length;
  const out: unknown[] = [];
  out.length = n;
  for (let i = 0; i < n; i++) {
    const v = raw[i];
    out[i] = typeof v === 'object' && v !== null ? wrap(v) : v;
  }
  return out;
}

function wrap(value: object): any {
  const n = nodes.get(value);
  if (n !== undefined) return n.proxy;
  if (!isWrappable(value)) return value;
  return new StoreNode(value).proxy;
}

/** The raw object behind a store proxy (or the value itself). O(1): the raw tree holds raw objects only. */
export function unwrap<T>(value: T): T {
  if (value !== null && typeof value === 'object') {
    const raw = (value as any)[$RAW];
    if (raw !== undefined) return raw;
  }
  return value;
}

/** A deep, detached copy (history, persistence, devtools). O(n); `unwrap()` is the live raw tree. */
export function snapshot<T>(value: T): T {
  return structuredClone(unwrap(value));
}

// ---- writes -------------------------------------------------------------------------------------

/** @internal > 0 inside `ungated()` (Task 6): leaf writes run plain walks instead of store walks. */
export let ungatedDepth = 0;
/** @internal */
export function setUngatedDepth(n: number) {
  ungatedDepth = n;
}

function notifyLeaf(s: Computation, value: unknown) {
  writeStoreNode(s, value, ungatedDepth === 0);
}

/**
 * Raw-tree invariant: no proxy inside. A new object written into the store (a spread copy of a store
 * object carries the proxies of its nested objects; `merge({ y: state.a.b })` carries one directly) is
 * unwrapped deeply — O(its new part): the walk stops at objects already in the tree (raw by the
 * invariant) and at values. A cyclic NEW object graph is not supported (infinite recursion).
 */
function adopt(v: object): object {
  const r = (v as any)[$RAW];
  if (r !== undefined) return r; // a store proxy or a produce draft
  if (nodes.has(v) || !isWrappable(v)) return v;
  const o = v as Record<string, unknown>;
  const keys = Object.keys(o);
  for (let i = 0; i < keys.length; i++) {
    const c = o[keys[i]];
    if (c !== null && typeof c === 'object') {
      const a = adopt(c);
      if (a !== c) o[keys[i]] = a;
    }
  }
  return v;
}

/**
 * Write `raw[key] = value` — or, when `value` is `undefined` and `deleteOnUndefined` holds, delete the
 * key — and notify what exists: the leaf (dropped from the table after a deletion: its readers are dirty
 * and re-link a fresh leaf if they still read the key), the array `length` (on truncation also the
 * removed indexes) and the shape signal (arrays: any index/length write; objects: a key added or
 * removed). An object never read through a proxy has no node: nothing to notify.
 * Writing into a frozen object: a DEV `TypeError` with a clear message; in production the strict-mode
 * assignment throws the native one.
 */
export function setProperty(raw: any, key: PropertyKey, value: unknown, deleteOnUndefined = true): void {
  if (value !== null && typeof value === 'object') value = adopt(value);
  const prev = raw[key];
  const had = prev !== undefined || Object.hasOwn(raw, key);
  const del = value === undefined && deleteOnUndefined;
  if (del ? !had : prev === value && (had || value !== undefined)) return;
  if (DEV && Object.isFrozen(raw)) {
    throw new TypeError(`[frameact/store] cannot write "${String(key)}" into a frozen object (the store owns and mutates the objects it holds; replace the frozen object instead)`);
  }
  const isArr = Array.isArray(raw);
  const prevLen = isArr ? raw.length : 0;
  if (del) delete raw[key];
  else raw[key] = value;
  const node = nodes.get(raw);
  if (node === undefined) return;
  const sigs = node.sigs;
  if (sigs !== null) {
    const s = sigs[key];
    if (s !== undefined) {
      notifyLeaf(s, value);
      if (del) delete sigs[key];
    }
    if (isArr) {
      const len = raw.length;
      if (len !== prevLen) {
        const ls = sigs.length;
        if (ls !== undefined && key !== 'length') notifyLeaf(ls, len);
        // truncation: the removed indexes read undefined now
        for (let i = len; i < prevLen; i++) {
          const is = sigs[i];
          if (is !== undefined) notifyLeaf(is, undefined);
        }
      }
    }
  }
  const self = node.self;
  if (self !== null && (isArr || had === del)) notifyLeaf(self, ++node.shape);
}

declare const MERGED: unique symbol;
/**
 * The updater `merge()` returns — a function at run time, typed as a marker (no call signature, so it
 * never competes with `(prev: V) => V` for the contextual typing of inline updaters). It is accepted
 * where `Updater<V>` lists `Merger<Partial<V>>`: the partial's keys and value types are checked
 * against the value at the path (an unknown key or a wrong value type is an error).
 */
export interface Merger<P> {
  readonly [MERGED]?: P;
}

/**
 * `setState(…path, merge({ title, unread: 0 }))`: a SHALLOW merge into the object at the path (the
 * only way to merge — a plain object at a path replaces). `undefined` values delete their keys.
 */
export function merge<P extends object>(partial: P): Merger<P> {
  const next = unwrap(partial) as Record<PropertyKey, unknown>;
  return ((prev: unknown) => {
    if (!isWrappable(prev) || Array.isArray(prev)) {
      throw new TypeError('[frameact/store] merge(): the value at the path is not a plain object');
    }
    const keys = Object.keys(next);
    for (let i = 0; i < keys.length; i++) setProperty(prev, keys[i], next[keys[i]]);
    return prev;
  }) as unknown as Merger<P>;
}

type PathPart = PropertyKey | readonly PropertyKey[] | ((item: any, index: number) => boolean);

/** Apply the last argument of setState at `parent[key]`: a value replaces, `undefined` deletes a key, an updater runs first. */
function applyAt(parent: any, key: PropertyKey, value: unknown): void {
  if (typeof value === 'function') {
    const prev = parent[key];
    value = (value as (prev: unknown) => unknown)(prev);
    if (value === prev) return; // merge / produce / reconcile mutated in place
  }
  if (value === undefined && Array.isArray(parent)) {
    // A hole is never what is wanted (For renders an undefined item, JSON turns it into null).
    throw new TypeError(`[frameact/store] setState(…, ${String(key)}, undefined): use produce(a => a.splice(i, 1)) to remove an item`);
  }
  setProperty(parent, key, unwrap(value));
}

function fanOut(current: any, part: PathPart, apply: (key: PropertyKey) => void): boolean {
  if (Array.isArray(part)) {
    for (let j = 0; j < part.length; j++) apply(part[j]);
    return true;
  }
  if (typeof part === 'function') {
    if (!Array.isArray(current)) throw new TypeError('[frameact/store] a filter function in a path selects items of an array');
    for (let j = 0; j < current.length; j++) if (part(current[j], j)) apply(j);
    return true;
  }
  return false;
}

/** Walk `path` (the setState arguments) from `current`; iterative over plain keys, recursive only where a part fans out. */
function updatePath(current: any, path: unknown[], i: number): void {
  const last = path.length - 1; // the value
  for (; i < last - 1; i++) {
    const part = path[i] as PathPart;
    if (fanOut(current, part, (key) => updatePath(current[key], path, i + 1))) return;
    current = current[part as PropertyKey];
    if (current === null || typeof current !== 'object') {
      throw new TypeError(`[frameact/store] setState: nothing to descend into at "${String(part)}" (${String(current)})`);
    }
  }
  const value = path[last];
  if (i === last) {
    // The root: its object cannot be replaced (the proxy is bound to it): merge / produce / reconcile only.
    if (typeof value !== 'function' || (value as (prev: unknown) => unknown)(current) !== current) {
      throw new TypeError('[frameact/store] setState(value): the root cannot be replaced — use merge(), produce() or reconcile()');
    }
    return;
  }
  const part = path[last - 1] as PathPart;
  if (fanOut(current, part, (key) => applyAt(current, key, value))) return;
  applyAt(current, part as PropertyKey, value);
}

// ---- produce ------------------------------------------------------------------------------------

const drafts = new WeakMap<object, any>();
const draftHandler: ProxyHandler<any> = {
  get(target, key) {
    if (key === $RAW) return target;
    const v = target[key];
    return isWrappable(v) ? draftOf(v) : v;
  },
  set(target, key, value) {
    setProperty(target, key, unwrap(value), false); // JS semantics: `draft[k] = undefined` stores undefined
    return true;
  },
  deleteProperty(target, key) {
    setProperty(target, key, undefined); // `delete draft[k]`: the key goes (an array gets a hole)
    return true;
  },
};
function draftOf(raw: object): any {
  let d = drafts.get(raw);
  if (d === undefined) drafts.set(raw, (d = new Proxy(raw, draftHandler)));
  return d;
}

/**
 * Draft mutation: `setState('chats', id, produce(c => { c.title = t; c.unread++ }))`. Every
 * assignment is a leaf write (only that leaf notifies); nothing is copied, identities are kept.
 * Arrays keep JS semantics inside: `splice` shifts, `delete draft[i]` leaves a hole, `draft[i] =
 * undefined` stores the value. A frozen value cannot be drafted (DEV `TypeError`): replace it.
 */
export function produce<T>(fn: (draft: T) => void): (prev: unknown) => T {
  return (prev) => {
    if (isWrappable(prev)) fn(draftOf(prev) as T);
    else if (DEV && prev !== null && typeof prev === 'object' && Object.isFrozen(prev)) {
      throw new TypeError('[frameact/store] produce(): the value at the path is frozen (an immutable value) — replace it instead');
    }
    return prev as unknown as T;
  };
}

 * `[state, setState]`: `state` is a read-only tracked view of `initial` (which the store now owns and
 * mutates — it must not be frozen); writes go through `setState`. Reactivity notes: `key in obj`,
 * `Object.keys`, iteration and `length` are tracked; `Object.hasOwn`/`hasOwnProperty` are not (use
 * `in`); a getter defined on a raw object runs with the raw receiver, so its reads are not tracked —
 * derive with `createMemo` instead.
 */
export function createStore<T extends object>(initial: T): [Store<T>, SetStoreFunction<T>] {
  const raw = unwrap(initial);
  if (Object.isFrozen(raw)) throw new TypeError('[frameact/store] createStore: the root object is frozen; the store owns and mutates its state');
  const node = nodes.get(raw) ?? new StoreNode(raw);
  const setState = ((...args: unknown[]) => updatePath(raw, args, 0)) as SetStoreFunction<T>;
  return [node.proxy as Store<T>, setState];
}
```

```ts
// reconcile (spec §3.5 req. 3): merge immutable data into the store by diff — matched items (by key)
// and unchanged branches keep their store identity, only changed leaves notify.
import { isWrappable, setProperty, unwrap } from './store';

export interface ReconcileOptions {
  /** Identity key of array items (default `'id'`); `null`: arrays are diffed by index. */
  key?: string | null;
}

/** `T` without `readonly` (deep): a `Readonly<…>`/`as const` chunk reconciles into a mutable path. */
export type Mutable<T> = T extends (...args: any[]) => any
  ? T
  : T extends readonly (infer U)[]
    ? Mutable<U>[]
    : T extends object
      ? { -readonly [K in keyof T]: Mutable<T[K]> }
      : T;

/** `parent[prop]` ← `next`: a changed primitive, a type change or a different key replaces; same-shaped objects recurse. */
function applyState(next: any, parent: any, prop: PropertyKey, key: string | null): void {
  const prev = parent[prop];
  if (next === prev) return;
  if (
    !isWrappable(next) ||
    !isWrappable(prev) ||
    Array.isArray(next) !== Array.isArray(prev) ||
    (key !== null && !Array.isArray(next) && (next as any)[key] !== (prev as any)[key])
  ) {
    setProperty(parent, prop, next);
    return;
  }
  reconcileInto(prev, next, key);
}

function reconcileInto(prev: any, next: any, key: string | null): void {
  if (Array.isArray(next)) {
    reconcileArray(prev, next, key);
    return;
  }
  let prevCount = 0; // prev's keys BEFORE the loop (an explicit `undefined` in next deletes during it)
  for (const k in prev) if (k !== undefined) prevCount++;
  let present = 0; // keys of `next` that `prev` has too
  for (const k in next) {
    const nv = next[k];
    const pv = prev[k];
    if (pv !== undefined || Object.hasOwn(prev, k)) present++;
    if (nv === pv) continue; // (the common case: an unchanged primitive)
    if (typeof nv === 'object' && nv !== null && typeof pv === 'object' && pv !== null) applyState(nv, prev, k, key);
    else setProperty(prev, k, nv); // (an `undefined` value deletes the key)
  }
  // deletions only when `prev` has keys `next` lacks: prevCount === present ⇔ every key of prev is in next
  if (prevCount !== present) {
    for (const k in prev) if (!Object.hasOwn(next, k)) setProperty(prev, k, undefined);
  }
}

function reconcileArray(prev: any[], next: any[], key: string | null): void {
  const n = next.length;
  const keyed = key !== null && n > 0 && isWrappable(next[0]) && (next[0] as any)[key] != null;
  if (!keyed) {
    for (let i = 0; i < n; i++) {
      if (next[i] === undefined) setProperty(prev, i, undefined, false); // an explicit undefined element is a value, not a hole
      else applyState(next[i], prev, i, key);
    }
  } else {
    // items matched by key keep their (old) raw object, merged in place; new keys are adopted
    const byKey = new Map<unknown, any>();
    for (let i = 0; i < prev.length; i++) {
      const o = prev[i];
      if (isWrappable(o)) byKey.set((o as any)[key], o);
    }
    const result: any[] = [];
    result.length = n;
    for (let i = 0; i < n; i++) {
      const item = next[i];
      const old = isWrappable(item) ? byKey.get((item as any)[key]) : undefined;
      if (old !== undefined && old !== item) {
        reconcileInto(old, item, key);
        result[i] = old;
      } else result[i] = item;
    }
    for (let i = 0; i < n; i++) if (prev[i] !== result[i]) setProperty(prev, i, result[i], false);
  }
  if (prev.length !== n) setProperty(prev, 'length', n);
}

/**
 * `setState('messages', chatId, reconcile(chunk))`: merge immutable data by diff. Array items are
 * matched by `key` (default `'id'`; keys must be unique — a duplicate puts one raw object at two
 * indexes) and merged into their old raw object — proxies and `For` rows keep their identity; new
 * items are adopted as they are (the store owns them from then on); the order is rewritten by index.
 * A non-object at the path, a type mismatch or a frozen `prev` (an immutable value) is replaced.
 */
export function reconcile<T>(value: T, options: ReconcileOptions = {}): (prev: unknown) => Mutable<T> {
  const key = options.key === undefined ? 'id' : options.key;
  const next = unwrap(value) as any;
  return (prev: any) => {
    if (!isWrappable(prev) || !isWrappable(next)) return next;
    if (Array.isArray(prev) !== Array.isArray(next)) return next;
    reconcileInto(prev, next, key);
    return prev;
  };
}
```

```ts
// Actions (spec §3.5 req. 5): plain typed functions. A call made while another action runs is queued
// and runs after it (FIFO: a nested call never interleaves with its caller, so the caller's writes are
// complete when the callee reads); afterActions(cb) runs once the cascade — actions and the callbacks
// they queued — is done. A throwing (or rejecting) action is reported; the queue goes on.
import { DEV } from '../env';

type AnyFn = (...args: any[]) => any;

/** DEV: a cascade (actions, their synchronous store walks, the after-callbacks) longer than this is reported. */
const SLOW_UPDATE_MS = 7;

/** A sync definition returns void; an `async` one a `Promise<void>` that resolves after it settled and never rejects. */
export type Actions<D extends Record<string, AnyFn>> = {
  readonly [K in keyof D]: (...args: Parameters<D[K]>) => ReturnType<D[K]> extends PromiseLike<any> ? Promise<void> : void;
};

let running = false;
const queue: (() => void)[] = [];
const names: string[] = [];
const after: (() => void)[] = [];

function report(name: string, error: unknown) {
  console.error(`[frameact/store] action "${name}" failed`, error);
}

/** Run one action; `done` (async definitions) is called once it settled, success or failure. */
function runOne(name: string, fn: AnyFn, args: unknown[], done: (() => void) | undefined) {
  let r: unknown;
  try {
    r = fn(...args);
  } catch (error) {
    report(name, error);
    done?.();
    return;
  }
  if (r && typeof (r as Promise<unknown>).then === 'function') {
    (r as Promise<unknown>).then(
      () => done?.(),
      (e) => {
        report(name, e);
        done?.();
      },
    );
  } else done?.();
}

/** Run the queue to completion: queued actions first, then the after-callbacks; either may queue more. */
function drain() {
  running = true;
  const t0 = DEV ? performance.now() : 0;
  try {
    for (;;) {
      if (queue.length !== 0) {
        queue.shift()!();
      } else if (after.length !== 0) {
        const cb = after.shift()!;
        try {
          cb();
        } catch (error) {
          report('afterActions', error);
        }
      } else break;
    }
  } finally {
    running = false;
  }
  if (DEV) {
    const dt = performance.now() - t0;
    const ran = names.splice(0);
    if (dt > SLOW_UPDATE_MS) console.warn(`[frameact/store] Slow store update: ${dt.toFixed(1)} ms in ${ran.join(', ')}`);
  }
}

/**
 * `const actions = defineActions({ openChat(id: string) { setState('currentChatId', id) } })`: the
 * types come from the definition. Each returned function queues the call and, outside a running
 * cascade, drains the queue at once (synchronously: a controlled input's handler sees the write).
 * An `async` definition returns a `Promise<void>` per call (resolved once the action settled, never
 * rejected — the error was reported); a sync definition returns `void` and allocates nothing. A sync
 * function that returns a promise is awaited for error reporting but returns `void`: declare it `async`.
 */
export function defineActions<D extends Record<string, AnyFn>>(defs: D): Actions<D> {
  const out: Record<string, (...args: unknown[]) => Promise<void> | undefined> = {};
  for (const name of Object.keys(defs)) {
    const fn = defs[name];
    const isAsync = fn.constructor.name === 'AsyncFunction';
    out[name] = (...args: unknown[]) => {
      let done: (() => void) | undefined;
      let promise: Promise<void> | undefined;
      if (isAsync) {
        promise = new Promise<void>((resolve) => {
          done = resolve;
        });
      }
      queue.push(() => runOne(name, fn, args, done));
      if (DEV) names.push(name);
      if (!running) drain();
      return promise;
    };
  }
  return out as unknown as Actions<D>;
}

/** Run `cb` after the current action cascade; outside a cascade, at once. */
export function afterActions(cb: () => void): void {
  if (running) after.push(cb);
  else cb();
}
```

## Follow-ups (not in this plan)

1. **Natives for `classList`, `style` and `addEventListener`** (`src/dom/classes.ts`, `styles.ts`, `events.ts`; getters `Element.prototype.classList`, `HTMLElement.prototype.style` / `SVGElement.prototype.style`, `EventTarget.prototype.addEventListener`/`removeEventListener`, called with `.call(node, …)` like the natives of Task 1). Today a `<form>` whose descendant is named `classList`/`style`/`addEventListener` fails loudly and locally, but because the compiler groups an element's dynamic attributes into one effect and `spread` applies props in one pass, the *sibling* attributes of that element (`title`, `aria-*`, `data-*`) are not applied either. Same cost as the existing `.call`s; a dozen call sites; its own `clobbering.test.ts` cases (a clobbered form with `class={…}`, `style={…}`, `on:click`).
2. **`document.addEventListener` through `EventTarget.prototype.addEventListener`** in `delegateEvents`/`clearDelegatedEvents` (`src/dom/events.ts`) and `installListeners` (`src/dom/controlled.ts`): `document` has `[LegacyOverrideBuiltIns]` too, so `<form name="addEventListener">` or `<img name="addEventListener">` in the document shadows the method (a `name`, not an `id`: low risk). Do together with 1; update the "Не покрыто" lines of spec §3.3 and the header of `natives.ts`.
3. **Store benchmarks of the prototype** (`read`, `list`, `memory`, `reconcile`, `write`) belong to plan 5's suite next to the teact/Solid comparison.
