# frameact store — Implementation Plan (plan 3 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `frameact/store` — TeactN (Telegram Web A's global store) ported onto frameact's signals: a private `global` signal with the DEV outdated-global check, propagation through one gated *bridge* signal per heavy-animation scope, the teact action queue (`execAfterActions`, promise actions, callbacks), `withGlobal` containers with per-key lazy memos, `liveGlobal` for controlled inputs — preceded by one DOM-hardening task (DOM clobbering outside event delegation, carried from plan 2's appsec review).

**Architecture:** `setGlobal` writes a plain signal at once; nothing in the UI reads that signal directly. For every heavy-animation scope that has a container, the store lazily creates a *bridge*: `[bridged, setBridged]` plus ONE `createEffect(() => global(), v => setBridged(v))` scheduled at `tickEnd` and parked while a non-blocking heavy animation runs on the scope chain (its own schedule, so `forceOnHeavyAnimation` can release a parked run). A container is `createMemo(() => mapStateToProps(bridged(), props), { equals: shallowEqual })` — own-prop changes recompute it immediately (tracked getters, no gate), global changes arrive through the bridge (gated) — exposed to the component as a Proxy of per-key lazy memos (`===`), own props winning. Actions run synchronously in a serialized queue, exactly as in `teactn.tsx`. Controlled inputs cannot be bound to container props (they lag by a tick and by any animation): `liveGlobal(selector)` is a tracked, ungated memo over the current global for that one purpose, and DEV reports a `use:value` fed from a container prop. Task 1 makes the DOM runtime read structure and call DOM methods through prototype natives, so a `<form>` row or container whose descendant is named `remove`/`insertBefore`/`parentNode`… cannot freeze a list or crash a render.

**Tech Stack:** TypeScript 7 (strict), pnpm, Vite 8 + vitest 5 + jsdom 30, oxlint; `@solidjs/babel-plugin@2.0.0-rc.14` through `frameact/vite` for the one `.tsx` test. No new dependencies.

## Scope decisions

Facts established while writing this plan. **Every code block below was run in a scratch copy of the worktree** (`pnpm check` green at the end of every task: 770 → 776 → 782 → 792 → 805 → 812 tests, oxlint 0 warnings, tsc 0 errors); the micro-benchmark numbers are from that run (jsdom, Apple Silicon, `--no-file-parallelism`).

1. **DOM clobbering (Task 1) — natives unconditionally, not "only for forms".** `HTMLFormElement` has `[LegacyOverrideBuiltIns]`: a descendant control with `name="X"` or any descendant with `id="X"` (an `<img id>`) shadows the form's own property `X`, built-ins included. Checking "is the parent a form" on every call costs about as much as the `.call` itself and leaves the row case (`n.remove()` on a row that *is* a form) uncovered, so `src/dom/natives.ts` grows to the full set — getters `parentNode`/`firstChild`/`nextSibling`/`nodeType`/`nodeName`/`ownerDocument`/`localName`/`namespaceURI`, the `textContent` setter, `insertBefore`/`appendChild`/`replaceChild`/`removeChild`, `setAttribute`/`removeAttribute` (+NS) — and `reconcile.ts`, `insert.ts`, `render.ts`, `flow.ts` (Portal), `props.ts`, `attributes.ts` call them with `.call(node, …)`. `n.remove()` becomes `removeChild.call(parent, n)` (`ownedBy` has just confirmed the parent, and `Element.prototype.remove` would be the wrong brand for Text rows). *Not* covered, fail-closed (that one binding's effect logs an error, nothing else is affected): `classList`, `style`, `addEventListener`, `value`, `data` of a form whose descendant takes exactly that name. L3 from the appsec review: in the delegation walk a handler whose bound data (`_$$<event>Data`) is a Node / RadioNodeList / HTMLCollection *on a form* is skipped with a DEV error (the real data could never be a form's named property), a non-callable handler on a form is reported too, and `addEvent`'s expando writes are wrapped in `try` (the named property is non-writable: the assignment throws in strict mode). jsdom does not implement form named properties: tests define the same descriptor by hand (`test/helpers/clobber.ts`); a headless-Chrome check is described as an optional manual step. Micro-benchmarks (`bench/dom`, median of 7 batches, 1000 rows, µs/op) before → after: `manual-order[manual]` 46.1 → 46.0, `manual-order[keyed-fn]` 11.7 → 11.3 (both fast paths never reach the reconciler), `reconcile[edit-1]` 16.5 → 17.5, `reconcile[remove-1-add-1]` 249 → 265, `reconcile[swap-2]` 107 → 121 (the prefix scan calls `ownedBy` once per kept row), `reconcile[prepend-5-drop-5]` 297 → 316, `spread-toggle` 2.51 → 2.60 ms. Within the brief ("1 of 1000 changed" ≈ 11 µs, manual fast path ≈ 45 µs kept); in a real DOM the operations themselves dominate. Existing tests that spied on instance methods (`vi.spyOn(ul, 'insertBefore')`) switch to `spyNodeOps(ul, …)`, which wraps the cached natives and records calls whose receiver is `ul`.

2. **Controlled inputs bound to store state — the design question from the brief.** The `use:value` check compares the DOM with the authoritative value synchronously in the `input` event (accessor form) or in the mutate phase after the delivering compiler effect is clean (plain form). A value that comes through a container prop is **bridged**: it reaches the memo chain at tickEnd (a microtask *after* the synchronous check — in a jsdom test and under `dispatchEvent` there is no microtask checkpoint between listeners, and even in a browser the checkpoint cannot be relied on) and not at all while a non-blocking heavy animation runs on the container's scope (the bridge is parked, the compiler effect stays clean, so even the plain form's "wait for the dirty effect" rule does not help). So the accessor form would roll an accepted keystroke back always, and the plain form would roll it back during animations. Resolution, in three parts: **(a)** the store exports **`liveGlobal(selector, options?)`** = `createMemo(() => selector(global()))` — tracked, never gated, updated by the very `setGlobal` the action performs; a composer binds `const draft = liveGlobal(g => selectDraft(g, chatId))` and `<input use:value={draft} onInput={e => actions.setDraft(…)}>`: the action writes synchronously (the queue has no microtask hop), the check sees the write, an accepted keystroke stays, a rejected one is restored before paint, with or without animations (test in Task 6); **(b)** everything that is not an input keeps reading the store through `withGlobal`, so the animation gate is preserved; **(c)** a DEV guard: the container-props Proxy calls `markGatedRead()` (`src/dom/gated.ts`, new, DEV-only state) on every read, which remembers the effect whose compute/apply is running; the directives check whether the effect delivering to them (plain form) or their own compute (accessor form) was marked and print one `console.error` naming `liveGlobal`. It catches prop chains too (`<Composer draft={props.draft}/>`: the getter runs at read time). The plain form through a container prop still works without animations (the deferred check waits for the dirty compiler effect: no flicker) and is covered by a test that documents both that and the rollback during an animation. The spec gets a new §3.5 subsection "Контролируемые инпуты и стор" (Task 6).

3. **Outdated-global DEV check — a symbol stamp on the object, not a `WeakMap` (deviation from the spec text, spec updated in Task 6).** A new state is always a new object built by spread, so `WeakMap<object, epoch>` keyed by the object read would never see it: the check would never fire. Instead `getGlobal()` stamps the *current* object in place with an own, enumerable, symbol-keyed property holding the epoch: object spread copies it (`{ ...global, x }` carries the epoch of the global it was built from — what teact's `DEBUG_randomId` does), while `Object.keys`, `for…in`, `JSON.stringify` and `structuredClone` never see it (`shallowEqual` uses `Object.keys`). No copy is made, so reading never dirties the signal. `setGlobal` throws when the stamp differs from the current epoch (unless `forceOutdated`), then bumps the epoch and stamps the new global with it — deriving the next state from the object just set is allowed (teact refuses it; here it is the current state, so it is safe). The epoch is also bumped at tickEnd after a read, like teact's `throttleWithTickEnd` invalidation. A frozen object cannot be stamped and is not checked.

4. **Bridge lifetime and schedule.** A `HeavyAnimationScope` object has no lifecycle, so a bridge is reference-counted: every container (and every `addCallback`) acquires the bridge of its scope at creation and releases it in `onCleanup`; the last holder disposes the bridge (its effect stops following `global`) and the next container recreates it. Bridges live in a `Map<scope, bridge>` on the store (tests count them). The bridge uses its own `Schedule` (`tickEnd` + `firstAnimatingScope(effectScopeOf(node), false)` + the scope's `isAnimating.once`), not `gateOnHeavyAnimation(tickEnd)`: a run already parked on `once` must be releasable by a forced write (`setGlobal(next, { forceOnHeavyAnimation: true })` or `forceOnHeavyAnimationOnce()` + `setGlobal`), as teact's forced `runCallbacks` runs even while an earlier pass waits on `getIsHeavyAnimating.once`. The force flag is set before the signal write (effects notified by the write schedule past the gate) and consumed at the end of `setGlobal` (parked runs are released explicitly). `forceSyncOnIOs` delivers to every bridge inside `setGlobal`; the bridge remembers the delivered value, so the effect's later run is a no-op. Callbacks (`addCallback`) run from the root bridge's delivery (gated like containers, synchronous with `forceSyncOnIOs`), each isolated by try/catch. The creation-time run of a bridge effect is booked ungated (initial value): a `setGlobal` in the same tick as the first container's mount during an animation propagates once ungated — harmless, documented in the tests.

5. **Actions — ported as is, errors handled.** `handleAction`'s queue (`actionQueue.length === 1`, no shift before execution) and `execAfterActions` are ported verbatim, so a cascade is synchronous. Deviations are only in failure paths (teact would drop the rest of the queue and leave the promise pending): a throwing handler, a rejected async handler and a DEV outdated-global throw from `setGlobal(result)` are reported with `console.error`, the action's promise resolves, the queue continues. `execAfterActions` outside a cascade runs the callback at once with a DEV warning (teact would strand it until the next action). `getActions()` and `getPromiseActions()` return the same object; `Actions<P>` types a payload that may be `undefined` as optional.

6. **Container props — one Proxy, not `mergeProps`.** `mergeProps(() => getters, props)` would make `isOwnProp` → `getOwnPropertyDescriptor` read `mapped()` *tracked* on every prop access, subscribing a binding on `isSelected` to the whole mapped object and defeating the per-key isolation the spec requires. `containerProps(mapped, own, owner)` is a single Proxy: `get` returns the own prop when defined (teact: `{...mapped, ...props}` — own props win; an own `undefined` falls through to mapped, as in `mergeProps`), else a per-key memo `createMemo(() => mapped()[key])` created on first access **under the container's owner** (`runWithOwner`, not the binding effect that happened to read first) — a key that is in neither still gets a memo (undefined), which keeps a key that appears later reactive; `has`/`getOwnPropertyDescriptor` read `mapped` untracked; `ownKeys` reads it tracked (a spread of the container's props onto an element follows the key set). `withGlobal(mapState?, activationFn?)(Component)` returns a `Container` named `withGlobal(<Component>)` in DEV. `activationFn`/`stickToFirst` keep teact's truthiness semantics. A throwing `mapStateToProps` is reported through the owner's `onError` chain (else the console), the last props are kept and the memo itself never errors. teact's "empty mapped props never update" quirk is not reproduced; its DEV NaN warning is.

7. **`createGlobalStore<G, P>(initialState)`** takes the initial state (the spec's signature has no argument; teact starts from `{ isInited: false }` and Telegram sets `INITIAL_STATE` right away). Each call is an independent instance (teact's `typify` + module state in one). Not included: teact's DEV `window.getGlobal`/`setGlobal` globals and the `dblclick` container dump (`DEBUG_updates`); store selectors by path (spec §6).

8. **"Slow containers update" (DEV).** Containers are lazy memos, so a bridge delivery itself does no work; the bridge arms a `requestMutation` report *after* its signal write (so the report follows the mutate drain the write armed) and every container memo adds its `mapStateToProps` time to the store's accumulator; the report warns when the total exceeds 7 ms (teact's threshold) with the sum and the number of calls.

9. **Core touch-ups:** `src/core/effects.ts` gains `effectScopeOf(node)` (Task 4). `src/dom` gains `gated.ts` (Task 5) and the two DEV checks in `controlled.ts` (Task 6). Nothing else outside `src/store` changes after Task 1.

10. **Tests** are plain `.ts` calling the runtime as the compiler emits it (`createComponent(Container, { get id() {…} })`, `setAttribute(input, 'use:value', accessor)`, `effect(...)` for the plain form); one `.tsx` test (Task 5) covers `withGlobal` with JSX compiled by `frameact/vite`. /**
```ts
 * Simulate what a browser does to a `<form>` with a descendant named `name` (`<input name>` or any
 * `<img id>`): jsdom does not implement form named properties, so the test defines what
 * `[LegacyOverrideBuiltIns]` presents — an own, non-writable, non-enumerable data property (an
 * assignment to it throws in strict mode).
 */
export function clobber(form: HTMLFormElement, name: string, value: unknown = document.createElement('img')): void {
  Object.defineProperty(form, name, { value, writable: false, enumerable: false, configurable: true });
}

/** A `<form>` whose listed built-ins are all shadowed by one `<img>` child. */
export function clobberedForm(...names: string[]): HTMLFormElement {
  const form = document.createElement('form');
  const img = document.createElement('img');
  form.appendChild(img);
  for (const name of names) clobber(form, name, img);
  return form;
}
```

```ts
type NodeOp = 'insertBefore' | 'appendChild' | 'replaceChild' | 'removeChild';

/**
 * Spies on the DOM writes the runtime makes on `parent`. The runtime calls the prototype natives
 * (`Node.prototype.insertBefore.call(parent, …)`, see `src/dom/natives.ts`), so an instance spy
 * (`vi.spyOn(parent, 'insertBefore')`) never fires; this wraps the cached natives and records only
 * the calls whose receiver is `parent`. Restored by `vi.restoreAllMocks()`.
 */
export function spyNodeOps<M extends NodeOp>(parent: Node, ...methods: M[]): Record<M, ReturnType<typeof vi.fn>> {
  const natives = getNatives() as unknown as Record<string, (...args: unknown[]) => unknown>;
  const out = {} as Record<M, ReturnType<typeof vi.fn>>;
  for (const method of methods) {
    const recorder = vi.fn();
    const original = natives[method];
    vi.spyOn(natives, method).mockImplementation(function (this: Node, ...args: unknown[]) {
      if (this === parent) recorder(...args);
      return original.apply(this, args);
    });
    out[method] = recorder;
  }
  return out;
}
```

```ts
// Reconciler hot paths on 1000 rows (`For keyed={fn}`), after the prototype-natives change (Task 1 of
// plan 3): structural edits that go through reconcileArrays, plus the "1 of 1000 changed" fast path
// that never reaches it. Cost per op = signal write + flushSync (jsdom DOM, no layout).
import { createRoot, createSignal, flushSync, untrack } from '../../src/index';
import { insert } from '../../src/dom/insert';
import { createComponent } from '../../src/dom/component';
import { For } from '../../src/dom/list';

type Row = { id: number; text: string };
const N = 1000;

function median(xs: number[]) {
  return [...xs].sort((a, b) => a - b)[xs.length >> 1];
}

function mount() {
  const ul = document.createElement('ul');
  document.body.appendChild(ul);
  const [list, setList] = createSignal<Row[]>(Array.from({ length: N }, (_, i) => ({ id: i, text: `t${i}` })));
  createRoot(() =>
    insert(
      ul,
      createComponent(() =>
        For({
          get each() { return list(); },
          keyed: (r: Row) => r.id,
          children: (item: () => Row) => {
            const li = document.createElement('li');
            insert(li, () => item().text);
            return li;
          },
        }), {}),
    ),
  );
  flushSync();
  return { list, setList };
}

let nextId = N;

const scenarios: Record<string, (list: () => Row[], setList: (v: Row[]) => void, k: number) => void> = {
  'edit-1': (list, setList, k) => {
    const next = untrack(list).slice();
    next[(k * 37) % N] = { id: (k * 37) % N, text: `e${k}` };
    setList(next);
  },
  'remove-1-add-1': (list, setList) => {
    const next = untrack(list).slice(1);
    next.push({ id: nextId++, text: 'new' });
    setList(next);
  },
  'swap-2': (list, setList, k) => {
    const next = untrack(list).slice();
    const i = (k * 37) % (N - 1);
    [next[i], next[i + 1]] = [next[i + 1], next[i]];
    setList(next);
  },
  'prepend-5-drop-5': (list, setList) => {
    const prev = untrack(list);
    const fresh = Array.from({ length: 5 }, () => ({ id: nextId++, text: 'p' }));
    setList([...fresh, ...prev.slice(0, N - 5)]);
  },
};

it('reconcile: structural edits on 1000 keyed rows', () => {
  for (const [name, step] of Object.entries(scenarios)) {
    const { list, setList } = mount();
    const run = (k: number) => {
      step(list, setList, k);
      flushSync();
    };
    for (let k = 0; k < 200; k++) run(k); // warm up
    const batches: number[] = [];
    let k = 200;
    for (let b = 0; b < 7; b++) {
      const t0 = performance.now();
      for (let i = 0; i < 300; i++) run(k++);
```

```ts
// DOM clobbering. `HTMLFormElement` has `[LegacyOverrideBuiltIns]`: a descendant form control with
// `name="X"` or ANY descendant with `id="X"` (an `<img id>`) shadows the form's own property `X`, built-ins
// included: `form.parentNode` is then the control, `form.remove` / `form.insertBefore` are not functions,
// `form.nodeName` is an element. Content-derived names and ids inside a form (an emoji id, a file name,
// a poll option) would let a message freeze a list or crash a render. So the runtime reads structure
// and calls the DOM methods it depends on through the prototype natives below, cached on first use
// (`.call(node, …)`: the same monomorphic call V8 makes for `node.method(…)`).
//
// Covered: structure getters, insertion/removal, identity getters, `textContent`, the attribute
// methods. Not covered (fail closed, the one binding's effect logs an error and nothing else is
// affected): `classList`, `style`, `addEventListener`, `value`, `data` and other per-feature APIs of a
// form whose descendant takes that exact name.
export interface Natives {
  parentNode: (this: Node) => Node | null;
  firstChild: (this: Node) => ChildNode | null;
  nextSibling: (this: Node) => ChildNode | null;
  nodeType: (this: Node) => number;
  /** Upper-case for HTML elements (`'FORM'`), the same as `tagName` there. */
  nodeName: (this: Node) => string;
  ownerDocument: (this: Node) => Document | null;
  localName: (this: Element) => string;
  namespaceURI: (this: Element) => string | null;
  /** `Node.prototype.textContent` setter. */
  setTextContent: (this: Node, text: string | null) => void;
  insertBefore: <T extends Node>(this: Node, node: T, child: Node | null) => T;
  appendChild: <T extends Node>(this: Node, node: T) => T;
  replaceChild: <T extends Node>(this: Node, node: Node, child: T) => T;
  removeChild: <T extends Node>(this: Node, child: T) => T;
  contains: (this: Node, other: Node | null) => boolean;
  shadowHost: (this: ShadowRoot) => Element;
  setAttribute: (this: Element, name: string, value: string) => void;
  removeAttribute: (this: Element, name: string) => void;
  setAttributeNS: (this: Element, namespace: string | null, name: string, value: string) => void;
  removeAttributeNS: (this: Element, namespace: string | null, localName: string) => void;
  /** `HTMLFormElement.prototype.elements` (`<input name="elements">` shadows `form.elements`). */
  formElements: (this: HTMLFormElement) => HTMLFormControlsCollection;
  /** `querySelectorAll` of a document / shadow root / element (a form named `querySelectorAll` shadows it on `document`). */
  querySelectorAll: {
    document: Document['querySelectorAll'];
    fragment: DocumentFragment['querySelectorAll'];
    element: Element['querySelectorAll'];
  };
}

let natives: Natives | undefined;

function getter<T extends object>(proto: T, name: string): (this: T) => any {
  return Object.getOwnPropertyDescriptor(proto, name)!.get!;
}

export function getNatives(): Natives {
  return (natives ??= {
    parentNode: getter(Node.prototype, 'parentNode'),
    firstChild: getter(Node.prototype, 'firstChild'),
    nextSibling: getter(Node.prototype, 'nextSibling'),
    nodeType: getter(Node.prototype, 'nodeType'),
    nodeName: getter(Node.prototype, 'nodeName'),
    ownerDocument: getter(Node.prototype, 'ownerDocument'),
    localName: getter(Element.prototype, 'localName'),
    namespaceURI: getter(Element.prototype, 'namespaceURI'),
    setTextContent: Object.getOwnPropertyDescriptor(Node.prototype, 'textContent')!.set!,
    insertBefore: Node.prototype.insertBefore,
    appendChild: Node.prototype.appendChild,
    replaceChild: Node.prototype.replaceChild,
    removeChild: Node.prototype.removeChild,
    contains: Node.prototype.contains,
    shadowHost: getter(ShadowRoot.prototype, 'host'),
    setAttribute: Element.prototype.setAttribute,
    removeAttribute: Element.prototype.removeAttribute,
    setAttributeNS: Element.prototype.setAttributeNS,
    removeAttributeNS: Element.prototype.removeAttributeNS,
    formElements: getter(HTMLFormElement.prototype, 'elements'),
    querySelectorAll: {
      document: Document.prototype.querySelectorAll,
      fragment: DocumentFragment.prototype.querySelectorAll,
      element: Element.prototype.querySelectorAll,
    },
  });
}
```

```ts
// Adapted from solidjs/solid packages/web/src/reconcile.ts (MIT, © 2016-2025 Ryan Carniato),
// itself a modified https://github.com/WebReflection/udomdiff (ISC, © 2020 Andrea Giammarchi).
// frameact: structure is read and written through the prototype natives (natives.ts): a row that is
// a <form> with a descendant named `remove`, `parentNode` or `nextSibling` must not break the diff.
import { getNatives } from './natives';

/** Nodes inserted under a marker are tagged with it: a node that migrated to another slot of the same parent is not ours. */
export const SLOT: unique symbol = Symbol('frameact.slot');

/**
 * Tag a node with the slot that inserted it: its marker, or `null` for the last slot (and for root
 * mode). Always written, so a node that migrates between slots never keeps a stale tag.
 */
export function tagSlot(n: any, marker: Node | null | undefined): void {
  n[SLOT] = marker ?? null;
}

/** `undefined` tag = never inserted by a slot (static template nodes): owned by whoever holds it. */
export function ownedBy(n: any, parentNode: any, marker: any): boolean {
  if (!n || getNatives().parentNode.call(n) !== parentNode) return false;
  const tag = n[SLOT];
  return tag === undefined || tag === (marker ?? null);
}

/** Diff `a` (current nodes) → `b` (next nodes) inside `parentNode`, minimal moves. `a` must be non-empty. */
export function reconcileArrays(parentNode: any, a: any[], b: any[], marker?: Node | null): void {
  const { nextSibling, insertBefore, replaceChild, removeChild } = getNatives();
  const bLength = b.length;
  let aEnd = a.length,
    bEnd = bLength,
    aStart = 0,
    bStart = 0,
    map: Map<any, number> | null = null;
  const tail = a[aEnd - 1];
  const after = ownedBy(tail, parentNode, marker) ? nextSibling.call(tail) : marker || null;

  while (aStart < aEnd || bStart < bEnd) {
    // common prefix
    if (a[aStart] === b[bStart] && ownedBy(a[aStart], parentNode, marker)) {
      aStart++;
      bStart++;
      continue;
    }
    // common suffix
    while (a[aEnd - 1] === b[bEnd - 1] && ownedBy(a[aEnd - 1], parentNode, marker)) {
      aEnd--;
      bEnd--;
    }
    if (aEnd === aStart) {
      // append
      let node: any;
      if (bEnd < bLength) {
        if (bStart) {
          const prev = b[bStart - 1];
          node = ownedBy(prev, parentNode, marker) ? nextSibling.call(prev) : after;
        } else node = b[bEnd - bStart];
      } else node = after;
      while (bStart < bEnd) {
        const n = b[bStart++];
        insertBefore.call(parentNode, n, node);
        tagSlot(n, marker);
      }
    } else if (bEnd === bStart) {
      // remove
      while (aStart < aEnd) {
        const n = a[aStart++];
        if ((!map || !map.has(n)) && ownedBy(n, parentNode, marker)) removeChild.call(parentNode, n);
      }
    } else if (a[aStart] === b[bEnd - 1] && b[bStart] === a[aEnd - 1] && ownedBy(a[aStart], parentNode, marker)) {
      // swap backward: walk inward with a stable front anchor
      const anchor = a[aStart];
      do {
        const n = a[--aEnd];
        insertBefore.call(parentNode, n, anchor);
        tagSlot(n, marker);
        bStart++;
        if (aStart >= aEnd - 1 || bStart >= bEnd) break;
      } while (a[aStart] === b[bEnd - 1] && b[bStart] === a[aEnd - 1]);
    } else {
      // fallback to map
      if (!map) {
        map = new Map();
        let i = bStart;
        while (i < bEnd) map.set(b[i], i++);
      }
      const index = map.get(a[aStart]);
      if (index != null) {
        if (bStart < index && index < bEnd) {
          let i = aStart,
            sequence = 1,
            t: number | undefined;
          while (++i < aEnd && i < bEnd) {
            if ((t = map.get(a[i])) == null || t !== index + sequence) break;
            sequence++;
          }
          if (sequence > index - bStart) {
            const head = a[aStart];
            const node = ownedBy(head, parentNode, marker) ? head : after;
            while (bStart < index) {
              const n = b[bStart++];
              insertBefore.call(parentNode, n, node);
              tagSlot(n, marker);
            }
          } else {
            const oldNode = a[aStart++];
            const newNode = b[bStart++];
            if (ownedBy(oldNode, parentNode, marker)) replaceChild.call(parentNode, newNode, oldNode);
            else insertBefore.call(parentNode, newNode, after);
            tagSlot(newNode, marker);
          }
        } else aStart++;
      } else {
        const n = a[aStart++];
        if (ownedBy(n, parentNode, marker)) removeChild.call(parentNode, n);
      }
    }
  }
}

/**
 * Marks a node array as manually ordered (`For order="manual"`): `insertExpression` then applies it with
 * `reconcileManual` (insert-only) instead of `reconcileArrays`. The value is the set of rows that must
 * be (re)inserted at their array position even though they are already in the DOM (changed `orderKey`).
 * A non-enumerable symbol property, so it is invisible to spreads and `Object.keys`.
 */
export const MANUAL_ORDER: unique symbol = Symbol('frameact.manualOrder');

export function tagManualOrder(array: any[], moved: ReadonlySet<unknown>): void {
  Object.defineProperty(array, MANUAL_ORDER, { value: moved, configurable: true });
}

/** The set of rows to move if `array` is tagged as manually ordered. */
export function manualOrderOf(array: any[]): ReadonlySet<unknown> | undefined {
  return (array as any)[MANUAL_ORDER];
}

/**
 * Insert-only counterpart of `reconcileArrays`. `next` lists the slot's nodes in DOM order, except
 * for new nodes (placed at their list index) and the `moved` ones. Kept, unmoved nodes are never
 * touched (no `remove`, `replaceChild` or `insertBefore`); a contiguous run of nodes to insert goes
 * before one anchor (the next kept node, else the marker); a `moved` node is moved exactly once.
 * `prev` must be non-empty. A kept node that is out of DOM order despite not being listed in `moved`
 * (the memo ran ahead of the applied DOM) is moved too: correctness first.
 */
export function reconcileManual(
  parentNode: any,
  prev: any[],
  next: any[],
  marker: Node | null | undefined,
  moved: ReadonlySet<unknown>,
): void {
  const { insertBefore, removeChild } = getNatives();
  const nextSet = new Set<any>(next);
  const prevIndex = new Map<any, number>();
  for (let i = 0; i < prev.length; i++) {
    const n = prev[i];
    if (!nextSet.has(n)) {
      if (ownedBy(n, parentNode, marker)) removeChild.call(parentNode, n);
    } else if (ownedBy(n, parentNode, marker)) prevIndex.set(n, i);
  }
  // Stable nodes: already in the DOM, not moved, in increasing DOM order. Walking backwards gives
  // every position the anchor to insert before.
  // The `at > last` test is the safety branch for a `next` that is not in DOM order (the memo ran
  // ahead of the applied DOM): theoretical for `For`, and greedy, not an LIS, so it may move more
  // nodes than the minimum. `moved` carries the intended moves.
  const length = next.length;
  const stable: boolean[] = [];
  let last = -1;
  for (let i = 0; i < length; i++) {
    const n = next[i];
    const at = prevIndex.get(n);
    stable[i] = at !== undefined && at > last && !moved.has(n);
    if (stable[i]) last = at!;
  }
  const anchors: (Node | null)[] = [];
  let anchor: Node | null = marker ?? null;
  for (let i = length - 1; i >= 0; i--) {
```

```ts
// Adapted from solidjs/solid packages/web/src/client.ts (MIT, © 2016-2025 Ryan Carniato) and
// dom-expressions packages/dom-expressions/src/client.js (MIT, © 2018-2019 Ryan Carniato).
// frameact: `insert` is a two-phase render effect — compute = normalize (pure; creates subtrees on
// detached DOM), apply = insertExpression (the DOM write: synchronous at creation, mutate phase later).
// Structure is read and written through the prototype natives (natives.ts): a parent or a child that
// is a <form> with a descendant named `insertBefore`, `firstChild`, `textContent`… must not break a slot.
import { DEV } from '../env';
import { createRenderEffect } from '../core/frame';
import type { EffectOptions } from '../core/effects';
import { getNatives } from './natives';
import { manualOrderOf, ownedBy, reconcileArrays, reconcileManual, tagManualOrder, tagSlot } from './reconcile';

// No `Document`: lib.dom types its `textContent` as a read-only `null`, and mounting into a Document is meaningless anyway.
export type MountableElement = Element | ShadowRoot | DocumentFragment;

export interface InsertOptions {
  /** Portal: the slot's logical host. Inserted top-level nodes are registered for event retargeting (`portalHostOf`). */
  host?: () => Node | null;
  /** Dev label from the compiler's sourceNames (`div.children`). */
  name?: string;
}

/** Returned by the outer insert compute when a nested effect owns the slot (its apply then does nothing). */
const INNER_OWNED: unique symbol = Symbol('frameact.innerOwned');
/** Text nodes created by this module. Only these are reused as positional text slots; a Text node handed in by the user is a plain node. */
const ownText = new WeakSet<Text>();

function createOwnText(data: string): Text {
  const node = document.createTextNode(data);
  ownText.add(node);
  return node;
}

/**
 * Resolve nested accessors and arrays. Functions with parameters (row mappers) are values, not
 * accessors. `doNotUnwrap`: keep a top-level function (and any function inside an array — the
 * array then resolves to a wrapper function) so the caller can give it its own effect.
 */
export function flatten(children: any, skipNonRendered: boolean, doNotUnwrap: boolean): any {
  if (typeof children === 'function' && !children.length) {
    if (doNotUnwrap) return children;
    do children = children();
    while (typeof children === 'function' && !children.length);
  }
  if (skipNonRendered && (children == null || children === true || children === false || children === '')) {
    return undefined;
  }
  if (Array.isArray(children)) {
    const results: any[] = [];
    // The copy keeps the manual-order tag (`For order="manual"`); a For nested inside a larger array
    // is flattened into it and loses the tag: it then falls back to the ordinary reconcile.
    const manual = manualOrderOf(children);
    if (manual) tagManualOrder(results, manual);
    if (flattenArray(children, results, skipNonRendered, doNotUnwrap)) {
      return () => {
        const nested: any[] = [];
        flattenArray(results, nested, skipNonRendered, false);
        return nested;
      };
    }
    return results;
  }
  return children;
}

let warnedNestedManual = false;

function flattenArray(children: any[], results: any[], skipNonRendered: boolean, doNotUnwrap: boolean): boolean {
  let needsUnwrap = false;
  for (let i = 0; i < children.length; i++) {
    let child = children[i];
    if (typeof child === 'function' && !child.length) {
      if (doNotUnwrap) {
        results.push(child);
        needsUnwrap = true;
        continue;
      }
      do child = child();
      while (typeof child === 'function' && !child.length);
    }
    if (Array.isArray(child)) {
      if (DEV && !warnedNestedManual && manualOrderOf(child)) {
        warnedNestedManual = true;
        console.warn('[frameact] <For order="manual"> nested in a larger array loses its manual order (it needs its own slot); the ordinary diff is used');
      }
      needsUnwrap = flattenArray(child, results, skipNonRendered, doNotUnwrap) || needsUnwrap;
    } else if (skipNonRendered && (child == null || child === true || child === false || child === '')) {
      // not rendered
    } else results.push(child);
  }
  return needsUnwrap;
}

/** Compute-half value shape: primitives stay raw (text nodes are materialised in the apply, reusing positional ones). */
export function normalize(value: any, multi: boolean, doNotUnwrap: boolean): any {
  value = flatten(value, true, doNotUnwrap);
  // Only a zero-parameter function is an accessor that gets its own effect. A function with parameters
  // (a row mapper) is a value: it falls through to insertExpression, which renders it as nothing.
  if (doNotUnwrap && typeof value === 'function' && !value.length) return value;
  if (multi && !Array.isArray(value)) value = [value != null ? value : ''];
  return value;
}

/**
 * Compiler primitive. `marker === undefined`: the hole is the element's only content (root mode:
 * textContent fast path). `marker` a node or `null`: multi mode, content lives before the marker
 * (`null` = at the end).
 */
export function insert(
  parent: MountableElement,
  accessor: unknown,
  marker?: Node | null,
  initial?: unknown,
  options?: InsertOptions,
): void {
  const multi = marker !== undefined;
  const host = options?.host && { parent, host: options.host };
  if (multi && !initial) initial = [];
  if (typeof accessor !== 'function' || (accessor as (...args: unknown[]) => unknown).length) {
    const value = normalize(accessor, multi, true);
    if (typeof value !== 'function' || value.length) {
      const inserted = insertExpression(parent, value, initial, marker);
      if (host) tagHost(inserted, host);
      return;
    }
    accessor = value;
  }
  if (multi && (initial as unknown[]).length === 0) {
    const placeholder = createOwnText('');
    getNatives().insertBefore.call(parent, placeholder, marker ?? null);
    initial = [placeholder];
  }
  let current: any = initial;
  const effectOptions: EffectOptions | undefined = options?.name === undefined ? undefined : { name: options.name };
  const read = accessor as () => unknown;
  createRenderEffect<any>(
    () => {
      const value = normalize(read(), multi, true);
      if (typeof value !== 'function') return value;
      // A function value (a For's row accessor, a memo, a fragment holding one) gets its own effect:
      // the outer tracks only what produced the function. Owned by this compute → disposed when the
      // outer recomputes.
      createRenderEffect<any>(
        () => normalize(value, multi, false),
        (inner) => {
          current = insertExpression(parent, inner, current, marker);
          if (host) tagHost(current, host);
        },
        effectOptions,
      );
      return INNER_OWNED;
    },
    (value) => {
      if (value === INNER_OWNED) return;
      current = insertExpression(parent, value, current, marker);
      if (host) tagHost(current, host);
    },
    effectOptions,
  );
}

/**
 * Apply half: write `value` into the slot described by `current`, return the new `current`.
 * Note: when `value` is an array it is mutated in place (primitives and non-renderables are replaced
 * by text nodes). `insert` always passes a fresh copy (see `flatten`); direct callers must too.
 */
export function insertExpression(parent: MountableElement, value: any, current: any, marker?: Node | null): any {
  if (value === current) return value;
  const { firstChild, nodeType, parentNode, insertBefore, replaceChild, removeChild, setTextContent } = getNatives();
  const t = typeof value;
  const multi = marker !== undefined;

  if (t === 'string' || t === 'number') {
    const text = String(value);
    if (multi) {
      // Direct callers only: insert() wraps primitives into an array in multi mode.
      let node = Array.isArray(current) ? current[0] : undefined;
      if (node && ownText.has(node)) {
        if (node.data !== text) node.data = text;
      } else node = createOwnText(text);
      return cleanChildren(parent, current, marker, node);
    }
    const tc = typeof current;
    const first = firstChild.call(parent);
    if ((tc === 'string' || tc === 'number') && current !== '' && first && nodeType.call(first) === 3) {
      (first as Text).data = text;
    } else setTextContent.call(parent, text);
    return value;
  }
  if (value == null || t === 'boolean') return cleanChildren(parent, current, marker);
  if (t === 'function') {
    if (value.length) {
      // Same as an array item: a row mapper is not renderable. Renders as nothing, old content cleared.
      if (DEV) console.warn('[frameact] Unrecognized child value. Rendered as nothing', value);
      return cleanChildren(parent, current, marker);
    }
    if (DEV) console.error('[frameact] insertExpression: unexpected function value (normalize first)', value);
    return current;
  }
  if (Array.isArray(value)) {
    const currentArray = Array.isArray(current);
    for (let i = 0; i < value.length; i++) {
      const item = value[i];
      const ti = typeof item;
      if (ti === 'string' || ti === 'number') {
        const text = String(item);
        const prev = currentArray ? current[i] : undefined;
        if (prev && ownText.has(prev)) {
          if (prev.data !== text) prev.data = text;
          value[i] = prev;
        } else value[i] = createOwnText(text);
      } else if (item == null || !item.nodeType) {
        // Not renderable: a function with parameters (a row mapper is a value, not an accessor), a plain
        // object, a stray null. Placing it into the DOM would throw `insertBefore: not of type Node`, so it
        // renders as nothing (Solid 2.0's client.ts has no such guard and throws).
        if (DEV) console.warn('[frameact] Unrecognized child value. Rendered as nothing', item);
        value[i] = createOwnText('');
      }
    }
    if (value.length === 0) {
      cleanChildren(parent, current, marker);
    } else if (currentArray) {
      if (current.length === 0) appendNodes(parent, value, marker ?? null);
      else {
        const manual = manualOrderOf(value);
        if (manual) reconcileManual(parent, current, value, marker, manual);
        else reconcileArrays(parent, current, value, marker);
      }
    } else {
      if (current != null && current !== '') {
        if (!multi) setTextContent.call(parent, '');
        else if (current.nodeType && parentNode.call(current) === parent) removeChild.call(parent, current);
      }
      appendNodes(parent, value, marker ?? null);
    }
    return value;
  }
  if (value.nodeType) {
    if (Array.isArray(current)) {
      cleanChildren(parent, current, multi ? marker : null, value);
    } else if (current != null && current.nodeType) {
      if (parentNode.call(current) === parent) replaceChild.call(parent, value, current);
      else insertBefore.call(parent, value, marker ?? null);
    } else if (current != null && current !== '' && firstChild.call(parent)) {
      // a sole text child holds the previous primitive (`0`/`NaN` are falsy, hence `!= null`)
      replaceChild.call(parent, value, firstChild.call(parent)!);
    } else insertBefore.call(parent, value, marker ?? null);
    tagSlot(value, marker);
    return value;
  }
  if (DEV) console.warn('[frameact] Unrecognized value. Skipped inserting', value);
  return current;
}

/** Remove the slot's nodes (optionally replacing them with one node). Returns the new `current`. */
function cleanChildren(parent: MountableElement, current: any, marker?: Node | null, replacement?: any): any {
  const { insertBefore, replaceChild, removeChild, appendChild, setTextContent } = getNatives();
  if (marker === undefined) {
    setTextContent.call(parent, '');
    if (replacement) {
      appendChild.call(parent, replacement);
      tagSlot(replacement, marker);
    }
    return replacement ?? '';
  }
  const list: any[] = Array.isArray(current) ? current : current != null && current !== '' ? [current] : [];
  if (list.length) {
    let inserted = false;
    for (let i = list.length - 1; i >= 0; i--) {
      const el = list[i];
      if (replacement !== el) {
        const owns = ownedBy(el, parent, marker);
        if (replacement && !inserted && !i) {
          if (owns) replaceChild.call(parent, replacement, el);
          else insertBefore.call(parent, replacement, marker);
        } else if (owns) removeChild.call(parent, el);
      } else inserted = true;
    }
  } else if (replacement) insertBefore.call(parent, replacement, marker);
  if (replacement) tagSlot(replacement, marker);
  return replacement ? [replacement] : [];
}

function appendNodes(parent: MountableElement, array: any[], marker: Node | null): void {
  const { insertBefore } = getNatives();
  for (let i = 0; i < array.length; i++) {
    const n = array[i];
    insertBefore.call(parent, n, marker);
    tagSlot(n, marker);
  }
}

  parent: MountableElement;
  host: () => Node | null;
}

/** Portal content node -> its insert call's tag. A WeakMap, not a property: nothing on the node can clobber or throw. */
const portalHosts = new WeakMap<Node, HostTag>();

/**
 * The logical parent of a portal's top-level content node, or null. Reported only while the node's
 * native `parentNode` (prototype getter: a `<form>` control named `parentNode` shadows the property) is
 * that insert's mount, so a node moved out of the portal, or removed, stops reporting the old host.
 * Limitation: a node moved by hand elsewhere under the SAME mount (the default, `document.body`) keeps
 * its host; only leaving the mount is detected.
 */
export function portalHostOf(node: Node): Node | null {
  const tag = portalHosts.get(node);
  return tag !== undefined && getNatives().parentNode.call(node) === tag.parent ? tag.host() : null;
}

/**

 * `parent` (default: its current native parent).
 */
export function tagPortalHost(
  node: Node,
  host: () => Node | null,
  parent: MountableElement = getNatives().parentNode.call(node) as MountableElement,
): void {
  portalHosts.set(node, { parent, host });
}

/** Portal content: top-level nodes learn their logical host (delegated events bubble through it). */

    for (let i = 0; i < value.length; i++) tagHost(value[i], tag);
  } else if (value && value.nodeType && portalHosts.get(value) !== tag) portalHosts.set(value, tag);
}
```

```ts
/**
 * Mount `code()` into `element` (appended after existing children). Synchronous: the root insert's
 * first apply runs at creation; the write into an attached container goes through the stricterdom
 * seam.
 *
 * The returned disposer depends on the container at mount time. Empty container: root mode (the
 * `textContent` fast path), and the disposer clears the WHOLE container. Non-empty container: render
 * brackets its nodes with its own pair of empty text markers and the disposer removes only what is
 * between them (plus the markers), leaving pre-existing and later-appended siblings alone.
 * The container is read and written through the prototype natives: a `<form>` container with a
 * descendant named `firstChild`, `append` or `textContent` mounts and unmounts like any element.
 */
export function render(code: () => unknown, element: MountableElement, init?: unknown): () => void {
  if (DEV && !element) {
    throw new Error("[frameact] render(): the container element doesn't exist. Make sure it is in the document.");
  }
  const { firstChild, nextSibling, parentNode, appendChild, removeChild, setTextContent } = getNatives();
  let disposer!: () => void;
  const bounded = firstChild.call(element) !== null;
  const start = bounded ? document.createTextNode('') : null;
  const end = bounded ? document.createTextNode('') : null;
  strictHooks.forceMutation(() => {
    if (start && end) {
      appendChild.call(element, start);
      appendChild.call(element, end);
    }
    createRoot((dispose) => {
      disposer = dispose;
      insert(element, code(), end ?? undefined, init);
    });
  }, element);
  return () => {
    disposer();
    strictHooks.forceMutation(() => {
      if (!start || !end) {
        setTextContent.call(element, '');
        return;
      }
      if (parentNode.call(start) === element) {
        if (parentNode.call(end) === element) {
          for (let n = nextSibling.call(start); n && n !== end; ) {
            const next: ChildNode | null = nextSibling.call(n);
            removeChild.call(element, n);
            n = next;
          }
        } else if (DEV) {
          console.warn('[frameact] render(): the end marker is gone; only the start marker was removed.');
        }
      }
      start.remove();
      end.remove();
    }, element);
  };
}
```

```ts
// event delegation on `document`; handlers live on nodes under the compiler's `_$$<event>` keys.
import { DEV } from '../env';
import { portalHostOf } from './insert';
import { getNatives } from './natives';

/** Compiler contract: `el._$$click = handler`, `el._$$clickData = data` (accessed as strings: oxlint no-underscore-dangle). */
export const EVENT_KEY = '_$$';

const delegated = new WeakMap<Document, Set<string>>();
const clearHooks = new Set<(doc: Document) => void>();

/** Compiler primitive: attach one document listener per event type (idempotent). */
export function delegateEvents(eventNames: readonly string[], doc: Document = window.document): void {
  let names = delegated.get(doc);
  if (!names) delegated.set(doc, (names = new Set()));
  for (const name of eventNames) {
    if (!names.has(name)) {
      names.add(name);
      doc.addEventListener(name, eventHandler);
    }
  }
}

/** Tests/teardown: remove every delegated listener (and whatever registered through `onClearDelegated`). */
export function clearDelegatedEvents(doc: Document = window.document): void {
  const names = delegated.get(doc);
  if (names) {
    for (const name of names) doc.removeEventListener(name, eventHandler);
    delegated.delete(doc);
  }
  for (const hook of clearHooks) hook(doc);
}

/** Modules that add their own document listeners next to delegation (controlled inputs) clean up here. */
export function onClearDelegated(fn: (doc: Document) => void): void {
  clearHooks.add(fn);
}

/** A native listener or a listener object: the only things `addEventListener` accepts. */
function isListener(value: unknown): value is EventListenerOrEventListenerObject {
  return typeof value === 'function' || (typeof value === 'object' && value !== null && typeof (value as { handleEvent?: unknown }).handleEvent === 'function');
}

function refuseHandler(where: string, name: string, handler: unknown): void {
  if (DEV) console.error(`[frameact] ${where}${name}: the handler must be a function, a [fn, data] tuple or an object with handleEvent; got`, handler);
}

/** `[fn, data]` as a listener calling `fn.call(node, data, e)`; `undefined` when `fn` is not a function. The tuple is never written to (it may be shared). */
export function tupleListener(node: Element, tuple: readonly unknown[]): EventListener | undefined {
  const fn = tuple[0] as (data: unknown, e: Event) => void;
  const data = tuple[1];
  return typeof fn === 'function' ? (e: Event) => fn.call(node, data, e) : undefined;
}

/**
 * Write the two delegation expandos. On a `<form>` whose descendant is named `_$$click` the property is
 * a non-writable named property: the assignment throws in strict mode (DOM clobbering), which must not
 * cut the spread or the component short — reported in DEV, the handler is simply not attached.
 */
function setDelegated(node: Element, name: string, handler: unknown, data: unknown): void {
  const target = node as unknown as Record<string, unknown>;
  try {
    target[EVENT_KEY + name] = handler;
    target[EVENT_KEY + name + 'Data'] = data;
  } catch (error) {
    if (DEV) console.error(`[frameact] on${name}: could not store the delegated handler on`, node, '(a form control or <img id> named "' + EVENT_KEY + name + '" shadows it)', error);
  }
}

/** Compiler primitive: `addEvent(el, name, handler, delegate)`; tuple handlers carry bound data. */
export function addEvent(node: Element, name: string, handler: unknown, delegate?: boolean): void {
  if (delegate) {
    if (Array.isArray(handler)) {
      if (!isListener(handler[0])) return refuseHandler('onX=', name, handler);
      setDelegated(node, name, handler[0], handler[1]);
    } else {
      if (handler != null && !isListener(handler)) return refuseHandler('onX=', name, handler);
      setDelegated(node, name, handler, undefined); // a plain handler replaces a tuple's data
    }
    return;
  }
  if (Array.isArray(handler)) {
    const listener = tupleListener(node, handler);
    if (!listener) return refuseHandler('onX=', name, handler);
    node.addEventListener(name, listener);
  } else if (handler == null) {
    // nothing to attach
  } else if (isListener(handler)) {
    node.addEventListener(name, handler, typeof handler === 'function' ? undefined : (handler as AddEventListenerOptions));
  } else refuseHandler('onX=', name, handler);
}

const listeners = new WeakMap<Element, Map<string, EventListenerOrEventListenerObject>>();

/**
 * `on:name` / `oncapture:name`: a native listener per element and name, replaced or removed on update.
 * `slot` namespaces the key, so a second owner (a spread's `onX`) never displaces `on:name`.
 */
export function setListener(node: Element, name: string, value: unknown, capture: boolean, slot = ''): void {
  let map = listeners.get(node);
  const key = slot + (capture ? `c:${name}` : name);
  const prev = map?.get(key);
  if (prev) {
    node.removeEventListener(name, prev, capture || (typeof prev === 'function' ? undefined : (prev as EventListenerOptions)));
    map!.delete(key);
  }
  if (!value) return;
  if (!isListener(value)) return refuseHandler(capture ? 'oncapture:' : 'on:', name, value); // never stored: later updates stay valid
  if (!map) listeners.set(node, (map = new Map()));
  map.set(key, value);
  node.addEventListener(name, value, capture || (typeof value === 'function' ? undefined : (value as AddEventListenerOptions)));
}

// Structure is read through the prototype getters (natives.ts); portal hosts live in a WeakMap (insert.ts),
// so neither a named form control nor an expando can redirect the walk. Only the handler expandos
// (`_$$click`, `_$$clickData`) must be read off the node and are validated: on a <form> either may be a
// descendant named like the expando (`<img id="_$$keydownData">`): a handler that is not callable is
// skipped, and so is a handler whose bound data turns out to be a Node or a node collection on a form
// (the real data could never be a form's named property), instead of calling it with the wrong argument.
const MAX_PORTAL_HOPS = 64;

/** A value a form's named-property getter can produce: an element, or a RadioNodeList / HTMLCollection. */
function isNamedPropertyValue(value: unknown): boolean {
  if (typeof value !== 'object' || value === null) return false;
  const v = value as { nodeType?: unknown; item?: unknown; length?: unknown };
  return typeof v.nodeType === 'number' || (typeof v.item === 'function' && typeof v.length === 'number');
}

function reportClobberedHandler(node: unknown, key: string, what: string): void {
  if (DEV) console.error(`[frameact] delegated handler skipped: ${what} on`, node, `is shadowed by a form control or <img id> named "${key}" (DOM clobbering)`);
}

function eventHandler(e: Event): void {
  const { parentNode, contains, shadowHost, nodeName } = getNatives();
  let node: any = e.target;
  const key = EVENT_KEY + e.type;
  const oriCurrentTarget = e.currentTarget;
  const retarget = (value: unknown) => Object.defineProperty(e, 'target', { configurable: true, value });
  /**
   * A portal's logical parent, from the registry insert.ts keeps (nothing on the node itself is read, so
   * DOM clobbering cannot fake a host). The host must also be a Node outside the portal's own subtree.
   */
  const portalHost = (n: any): Node | undefined => {
    const h = portalHostOf(n);
    return h instanceof Node && !contains.call(n, h) ? h : undefined;
  };
  let hops = 0; // safety net: portals nest a handful of levels, a longer chain is a cycle
  const handleNode = (): boolean => {
    const handler = node[key];
    if (handler && node.disabled !== true) {
      const data = node[`${key}Data`];
      const isForm = nodeName.call(node) === 'FORM';
      if (typeof handler === 'function') {
        if (data !== undefined && isForm && isNamedPropertyValue(data)) reportClobberedHandler(node, `${key}Data`, 'the handler data');
        else if (data !== undefined) handler.call(node, data, e);
        else handler.call(node, e);
      } else if (typeof handler.handleEvent === 'function') handler.handleEvent(e);
      else if (isForm && isNamedPropertyValue(handler)) reportClobberedHandler(node, key, 'the handler');
      if (e.cancelBubble) return false;
    }
    if (node instanceof ShadowRoot) {
      const host = shadowHost.call(node);
      if (!portalHost(host) && contains.call(node, e.target as Node)) retarget(host);
    }
    return true;
  };
  const walkUpTree = () => {
    while (handleNode()) {
      const host = portalHost(node);
      if (host && ++hops > MAX_PORTAL_HOPS) break;
      node = host || parentNode.call(node) || (node instanceof ShadowRoot ? shadowHost.call(node) : null);
      if (!node) break;
    }
  };
  // simulate currentTarget
  Object.defineProperty(e, 'currentTarget', {
    configurable: true,
    get() {
      return node || document;
    },
  });
  try {
    if (e.composedPath) {
      const path = e.composedPath();
      retarget(path[0]);
      for (let i = 0; i < path.length - 2; i++) {
        node = path[i];
        if (!handleNode()) break;
        const host = portalHost(node);
        if (host) {
          node = host;
          walkUpTree(); // bubble up from the portal's logical position
          break;
        }
        if (parentNode.call(node) === oriCurrentTarget) break; // never above the delegation root
      }
    } else walkUpTree();
  } finally {
    // Back to the native values for whoever listens after us (Task 8's document-level checks).
    // The shadowing own properties are deleted, so the prototype getters answer again.
    delete (e as any).target;
    delete (e as any).currentTarget;
  }
}
```

```ts
// Adapted from teact (MIT, © 2022 Alexander Zinchuk) — https://github.com/Ajaxy/teact src/teact/teactn.tsx
// (getUntypedGlobal / setUntypedGlobal and the DEBUG outdated-global check), on a signal.
import { DEV } from '../env';
import { createSignal, untrack, type Accessor, type Setter } from '../index';
import { onTickEnd } from '../scheduler/schedulers';
import type { HeavyAnimationScope } from '../scheduler/heavyAnimation';

export interface SetGlobalOptions {
  /** This propagation skips the heavy-animation gate of every bridge (consumed once, by the bridges). */
  forceOnHeavyAnimation?: boolean;
  /** Propagate synchronously, inside `setGlobal` (teact: a workaround for iOS gesture history navigation). */
  forceSyncOnIOs?: boolean;
  /** DEV: skip the outdated-global check for this write. */
  forceOutdated?: boolean;
}

export type GlobalCallback<G> = (global: G) => void;

/** @internal One bridge signal per heavy-animation scope (bridge.ts); the fields the state keeps for them. */
export interface BridgeHandle<G> {
  readonly scope: HeavyAnimationScope;
  /** What containers in the scope read: the last propagated global. */
  readonly bridged: Accessor<G>;
  /** Containers and callbacks holding the bridge; it is disposed when the count reaches 0. */
  refs: number;
  /** A bridge run waiting for a non-blocking animation on the scope chain to end. */
  parked: { run: () => void; node: object } | null;
  /** The last value handed to `bridged` (a later effect run with the same value is a no-op). */
  delivered: G;
  deliver(value: G): void;
  dispose(): void;
}

/** @internal DEV accumulator for the "Slow containers update" warning (one report per propagation). */
export interface SlowTimer {
  pending: boolean;
  total: number;
  count: number;
}

/** @internal Everything the store modules share. Created by `createStoreState`; never exported from the package. */
export interface StoreState<G extends object> {
  /** The raw, tracked signal. Containers must not read it (that would bypass the non-blocking gate): they read a bridge. */
  readonly global: Accessor<G>;
  readonly writeGlobal: Setter<G>;
  getGlobal(): G;
  setGlobal(next: G, options?: SetGlobalOptions): void;
  readonly bridges: Map<HeavyAnimationScope, BridgeHandle<G>>;
  readonly callbacks: GlobalCallback<G>[];
  /** `forceOnHeavyAnimation` pending for the next propagation (teact's `forceOnHeavyAnimation` flag). */
  force: boolean;
  /** Installed by bridge.ts: runs after every signal write with the write's options. */
  propagate: (next: G, options: SetGlobalOptions | undefined) => void;
  readonly slow: SlowTimer;
}

/**
 * DEV stamp: an own, enumerable, symbol-keyed property. Object spread copies it (`{ ...global, x }`
 * carries the epoch of the global it was built from, like teact's `DEBUG_randomId`), while
 * `Object.keys`, `for…in`, `JSON.stringify` and `structuredClone` never see it. Nothing is copied on
 * `getGlobal()`: the current object is stamped in place, so reading never dirties the signal.
 */
const STAMP: unique symbol = Symbol('frameact.store.epoch');

function stamp(target: object, epoch: number): void {
  const t = target as { [STAMP]?: number };
  if (Object.prototype.hasOwnProperty.call(t, STAMP)) t[STAMP] = epoch;
  else if (Object.isExtensible(t)) Object.defineProperty(t, STAMP, { value: epoch, enumerable: true, writable: true, configurable: true });
  // a frozen object cannot be stamped: no check for it
}

function stampOf(target: object): number | undefined {
  return (target as { [STAMP]?: number })[STAMP];
}

export function createStoreState<G extends object>(initial: G): StoreState<G> {
  const [global, writeGlobal] = createSignal<G>(initial);
  // DEV epochs: `getGlobal()` stamps the object with the current epoch and invalidates it at tickEnd;
  // `setGlobal` throws when the object it is given carries a stamp of another epoch, then starts a
  // new epoch (and stamps the new global with it: deriving the next state from the object just set is fine).
  let epoch = 1;
  let invalidationBooked = false;
  const invalidate = () => {
    invalidationBooked = false;
    epoch++;
  };
  const state: StoreState<G> = {
    global,
    writeGlobal,
    bridges: new Map(),
    callbacks: [],
    force: false,
    propagate: () => {},
    slow: { pending: false, total: 0, count: 0 },
    getGlobal() {
      const current = untrack(global);
      if (DEV) {
        stamp(current, epoch);
        if (!invalidationBooked) {
          invalidationBooked = true;
          onTickEnd(invalidate);
        }
      }
      return current;
    },
    setGlobal(next, options) {
      if (typeof next !== 'object' || next === null || next === untrack(global)) return;
      if (DEV) {
        const seen = stampOf(next);
        if (!options?.forceOutdated && seen !== undefined && seen !== epoch) {
          throw new Error(
            '[frameact/store] setGlobal: attempt to set an outdated global. It derives from a getGlobal() read before an earlier setGlobal or in an earlier tick; read getGlobal() again before building the next state, or pass { forceOutdated: true }.',
          );
        }
        epoch++;
        stamp(next, epoch);
      }
      if (options?.forceOnHeavyAnimation) state.force = true;
      writeGlobal(next);
      state.propagate(next, options);
      state.force = false;
    },
  };
  return state;
}
```

```ts
// Adapted from teact (MIT, © 2022 Alexander Zinchuk) — https://github.com/Ajaxy/teact src/teact/teactn.tsx
// (handleAction, addUntypedActionHandler, execAfterActions): the action queue is ported as is.
import { DEV } from '../env';
import type { SetGlobalOptions, StoreState } from './state';

export type ActionOptions = SetGlobalOptions;

/**
 * `ActionPayloads` → the typed actions object: a payload that may be `undefined` makes the argument
 * optional. Every action returns a promise that settles when its handlers have run (`R` is `void` for
 * `getActions()`, so a fire-and-forget call is not an unhandled promise in the types).
 */
export type Actions<P, R = void> = {
  [K in keyof P]: undefined extends P[K]
    ? (payload?: P[K], options?: ActionOptions) => R
    : (payload: P[K], options?: ActionOptions) => R;
};

export type ActionHandler<G, P, K extends keyof P> = (
  global: G,
  actions: Actions<P>,
  payload: P[K],
) => G | void | Promise<void>;

type AnyHandler<G> = (global: G, actions: any, payload: any) => G | void | Promise<void>;

export interface ActionsApi<G extends object, P> {
  getActions(): Actions<P>;
  getPromiseActions(): Actions<P, Promise<void>>;
  addActionHandler<K extends keyof P & string>(name: K, handler: ActionHandler<G, P, K>): void;
  execAfterActions(fn: () => void): void;
}

function reportActionError(name: string, error: unknown): void {
  console.error(`[frameact/store] action "${name}" failed`, error);
}

function isThenable(value: unknown): value is PromiseLike<void> {
  return typeof (value as { then?: unknown }).then === 'function';
}

export function createActions<G extends object, P>(state: StoreState<G>): ActionsApi<G, P> {
  const handlers = new Map<string, AnyHandler<G>[]>();
  const actions: Record<string, (payload?: unknown, options?: ActionOptions) => Promise<void>> = {};
  // teact: "Keep 1 as start requirement to avoid immediate nested action calls. Do not remove element
  // from array before it is executed for the same reason." A nested `actions.x()` call made by a
  // handler is queued and runs after the current handler returns, still inside the outer call: the
  // whole cascade is synchronous (an event handler that dispatches an action sees the new global
  // right after the call; a controlled input's check does too).
  let actionQueue: (() => void)[] = [];
  let afterActionQueue: (() => void)[] = [];

  function runHandlers(name: string, payload: unknown, options: ActionOptions | undefined, resolve: () => void): void {
    for (const handler of handlers.get(name)!) {
      let result: G | void | Promise<void>;
      try {
        result = handler(state.getGlobal(), actions, payload);
      } catch (error) {
        // A throwing handler must not drop the rest of the cascade or leave the promise pending.
        reportActionError(name, error);
        resolve();
        continue;
      }
      if (!result) {
        resolve();
        continue;
      }
      if (isThenable(result)) {
        result.then(resolve, (error) => {
          reportActionError(name, error);
          resolve();
        });
        continue;
      }
      try {
        state.setGlobal(result, options);
      } catch (error) {
        reportActionError(name, error); // DEV: an outdated global, reported where it happened
      }
      resolve();
    }
  }

  function handleAction(name: string, payload: unknown, options: ActionOptions | undefined): Promise<void> {
    let resolve!: () => void;
    const promise = new Promise<void>((r) => {
      resolve = r;
    });
    actionQueue.push(() => runHandlers(name, payload, options, resolve));
    if (actionQueue.length === 1) {
      try {
        while (actionQueue.length) {
          actionQueue[0]();
          actionQueue.shift();
        }
        while (afterActionQueue.length) {
          const fn = afterActionQueue[0];
          afterActionQueue.shift();
          try {
            fn();
          } catch (error) {
            console.error('[frameact/store] execAfterActions callback failed', error);
          }
        }
      } finally {
        actionQueue = [];
        afterActionQueue = [];
      }
    }
    return promise;
  }

  return {
    getActions: () => actions as Actions<P>,
    getPromiseActions: () => actions as Actions<P, Promise<void>>,
    addActionHandler(name, handler) {
      let list = handlers.get(name);
      if (!list) {
        handlers.set(name, (list = []));
        actions[name] = (payload, options) => handleAction(name, payload, options);
      }
      list.push(handler as AnyHandler<G>);
    },
    /**
     * Run `fn` after every action of the current cascade (teact: "call only from action handlers").
     * Outside a cascade there is nothing to wait for: `fn` runs at once (DEV warns; teact would strand it
     * until the next action).
     */
    execAfterActions(fn) {
      if (actionQueue.length === 0) {
        if (DEV) console.warn('[frameact/store] execAfterActions called outside an action handler: running the callback now.');
        fn();
        return;
      }
      afterActionQueue.push(fn);
    },
  };
}
```

```ts
// Propagation (spec §3.5 "Распространение — bridge на scope"). The idea is teact's
// `throttleWithTickEnd(runCallbacks)` + `getIsHeavyAnimating.once` (MIT, © 2022 Alexander Zinchuk),
// as one effect per heavy-animation scope on the signal graph.
import { DEV } from '../env';
import { createEffect, effectScopeOf, markDrainGuarded, tickEnd, type EffectNode, type Schedule } from '../core/effects';
import { createRoot, createSignal, runWithOwner, untrack } from '../index';
import { requestMutation } from '../scheduler/fasterdom';
import { firstAnimatingScope, provideHeavyAnimationScope, rootScope, type HeavyAnimationScope } from '../scheduler/heavyAnimation';
import type { BridgeHandle, GlobalCallback, SetGlobalOptions, StoreState } from './state';

/** DEV: teact warns when one containers update takes longer than this. */
const SLOW_UPDATE_MS = 7;

function safeCallback<G>(cb: GlobalCallback<G>, value: G): void {
  try {
    cb(value);
  } catch (error) {
    console.error('[frameact/store] callback failed', error);
  }
}

/**
 * Create the bridge of `scope`: `[bridged, setBridged]` plus ONE effect `global → setBridged`, scheduled
 * at tickEnd and gated on non-blocking heavy animations of the scope chain (the effect snapshots
 * `scope` as its `_scope`: it is created under a detached root that provides it). Ten `setGlobal`
 * in a row make one bridge run; containers see the last propagated state, handlers the current one.
 */
function createBridge<G extends object>(state: StoreState<G>, scope: HeavyAnimationScope): BridgeHandle<G> {
  const initial = untrack(state.global);
  const [bridged, setBridged] = createSignal<G>(initial);
  const bridge: BridgeHandle<G> = {
    scope,
    bridged,
    refs: 0,
    parked: null,
    delivered: initial,
    deliver(value) {
      if (value === bridge.delivered) return;
      bridge.delivered = value;
      setBridged(value);
      if (DEV) armSlowTimer(state); // after the write: its mutate task must follow the drain the write armed
      // teact runs its callbacks from the same throttled, gated pass that updates the containers: the
      // root bridge is that pass (sub-scope bridges only feed their own containers).
      if (scope === rootScope) for (const cb of state.callbacks.slice()) safeCallback(cb, value);
    },
    dispose: () => {},
  };
  // The bridge's own schedule, not the generic `gateOnHeavyAnimation(tickEnd)`: a run parked on a
  // scope's `once` must be releasable by `forceOnHeavyAnimation` (teact: the forced `runCallbacks`
  // skips the gate even while an earlier pass is waiting on `getIsHeavyAnimating.once`).
  const schedule: Schedule = (run, node) => {
    if (state.force) return tickEnd(run, node);
    const animating = firstAnimatingScope(effectScopeOf(node), false);
    if (animating === null) return tickEnd(run, node);
    const entry = { run, node };
    bridge.parked = entry;
    animating.isAnimating.once(() => {
      if (bridge.parked !== entry) return; // released by force, or disposed
      bridge.parked = null;
      schedule(run, node); // another scope of the chain may be animating by now
    });
  };
  markDrainGuarded(schedule); // tickEnd counts the runs per drain itself
  // A detached root with no inherited context or error handlers (the bridge is shared by every
  // container of the scope; an error in it is the store's, not the first container's).
  bridge.dispose = runWithOwner(null, () =>
    createRoot((dispose) => {
      provideHeavyAnimationScope(scope);
      createEffect<G>(() => state.global(), (value) => bridge.deliver(value), schedule, { name: 'store bridge' });
      return () => {
        bridge.parked = null;
        dispose();
      };
    }),
  )!;
  return bridge;
}

/** @internal The bridge of `scope` (created lazily), with one more holder. */
export function acquireBridge<G extends object>(state: StoreState<G>, scope: HeavyAnimationScope): BridgeHandle<G> {
  let bridge = state.bridges.get(scope);
  if (!bridge) {
    bridge = createBridge(state, scope);
    state.bridges.set(scope, bridge);
  }
  bridge.refs++;
  return bridge;
}

/** @internal Drop one holder; the last one disposes the bridge (its effect stops following `global`). */
export function releaseBridge<G extends object>(state: StoreState<G>, bridge: BridgeHandle<G>): void {
  if (--bridge.refs > 0) return;
  state.bridges.delete(bridge.scope);
  bridge.dispose();
}

/** Run every bridge run that is parked on an animation (the force flag is set: they skip the gate this time). */
function releaseParked<G extends object>(state: StoreState<G>): void {
  for (const bridge of state.bridges.values()) {
    const entry = bridge.parked;
    if (entry === null) continue;
    bridge.parked = null;
    tickEnd(entry.run, entry.node as EffectNode);
  }
}

/** The DEV "Slow containers update" report: mapStateToProps time accumulated from this propagation until the next mutate phase. */
function armSlowTimer<G extends object>(state: StoreState<G>): void {
  const slow = state.slow;
  if (slow.pending) return;
  slow.pending = true;
  slow.total = 0;
  slow.count = 0;
  // Queued after the mutate drain the propagation just armed (containers recompute when their
  // bindings run there), so the report sees that frame's mapStateToProps work.
  requestMutation(() => {
    slow.pending = false;
    if (slow.total > SLOW_UPDATE_MS) {
      console.warn(`[frameact/store] Slow containers update: ${Math.round(slow.total)} ms in ${slow.count} mapStateToProps call(s)`);
    }
  });
}

/** Installed into `state.propagate`: what `setGlobal` does after the signal write. */
export function installPropagation<G extends object>(state: StoreState<G>): void {
  state.propagate = (next, options: SetGlobalOptions | undefined) => {
    // Bridges that were dirty and parked before this write were not notified by it: release them.
    if (state.force) releaseParked(state);
    if (options?.forceSyncOnIOs) for (const bridge of state.bridges.values()) bridge.deliver(next);
  };
}

export interface CallbacksApi<G> {
  /** Called with the global after every propagation of the root bridge (gated like containers; sync with `forceSyncOnIOs`). */
  addCallback(cb: GlobalCallback<G>): void;
  removeCallback(cb: GlobalCallback<G>): void;
  /** The next propagation skips the heavy-animation gate of every bridge (teact's `forceOnHeavyAnimationOnce`). */
  forceOnHeavyAnimationOnce(): void;
}

export function createCallbacks<G extends object>(state: StoreState<G>): CallbacksApi<G> {
  return {
    addCallback(cb) {
      state.callbacks.push(cb);
      acquireBridge(state, rootScope); // a callback holds the root bridge like a container does
    },
    removeCallback(cb) {
      const index = state.callbacks.indexOf(cb);
      if (index === -1) return;
      state.callbacks.splice(index, 1);
      releaseBridge(state, state.bridges.get(rootScope)!);
    },
    forceOnHeavyAnimationOnce() {
      state.force = true;
    },
  };
}
```

```ts
// all while a non-blocking heavy animation runs on the container's scope. A controlled input bound
// to such a value (`use:value={props.draft}`) checks the DOM against a value the handler's action has
// not reached yet and rolls an accepted keystroke back. The store marks the running effect on every
// read of a container prop; the directives ask whether the effect that delivers to them was marked.

const gatedReaders = new WeakSet<object>();

/** The store calls it (DEV) when a gated value is read: the effect whose compute/apply is running is remembered. */
export function markGatedRead(): void {
  const effect = getRunningEffect();
  if (effect !== null) gatedReaders.add(effect);
}

/** Has `effect` ever read a gated value? */
export function isGatedReader(effect: object | null): boolean {
  return effect !== null && gatedReaders.has(effect);
```

```ts
// Adapted from teact (MIT, © 2022 Alexander Zinchuk) — https://github.com/Ajaxy/teact src/teact/teactn.tsx
// (withUntypedGlobal, activateContainer, arePropsShallowEqual): containers as memos over a bridge signal.
import { DEV } from '../env';
import { handleError } from '../core/core';
import type { Scope } from '../core/types';
import { createMemo, getOwner, onCleanup, runWithOwner, untrack, type Accessor } from '../index';
import { currentHeavyAnimationScope } from '../scheduler/heavyAnimation';
import { createComponent } from '../dom/component';
import { markGatedRead } from '../dom/gated';
import { acquireBridge, releaseBridge } from './bridge';
import type { StoreState } from './state';

export type StickToFirst = (value: unknown) => boolean;
export type MapStateToProps<G, OwnProps, Mapped> = (global: G, ownProps: OwnProps) => Mapped;
export type ActivationFn<G, OwnProps> = (global: G, ownProps: OwnProps, stickToFirst: StickToFirst) => boolean;

export type WithGlobal<G> = <OwnProps extends object, Mapped extends object>(
  mapStateToProps?: MapStateToProps<G, OwnProps, Mapped>,
  activationFn?: ActivationFn<G, OwnProps>,
) => (Component: (props: OwnProps & Mapped) => unknown) => (props: OwnProps) => unknown;

const EMPTY: Record<string, unknown> = Object.freeze({});

/** teact's `arePropsShallowEqual`: same keys, `===` values. */
export function shallowEqual(a: unknown, b: unknown): boolean {
  if (a === b) return true;
  if (typeof a !== 'object' || typeof b !== 'object' || a === null || b === null) return false;
  const keysA = Object.keys(a);
  if (keysA.length !== Object.keys(b).length) return false;
  for (let i = 0; i < keysA.length; i++) {
    const key = keysA[i];
    if ((a as Record<string, unknown>)[key] !== (b as Record<string, unknown>)[key]) return false;
  }
  return true;
}

/** Through the owner's `onError` handlers (as a failed `For` row is reported), else the console. */
function reportContainerError(owner: Scope | null, name: string, error: unknown): void {
  try {
    handleError(owner, error);
  } catch (unhandled) {
    console.error(`[frameact/store] withGlobal(${name}): mapStateToProps failed; the previous props are kept`, unhandled);
  }
}

/**
 * The props the wrapped component receives: own props win when defined (teact: `{...mapped, ...props}`;
 * an own `undefined` falls through, as in `mergeProps`), the rest are per-key lazy memos over `mapped`
 * (`===`): a binding on `isSelected` is not re-run by a change of `message`. A memo is created on the
 * first read of its key, owned by the container (not by the binding effect that happened to read first).
 * The key set is live: `ownKeys` reads `mapped` tracked, so a spread of these props follows it.
 * Symbol keys are never props.
 */
function containerProps<Mapped extends object>(
  mapped: Accessor<Mapped>,
  own: Record<string, unknown>,
  owner: Scope | null,
): Record<string, unknown> {
  const memos = new Map<string, Accessor<unknown>>();
  const read = (key: string): unknown => {
    let memo = memos.get(key);
    if (memo === undefined) {
      memo = runWithOwner(owner, () => createMemo(() => (mapped() as Record<string, unknown>)[key]))!;
      memos.set(key, memo);
    }
    if (DEV) markGatedRead(); // a controlled input bound to this value would see it late (gated.ts)
    return memo();
  };
  const get = (key: string): unknown => {
    const value = own[key];
    return value !== undefined ? value : read(key);
  };
  const has = (key: string | symbol): boolean => typeof key === 'string' && (key in own || key in untrack(mapped));
  return new Proxy(Object.create(null) as Record<string, unknown>, {
    get: (_target, key) => (typeof key === 'string' ? get(key) : undefined),
    has: (_target, key) => has(key),
    ownKeys: () => {
      const keys = new Set<string | symbol>();
      for (const key of Reflect.ownKeys(own)) if (typeof key === 'string') keys.add(key);
      for (const key of Object.keys(mapped())) keys.add(key);
      return [...keys];
    },
    getOwnPropertyDescriptor: (_target, key) =>
      has(key) ? { enumerable: true, configurable: true, get: () => get(key as string) } : undefined,
  });
}

/**
 * `withGlobal(mapStateToProps, activationFn?)(Component)` (spec §3.5 "Контейнеры"). The container is a
 * memo with `shallowEqual` over `mapStateToProps(bridged(), props)`: a change of its OWN props
 * recomputes it at once (the props getters are tracked; no gate, like teact's
 * `!arePropsShallowEqual(ownProps, props)`), a change of `global` arrives through the bridge of the
 * container's heavy-animation scope (tickEnd, gated on non-blocking animations of that scope chain).
 * `activationFn` / `stickToFirst` work as in teact (an inactive container keeps its last props). A
 * throwing `mapStateToProps` is reported through `onError` and keeps the last props: the component is
 * never frozen on an error.
 */
export function createWithGlobal<G extends object>(state: StoreState<G>): WithGlobal<G> {
  return function withGlobal<OwnProps extends object, Mapped extends object>(
    mapStateToProps: MapStateToProps<G, OwnProps, Mapped> = () => EMPTY as Mapped,
    activationFn?: ActivationFn<G, OwnProps>,
  ) {
    return (Component: (props: OwnProps & Mapped) => unknown) => {
      const name = Component.name || 'Component';
      function Container(props: OwnProps): unknown {
        const owner = getOwner();
        const bridge = acquireBridge(state, currentHeavyAnimationScope());
        onCleanup(() => releaseBridge(state, bridge));
        let stuckTo: unknown;
        const stickToFirst: StickToFirst = (value) => {
          if (stuckTo) return stuckTo === value;
          if (value !== undefined) stuckTo = value;
          return true;
        };
        let last: Mapped = EMPTY as Mapped;
        const mapped = createMemo<Mapped>(
          () => {
            const global = bridge.bridged();
            const started = DEV ? performance.now() : 0;
            try {
              if (activationFn !== undefined && !activationFn(global, props, stickToFirst)) return last;
              const next = mapStateToProps(global, props) || (EMPTY as Mapped);
              if (DEV && Object.values(next).some(Number.isNaN)) {
                console.warn(`[frameact/store] withGlobal(${name}): some mapped props are NaN; they never compare equal, so the container updates on every propagation.`);
              }
              last = next;
            } catch (error) {
              reportContainerError(owner, name, error);
            } finally {
              if (DEV) {
                state.slow.total += performance.now() - started;
                state.slow.count++;
              }
            }
            return last;
          },
          { equals: shallowEqual },
        );
        return createComponent(Component, containerProps(mapped, props as Record<string, unknown>, owner) as OwnProps & Mapped);
      }
      if (DEV) Object.defineProperty(Container, 'name', { value: `withGlobal(${name})`, configurable: true });
      return Container;
    };
  };
}
```

```ts
import { DEV } from '../env';
import { createMemo, getOwner, type Accessor, type SignalOptions } from '../index';
import type { StoreState } from './state';

export type LiveGlobal<G> = <T>(selector: (global: G) => T, options?: SignalOptions<T>) => Accessor<T>;

/**
 * `liveGlobal(selector)`: a memo over the CURRENT global — tracked, never gated, updated by the very
 * `setGlobal` that writes it (no tickEnd hop, no heavy-animation wait). It exists for controlled
 * inputs: `use:value={draft}` with `const draft = liveGlobal((g) => selectDraft(g, chatId))` lets the
 * directive's synchronous check see what the `onInput` action just wrote, so an accepted keystroke is
 * not rolled back; a container prop (`use:value={props.draft}`) reaches the input a tick later and
 * not at all during a non-blocking heavy animation (DEV reports that binding). Everything that is not
 * an input should read the store through `withGlobal`, which respects the animation gate. Call it in
 * a component body (it creates an owned memo; DEV warns without an owner).
 */
export function createLiveGlobal<G extends object>(state: StoreState<G>): LiveGlobal<G> {
  return (selector, options) => {
    if (DEV && getOwner() === null) {
      console.warn('[frameact/store] liveGlobal called without an owner (outside a component or root): its memo is never disposed.');
    }
    return createMemo(() => selector(state.global()), options);
  };
}
```

```ts
// frameact/store — TeactN on signals (spec §3.5): a private global signal, propagation through one
// bridge per heavy-animation scope, the teact action queue, `withGlobal` containers.
import { createActions, type ActionsApi } from './actions';
import { createCallbacks, installPropagation, type CallbacksApi } from './bridge';
import { createWithGlobal, type WithGlobal } from './container';
import { createLiveGlobal, type LiveGlobal } from './live';
import { createStoreState, type SetGlobalOptions } from './state';

export type { ActionHandler, ActionOptions, Actions } from './actions';
export type { ActivationFn, MapStateToProps, StickToFirst, WithGlobal } from './container';
export { shallowEqual } from './container';
export type { LiveGlobal } from './live';
export type { GlobalCallback, SetGlobalOptions } from './state';

export interface GlobalStore<G extends object, P> extends ActionsApi<G, P>, CallbacksApi<G> {
  /** The current global, untracked (DEV: stamped for the outdated-global check). */
  getGlobal(): G;
  /** Replace the global at once; containers see it at tickEnd through their bridge (see `SetGlobalOptions`). */
  setGlobal(next: G, options?: SetGlobalOptions): void;
  withGlobal: WithGlobal<G>;
  liveGlobal: LiveGlobal<G>;
}

/**
 * One store instance (teact's `typify`): `createGlobalStore<GlobalState, ActionPayloads>(initialState)`.
 * Independent instances do not share handlers, bridges or callbacks.
 */
export function createGlobalStore<G extends object, P = Record<string, never>>(initialState: G): GlobalStore<G, P> {
  const state = createStoreState<G>(initialState);
  installPropagation(state);
  return {
    getGlobal: state.getGlobal,
    setGlobal: state.setGlobal,
    ...createActions<G, P>(state),
    ...createCallbacks<G>(state),
    withGlobal: createWithGlobal<G>(state),
    liveGlobal: createLiveGlobal<G>(state),
  };
}
```

```markdown
#### Контролируемые инпуты и стор

Проверка `use:value` сравнивает DOM с авторитетным значением **синхронно в событии**
(accessor-форма) или в mutate-фазе, дождавшись чистоты доставляющего эффекта
(plain-форма). Значение из пропса контейнера приходит через bridge — на tickEnd, а при
non-blocking анимации scope'а не приходит вовсе: синхронная проверка откатила бы принятый
символ, plain-проверка откатила бы его во время анимации (эффект компилятора чист — bridge
запаркован). Поэтому:

- `liveGlobal(selector, options?)` стора — `createMemo(() => selector(global()))`:
  tracked, **не гейтится**, обновляется той же `setGlobal`, что пишет состояние.
  Контролируемый инпут биндится к нему: `const draft = liveGlobal(g => selectDraft(g,
  chatId)); <input use:value={draft} onInput={e => actions.setDraft(…)}>` — экшен пишет
  синхронно, проверка видит запись, принятый символ не откатывается, отклонённый
  откатывается до paint, при любой анимации. Программная запись (очистка после Send)
  приходит в следующем кадре, без гейта (поле ввода — не тяжёлое поддерево).
- Всё остальное читает стор через `withGlobal` (гейт анимаций сохраняется).
- DEV-защита: стор помечает эффект, читающий пропс контейнера (`src/dom/gated.ts`,
  `markGatedRead` в Proxy-геттере); директивы `use:value`/`use:checked` проверяют, помечен
  ли доставляющий им эффект (plain-форма) или их собственный compute (accessor-форма), и
  печатают `console.error` с подсказкой про `liveGlobal`. Ловится и через цепочку пропсов
  (`<Composer draft={props.draft}/>`): геттер вызывается при чтении.
```
