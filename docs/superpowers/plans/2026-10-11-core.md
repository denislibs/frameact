# frameact core — Implementation Plan (plan 1 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the reactive core of frameact — vendored maverick signals with two patches, the fasterdom scheduler, two-phase effects with batched frame queues and heavy-animation gating, scopes, keyed `mapArray`, context — fully unit-tested, with no DOM runtime yet.

**Architecture:** Signals/computeds are maverick-js/signals v6 (Reactively algorithm) vendored into `src/core`. Effects are split into a tracked pure `compute` and an untracked `apply`; when an effect becomes dirty the core calls its `schedule(run, node)`. Frame schedulers (`frameMeasure`/`frameMutation`/`frameForcedReflow`) are batched queues that put exactly one fasterdom task per phase per frame and sample heavy-animation gating once per drain. Everything in this plan runs under vitest + jsdom with a fake `requestAnimationFrame`.

**Tech Stack:** TypeScript 7 (the Go-native compiler, `typescript@^7.0.2`, strict, ES2022, `lib: DOM`), pnpm, Vite 8 + vitest 5 + jsdom 30, oxlint for linting. No build step yet (tests import `src/` directly).

**Spec:** `docs/superpowers/specs/2026-10-11-frameact-design.md` — §3.1 (scheduler), §3.2 (core, effects, heavyAnimation), §5 (tests). Read §3.2 fully before starting Task 8.

`test/helpers/raf.ts` — jsdom's rAF is unreliable; every scheduler test installs this:
```ts
type Cb = (now: number) => void;

export function installFakeRaf() {
  const original = { raf: globalThis.requestAnimationFrame, caf: globalThis.cancelAnimationFrame };
  let queue: { id: number; cb: Cb }[] = [];
  let nextId = 1;
  let now = 0;

  globalThis.requestAnimationFrame = (cb: Cb) => {
    const id = nextId++;
    queue.push({ id, cb });
    return id;
  };
  globalThis.cancelAnimationFrame = (id: number) => {
    queue = queue.filter((q) => q.id !== id);
  };

  return {
    /** Fire every callback queued so far (callbacks queued during the frame wait for the next frame). */
    frame(step = 16) {
      now += step;
      const current = queue;
      queue = [];
      for (const { cb } of current) cb(now);
    },
    pending: () => queue.length,
    uninstall() {
      globalThis.requestAnimationFrame = original.raf;
      globalThis.cancelAnimationFrame = original.caf;
    },
  };
}
```

### Task 3: Patch 1 — missed-wake latch (no lost self-writes)

Spec §3.2 "Правки в maverick" #1. Today a node stays `DIRTY` during its own compute and `update()` sets `CLEAN` in `finally`. A *signal* write made during compute to a source the node already read calls `notify(node)`, which bails on `_state >= DIRTY`, and the write is lost.

The naive fix — set `CLEAN` before compute — is wrong: a computed pulled lazily *inside* the compute writes its fresh result and notifies the computing node, which then recomputes once more for nothing (it breaks the vendored "jagged diamond + tails" glitch-free test). This is the same problem Solid 2.0 solves with `REACTIVE_MISSED_WAKE`. The fix: keep maverick's `DIRTY`-during-compute, mark the node `_computing`, and in `notify` **latch** writes that land on a computing node — except a computed's result write (a lazy pull this pass reads fresh). When the compute ends, a latched node is re-dirtied through a normal `notify` (which also re-schedules an effect).

**Files:**
- Modify: `src/core/types.ts` (two internal fields), `src/core/core.ts` (`ComputeNode` constructor, `notify`, `update`, constants)
- Test: `test/core/patch-missed-wake.test.ts`

**Interfaces:**
- Produces: behavioral guarantee — a node that receives a signal write while computing ends `update()` in state `DIRTY` and is propagated like any dirty node (observers CHECK, effects scheduled). Exposes `STATE_CLEAN, STATE_CHECK, STATE_DIRTY, STATE_DISPOSED` as named exports (Task 8 needs them). Internal fields `Computation._computing: boolean`, `Computation._missedWake: boolean`.

5. Replace `notify`'s first line so it starts:

```ts
function notify(node: Computation, state: number) {
  if (node._computing) {
    // Patch 1 (frameact): a write landing on a node mid-compute. A computed's result write is a
    // lazy pull this pass reads fresh — ignore it (maverick's behavior). A signal write may have
    // changed a value this pass already read: latch it; update() re-dirties the node at the end.
    if (computedWriteDepth === 0) node._missedWake = true;
    return;
  }
  if (node._state >= state) return;
  // …rest of notify unchanged
```

6. Rewrite `update()`:
```ts
export function update(node: Computation) {
  let prevObservers = currentObservers,
    prevObserversIndex = currentObserversIndex;

  currentObservers = null as Computation[] | null;
  currentObserversIndex = 0;
  node._computing = true;
  node._missedWake = false;

  try {
    cleanup(node);

    const result = compute(node, node._compute!, node);

    updateObservers(node);

    if (!node._effect && node._init) {
      computedWriteDepth++;
      try {
        write.call(node, result);
      } finally {
        computedWriteDepth--;
      }
    } else {
      node._value = result;
      node._init = true;
    }
  } catch (error) {
    if (DEV && !node._init && typeof node._value === 'undefined') {
      console.error(
        `computed \`${node.id}\` threw error during first run, this can be fatal.` +
          '\n\nSolutions:\n\n' +
          '1. Set the `initial` option to silence this error',
        '\n2. Or, use an `effect` if the return value is not being used',
        '\n\n',
        error,
      );
    }

    updateObservers(node);
    handleError(node, error);
  } finally {
    currentObservers = prevObservers;
    currentObserversIndex = prevObserversIndex;
    node._computing = false;
    // A node disposed during its own compute stays DISPOSED.
    if (node._state !== STATE_DISPOSED) {
      node._state = STATE_CLEAN;
      if (node._missedWake) {
```

```ts
export function updateCheck(node: Computation) {
  // Patch 2 (frameact): a disposed node is never resurrected by a stale observer.
  if (node._state === STATE_DISPOSED) return;

  if (node._state === STATE_CHECK) {
    for (let i = 0; i < node._sources!.length; i++) {
      updateCheck(node._sources![i]);
      if ((node._state as number) === STATE_DIRTY) {
        // Stop the loop here so we won't trigger updates on other parents unnecessarily

        break;
      }
    }
```

```ts
// Adapted from teact (MIT, © 2022 Alexander Zinchuk) — https://github.com/Ajaxy/teact src/util/schedulers.ts

export type NoneToVoidFunction = () => void;
export type AnyToVoidFunction = (...args: any[]) => void;
export type Scheduler = (cb: NoneToVoidFunction) => void;

export function throttle<F extends AnyToVoidFunction>(fn: F, ms: number, shouldRunFirst = true) {
  let interval: ReturnType<typeof setInterval> | undefined;
  let isPending: boolean;
  let args: Parameters<F>;

  return (..._args: Parameters<F>) => {
    isPending = true;
    args = _args;

    if (!interval) {
      if (shouldRunFirst) {
        isPending = false;
        fn(...args);
      }

      interval = setInterval(() => {
        if (!isPending) {
          clearInterval(interval!);
          interval = undefined;
          return;
        }

        isPending = false;
        fn(...args);
      }, ms);
    }
  };
}

export function throttleWithTickEnd<F extends AnyToVoidFunction>(fn: F) {
  return throttleWith(onTickEnd, fn);
}

export function throttleWith<F extends AnyToVoidFunction>(schedulerFn: Scheduler, fn: F) {
  let waiting = false;
  let args: Parameters<F>;

  return (..._args: Parameters<F>) => {
    args = _args;

    if (!waiting) {
      waiting = true;

      schedulerFn(() => {
        waiting = false;
        fn(...args);
      });
    }
  };
}

const FAST_RAF_TIMEOUT_FALLBACK_MS = 35; // < 30 FPS

let fastRafCallbacks: Set<NoneToVoidFunction> | undefined;
let fastRafFallbackCallbacks: Set<NoneToVoidFunction> | undefined;
let fastRafFallbackTimeout: ReturnType<typeof setTimeout> | undefined;

// May result in an immediate execution if called from another RAF callback which was scheduled
// (and therefore is executed) earlier than RAF callback scheduled by `fastRaf`
export function fastRaf(callback: NoneToVoidFunction, withTimeoutFallback = false) {
  if (!fastRafCallbacks) {
    fastRafCallbacks = new Set([callback]);

    requestAnimationFrame(() => {
      const currentCallbacks = fastRafCallbacks!;

      fastRafCallbacks = undefined;
      fastRafFallbackCallbacks = undefined;

      if (fastRafFallbackTimeout) {
        clearTimeout(fastRafFallbackTimeout);
        fastRafFallbackTimeout = undefined;
      }

      currentCallbacks.forEach((cb) => cb());
    });
  } else {
    fastRafCallbacks.add(callback);
  }

  if (withTimeoutFallback) {
    if (!fastRafFallbackCallbacks) {
      fastRafFallbackCallbacks = new Set([callback]);
    } else {
      fastRafFallbackCallbacks.add(callback);
    }

    if (!fastRafFallbackTimeout) {
      fastRafFallbackTimeout = setTimeout(() => {
        const currentTimeoutCallbacks = fastRafFallbackCallbacks!;

        if (fastRafCallbacks) {
          currentTimeoutCallbacks.forEach(fastRafCallbacks.delete, fastRafCallbacks);
        }
        fastRafFallbackCallbacks = undefined;

        if (fastRafFallbackTimeout) {
          clearTimeout(fastRafFallbackTimeout);
          fastRafFallbackTimeout = undefined;
        }

        currentTimeoutCallbacks.forEach((cb) => cb());
      }, FAST_RAF_TIMEOUT_FALLBACK_MS);
    }
  }
}

let onTickEndCallbacks: NoneToVoidFunction[] | undefined;

export function onTickEnd(callback: NoneToVoidFunction) {
  if (!onTickEndCallbacks) {
    onTickEndCallbacks = [callback];
    Promise.resolve().then(flushTickEnd);
  } else {
    onTickEndCallbacks.push(callback);
  }
}

/** Run every pending onTickEnd callback now. Used by the microtask itself and by flushSync(). */
export function flushTickEnd() {
  if (!onTickEndCallbacks) return;
  const currentCallbacks = onTickEndCallbacks;
  onTickEndCallbacks = undefined;
  currentCallbacks.forEach((cb) => cb());
}

const IDLE_TIMEOUT = 500;

let onIdleCallbacks: NoneToVoidFunction[] | undefined;

export function onIdle(callback: NoneToVoidFunction) {
  if (typeof requestIdleCallback !== 'function') {
    onTickEnd(callback);
    return;
  }

  if (!onIdleCallbacks) {
    onIdleCallbacks = [callback];

    requestIdleCallback((deadline) => {
      const currentCallbacks = onIdleCallbacks!;
      onIdleCallbacks = undefined;

      while (currentCallbacks.length) {
        const cb = currentCallbacks.shift()!;
        cb();

        if (!deadline.timeRemaining()) break;
      }

      if (currentCallbacks.length) {
        if (onIdleCallbacks) {
          // Prepend the remaining callbacks if the next pass is already planned
          onIdleCallbacks = currentCallbacks.concat(onIdleCallbacks);
        } else {
          currentCallbacks.forEach(onIdle);
        }
      }
    }, { timeout: IDLE_TIMEOUT });
  } else {
    onIdleCallbacks.push(callback);
  }
}
```

```ts
// Adapted from teact (MIT, © 2022 Alexander Zinchuk) — https://github.com/Ajaxy/teact src/lib/fasterdom/fasterdom.ts
import { fastRaf, throttleWith, type NoneToVoidFunction } from './schedulers';

export type Phase = 'measure' | 'mutate';
type ReflowTask = () => NoneToVoidFunction | void;

let phase: Phase = 'measure';
const phaseListeners = new Set<(phase: Phase) => void>();

export function getPhase(): Phase {
  return phase;
}

export function setPhase(next: Phase) {
  if (phase === next) return;
  phase = next;
  phaseListeners.forEach((l) => l(next));
}

/** stricterdom (plan 4) subscribes here. */
export function onPhaseChange(listener: (phase: Phase) => void) {
  phaseListeners.add(listener);
  return () => phaseListeners.delete(listener);
}

let pendingMeasureTasks: NoneToVoidFunction[] = [];
let pendingMutationTasks: NoneToVoidFunction[] = [];
let pendingForceReflowTasks: ReflowTask[] = [];
let inSyncPass = false;

function safeExec(fn: NoneToVoidFunction) {
  try {
    fn();
  } catch (error) {
    console.error('[frameact] scheduler task failed', error);
  }
}

function runMeasureTasks() {
  setPhase('measure');
  const current = pendingMeasureTasks;
  pendingMeasureTasks = [];
  current.forEach(safeExec);
}

function runMutationTasks() {
  setPhase('mutate');
  const current = pendingMutationTasks;
  pendingMutationTasks = [];
  current.forEach(safeExec);
}

function runForcedReflowTasks(): NoneToVoidFunction[] {
  setPhase('measure');
  const mutations: NoneToVoidFunction[] = [];
  // for..of over the live array: tasks requested during this loop are included (as in teact)
  for (const task of pendingForceReflowTasks) {
    safeExec(() => {
      const mutation = task();
      if (mutation) mutations.push(mutation);
    });
  }
  pendingForceReflowTasks = [];
  return mutations;
}

function runForcedReflowMutations(mutations: NoneToVoidFunction[]) {
  setPhase('mutate');
  for (const task of mutations) safeExec(task);
  setPhase('measure');
}

const runUpdatePassOnRaf = throttleWith(
  (cb) => fastRaf(cb, true),
  () => {
    runMeasureTasks();
    // Promise hops keep MutationObserver microtasks ordered against our phase changes.
    void Promise.resolve()
      .then(runMutationTasks)
      .then(runForcedReflowTasks)
      .then(runForcedReflowMutations);
  },
);

export function requestMeasure(cb: NoneToVoidFunction) {
  pendingMeasureTasks.push(cb);
  runUpdatePassOnRaf();
}

export function requestMutation(cb: NoneToVoidFunction) {
  pendingMutationTasks.push(cb);
  runUpdatePassOnRaf();
}

export function requestNextMutation(cb: NoneToVoidFunction) {
  requestMeasure(() => {
    requestMutation(cb);
  });
}

export function requestForcedReflow(cb: ReflowTask) {
  pendingForceReflowTasks.push(cb);
  runUpdatePassOnRaf();
}

/**
 * Run a whole frame pass synchronously (tests, imperative integration code).
 * Does not bypass heavy-animation gating of the core's run queues. Not reentrant.
 * The already-throttled rAF (if any) will later fire with empty queues — harmless.
 */
export function flushSync() {
  if (inSyncPass) throw new Error('[frameact] flushSync() is not reentrant');
  inSyncPass = true;
  try {
    runMeasureTasks();
    runMutationTasks();
    runForcedReflowMutations(runForcedReflowTasks());
  } finally {
    inSyncPass = false;
    setPhase('measure');
  }
}
```

```ts
// Adapted from teact (MIT, © 2022 Alexander Zinchuk) — https://github.com/Ajaxy/teact src/teact/heavyAnimation.ts
// Generalised to scopes: the global API is the root scope.
import { getContext, getScope, peek, setContext } from '../core/core';
import { signal } from '../core/signals';
import type { Scope } from '../core/types';
import { onIdle } from './schedulers';

const AUTO_END_TIMEOUT = 1000;

export interface OnceSignal {
  (): boolean;
  peek(): boolean;
  /** Run `cb` once, on the next change of the value. */
  once(cb: () => void): () => void;
}

export interface HeavyAnimationScope {
  readonly parent: HeavyAnimationScope | null;
  readonly isAnimating: OnceSignal;
  readonly isBlockingAnimating: OnceSignal;
  begin(duration?: number, isBlocking?: boolean): () => void;
  /** @internal effects.ts parks gated runs here */
  _parked: unknown[];
  /** @internal */
  _releaseArmed: boolean;
  /** @internal onHeavyAnimation listeners */
  _listeners: Set<(animating: boolean) => void>;
}

function createOnceSignal(): [OnceSignal, (v: boolean) => void] {
  const $value = signal(false);
  const callbacks = new Set<() => void>();
  const get = (() => $value()) as OnceSignal;
  get.peek = () => peek($value);
  get.once = (cb) => {
    callbacks.add(cb);
    return () => {
      callbacks.delete(cb);
    };
  };
  const set = (next: boolean) => {
    if (peek($value) === next) return;
    $value.set(next);
    // Snapshot: a callback that registers another `once` must wait for the *next* change,
    // otherwise a release that starts a new animation loops inside this flush.
    const current = Array.from(callbacks);
    callbacks.clear();
    for (const cb of current) cb();
  };
  return [get, set];
}

function createScopeInternal(parent: HeavyAnimationScope | null): HeavyAnimationScope {
  let counter = 0;
  let counterBlocking = 0;
  const [isAnimating, setAnimating] = createOnceSignal();
  const [isBlockingAnimating, setBlocking] = createOnceSignal();
  const listeners = new Set<(animating: boolean) => void>();

  const scope: HeavyAnimationScope = {
    parent,
    isAnimating,
    isBlockingAnimating,
    _parked: [],
    _releaseArmed: false,
    _listeners: listeners,
    begin(duration = AUTO_END_TIMEOUT, isBlocking = false) {
      counter++;
      if (counter === 1) {
        setAnimating(true);
        listeners.forEach((l) => l(true));
      }
      if (isBlocking) {
        counterBlocking++;
        if (counterBlocking === 1) setBlocking(true);
      }

      const timeout = setTimeout(onEnd, duration);
      let hasEnded = false;

      function onEnd() {
        if (hasEnded) return;
        hasEnded = true;
        clearTimeout(timeout);

        counter--;
        if (counter === 0) {
          setAnimating(false);
          listeners.forEach((l) => l(false));
        }
        if (isBlocking) {
          counterBlocking--;
          if (counterBlocking === 0) setBlocking(false);
        }
      }

      return onEnd;
    },
  };
  return scope;
}

export const rootScope: HeavyAnimationScope = createScopeInternal(null);

export function createHeavyAnimationScope(parent: HeavyAnimationScope | null = rootScope) {
  return createScopeInternal(parent);
}

export function beginHeavyAnimation(duration?: number, isBlocking?: boolean) {
  return rootScope.begin(duration, isBlocking);
}
export const getIsHeavyAnimating = rootScope.isAnimating;
export const getIsBlockingAnimating = rootScope.isBlockingAnimating;

/** First scope in the chain (scope → parent → … → root) that is animating (blocking or any). */
export function firstAnimatingScope(scope: HeavyAnimationScope, blocking: boolean) {
  for (let s: HeavyAnimationScope | null = scope; s; s = s.parent) {
    if ((blocking ? s.isBlockingAnimating : s.isAnimating).peek()) return s;
  }
  return null;
}

/** Replacement for teact's useHeavyAnimation hook. */
export function onHeavyAnimation(
  onStart?: () => void,
  onEnd?: () => void,
  scope: HeavyAnimationScope = rootScope,
) {
  const listener = (animating: boolean) => (animating ? onStart?.() : onEnd?.());
  scope._listeners.add(listener);
  if (scope.isAnimating.peek()) onStart?.();
  return () => {
    scope._listeners.delete(listener);
  };
}

export function onFullyIdle(cb: () => void, scope: HeavyAnimationScope = rootScope) {
  onIdle(() => {
    const animating = firstAnimatingScope(scope, false);
    if (animating) {
      animating.isAnimating.once(() => onFullyIdle(cb, scope));
    } else {
      cb();
    }
  });
}

const HEAVY_SCOPE_KEY = Symbol('frameact.heavyAnimationScope');

/** Make `scope` the heavy-animation scope for every effect created under the current owner. */
export function provideHeavyAnimationScope(scope: HeavyAnimationScope) {
  setContext(HEAVY_SCOPE_KEY, scope);
}

export function currentHeavyAnimationScope(owner: Scope | null = getScope()): HeavyAnimationScope {
  return getContext<HeavyAnimationScope>(HEAVY_SCOPE_KEY, owner) ?? rootScope;
}
```

```ts
import { DEV } from '../env';
import {
  compute as runInScope,
  createComputation,
  handleError,
  isFunction,
  setEffectDisposeHook,
  setEffectScheduler,
  STATE_CLEAN,
  STATE_DISPOSED,
  update,
  updateCheck,
} from './core';
import { SCOPE } from './symbols';
import type { Computation } from './types';
import { onTickEnd } from '../scheduler/schedulers';
import { currentHeavyAnimationScope, type HeavyAnimationScope } from '../scheduler/heavyAnimation';

export const NOT_APPLIED: unique symbol = Symbol('frameact.notApplied');

/** Called by the core when an effect becomes dirty. Decides *when* `run` executes. */
export type Schedule = (run: () => void, node: EffectNode) => void;

export interface EffectNode<T = any> extends Computation<T> {
  _apply: (value: T, prev: T | undefined) => void | (() => void);
  _applied: T | typeof NOT_APPLIED;
  _applyCleanup: (() => void) | null;
  _schedule: Schedule;
  _scope: HeavyAnimationScope;
  _bailed: EffectNode[] | null;
  _run: () => void;
  _name: string | undefined;
  _selfDirty: number;
}

export interface EffectOptions {
  /** Dev label (compiler's sourceNames or a facade name). */
  name?: string;
  /** @internal Apply synchronously at creation (mutation effects, createSelector). */
  immediateApply?: boolean;
}

const SELF_DIRTY_LIMIT = 100;

/** The effect whose apply/compute is currently running (dev attribution for stricterdom). */
export let currentEffect: EffectNode | null = null;

export const tickEnd: Schedule = (run) => onTickEnd(run);

export function createEffect<T>(
  compute: (prev: T | undefined) => T,
  apply: (value: T, prev: T | undefined) => void | (() => void),
  schedule: Schedule = tickEnd,
  options?: EffectOptions,
): void {
  const node = createComputation<T>(undefined as T, null) as EffectNode<T>;
  node._compute = function (this: EffectNode<T>) {
    return compute(this._init ? this._value : undefined);
  };
  node._effect = true;
  node._apply = apply;
  node._applied = NOT_APPLIED;
  node._applyCleanup = null;
  node._schedule = schedule;
  node._bailed = null;
  node._name = options?.name;
  node._selfDirty = 0;
  node._scope = currentHeavyAnimationScope(node); // appended to the current owner by the constructor
  node._run = () => runEffect(node);

  // First compute: synchronous, tracked, under the owner that created the effect.
  if (!computeNode(node)) return;
  if (options?.immediateApply) applyEffect(node);
  else schedule(node._run, node);
}

/** Recompute the node's compute half. Returns false if the node died or threw. */
function computeNode(node: EffectNode): boolean {
  const outer = currentEffect;
  currentEffect = node;
  try {
    if (node._state === STATE_CLEAN && node._init) return true;
    if (node._init) updateCheck(node);
    else update(node);
    return node._state !== STATE_DISPOSED;
  } catch (error) {
    // update() already offered the error to onError handlers and re-threw: just report.
    logEffectError(node, error);
    node._state = STATE_CLEAN;
    return false;
  } finally {
    currentEffect = outer;
  }
}

function runEffect(node: EffectNode) {
  if (node._state === STATE_DISPOSED) return;

  // Ancestor rule (spec §3.2): never run an ancestor effect's compute from here.
  for (let p = node[SCOPE] as Computation | null; p !== null; p = p[SCOPE] as Computation | null) {
    if (p._effect) {
      if (p._state !== STATE_CLEAN) {
        // Its own run will dispose us (DIRTY) or release us (CHECK that resolves clean).
        ((p as EffectNode)._bailed ??= []).push(node);
        return;
      }
    } else if (p._compute && p._state !== STATE_CLEAN) {
      // A dirty memo ancestor is pulled like any read (pure); it may dispose us.
      try {
        updateCheck(p);
      } catch (error) {
        logEffectError(node, error);
      }
      if (node._state === STATE_DISPOSED) return;
    }
  }

  if (!computeNode(node)) return;
  if (node._state === STATE_CLEAN) node._selfDirty = 0;

  if (node._applied === NOT_APPLIED || node._value !== node._applied) applyEffect(node);

  releaseBailed(node);
}

function applyEffect(node: EffectNode) {
  const prev = node._applied === NOT_APPLIED ? undefined : node._applied;
  const cleanup = node._applyCleanup;
  node._applyCleanup = null;
  const outer = currentEffect;
  currentEffect = node;
  try {
    cleanup?.();
    // Untracked (observer = null), owner = the effect node so onCleanup() inside apply attaches to it.
    const result = runInScope(node, () => node._apply(node._value, prev), null);
    if (isFunction(result)) node._applyCleanup = result as () => void;
  } catch (error) {
    try {
      handleError(node, error);
    } catch (unhandled) {
      logEffectError(node, unhandled);
    }
  } finally {
    currentEffect = outer;
    node._applied = node._value;
  }
}

function releaseBailed(node: EffectNode) {
  const bailed = node._bailed;
  if (!bailed) return;
  node._bailed = null;
  for (const child of bailed) {
    if (child._state !== STATE_DISPOSED) child._schedule(child._run, child);
  }
}

function logEffectError(node: EffectNode, error: unknown) {
  console.error(`[frameact] Error in effect${node._name ? ` "${node._name}"` : ''}`, error);
}

// ---- wiring into the core -------------------------------------------------

setEffectScheduler((raw) => {
  const node = raw as EffectNode;
  if (currentEffect === node) {
    // Dirtied by a write made inside its own compute (patch 1 made this visible).
    if (DEV && ++node._selfDirty > SELF_DIRTY_LIMIT) {
      console.error(
        `[frameact] Potential infinite loop: effect${node._name ? ` "${node._name}"` : ''} re-dirtied itself ${SELF_DIRTY_LIMIT} times. Scheduling stopped.`,
      );
      return;
    }
  }
  node._schedule(node._run, node);
});

/** How an apply-cleanup runs when its effect is disposed. Task 9 replaces this to defer DOM cleanups to the mutate phase. */
let applyCleanupDisposer: (node: EffectNode, cleanup: () => void) => void = (node, cleanup) => {
  try {
    cleanup();
  } catch (error) {
    logEffectError(node, error);
  }
};
export function setApplyCleanupDisposer(fn: typeof applyCleanupDisposer) {
  applyCleanupDisposer = fn;
}

setEffectDisposeHook((raw) => {
  const node = raw as EffectNode;
  node._bailed = null;
  const cleanup = node._applyCleanup;
  if (cleanup) {
    node._applyCleanup = null;
    applyCleanupDisposer(node, cleanup);
  }
});
```

```ts
import { DEV } from '../env';
import { STATE_DISPOSED } from './core';
import {
  createEffect,
  setApplyCleanupDisposer,
  type EffectNode,
  type EffectOptions,
  type Schedule,
} from './effects';
import { getPhase, requestForcedReflow, requestMeasure, requestMutation } from '../scheduler/fasterdom';
import type { HeavyAnimationScope } from '../scheduler/heavyAnimation';

export type FramePhase = 'measure' | 'mutate' | 'reflow';

/** @internal A queued run. `node === null` for detached work (deferred apply-cleanups). */
export interface FrameEntry {
  run: () => void;
  node: EffectNode | null;
  phase: FramePhase;
}

const DRAIN_LIMIT = 10_000;

const queues: Record<FramePhase, FrameEntry[]> = { measure: [], mutate: [], reflow: [] };
const armed: Record<FramePhase, boolean> = { measure: false, mutate: false, reflow: false };
const request: Record<FramePhase, (cb: () => void) => void> = {
  measure: requestMeasure,
  mutate: requestMutation,
  reflow: (cb) => requestForcedReflow(cb),
};

/** @internal Task 10 installs gating here. Returns the scope that blocks `scope`, or null. */
export const drainHooks: {
  blockingScopeFor: (
    scope: HeavyAnimationScope,
    cache: Map<HeavyAnimationScope, HeavyAnimationScope | null>,
  ) => HeavyAnimationScope | null;
  park: (blocker: HeavyAnimationScope, entry: FrameEntry) => void;
} = {
  blockingScopeFor: () => null,
  park: () => {},
};

/** @internal used by Task 10's release path */
export function enqueue(phase: FramePhase, run: () => void, node: EffectNode | null) {
  queues[phase].push({ run, node, phase });
  if (!armed[phase]) {
    armed[phase] = true;
    request[phase](() => drain(phase));
  }
  if (DEV && phase === 'measure' && getPhase() === 'mutate') {
    console.warn(
      `[frameact] measure effect${node?._name ? ` "${node._name}"` : ''} was dirtied during the mutate phase — it will run next frame. Write that signal from a measure effect or event handler instead.`,
    );
  }
}

/** @internal */
export function isArmed(phase: FramePhase) {
  return armed[phase];
}

/** @internal Drain one phase queue. Entries added while draining are processed in this same drain. */
export function drain(phase: FramePhase) {
  const queue = queues[phase];
  const blockCache = new Map<HeavyAnimationScope, HeavyAnimationScope | null>();
  let overflow: FrameEntry[] | null = null;
  try {
    for (let i = 0; i < queue.length; i++) {
      if (i === DRAIN_LIMIT) {
        overflow = queue.slice(i);
        console.error(
          `[frameact] ${phase} drain limit (${DRAIN_LIMIT}) reached — an effect keeps re-dirtying this phase. Remaining work moved to the next frame.`,
        );
        break;
      }
      const entry = queue[i];
      if (entry.node !== null) {
        if (entry.node._state === STATE_DISPOSED) continue;
        const blocker = drainHooks.blockingScopeFor(entry.node._scope, blockCache);
        if (blocker !== null) {
          drainHooks.park(blocker, entry);
          continue;
        }
      }
      entry.run();
    }
  } finally {
    queues[phase] = [];
    armed[phase] = false;
  }
  if (overflow) for (const e of overflow) enqueue(e.phase, e.run, e.node);
}

export const frameMeasure: Schedule = (run, node) => enqueue('measure', run, node);
export const frameMutation: Schedule = (run, node) => enqueue('mutate', run, node);
export const frameForcedReflow: Schedule = (run, node) => enqueue('reflow', run, node);

/** Reads layout. First apply is scheduled (after attach), never synchronous. */
export function createMeasureEffect<T>(
  compute: (prev: T | undefined) => T,
  apply: (value: T, prev: T | undefined) => void | (() => void),
  options?: EffectOptions,
) {
  createEffect(compute, apply, frameMeasure, { name: 'measure', ...options, immediateApply: false });
}

/** Writes the live DOM. First apply is synchronous: the nodes are detached at creation. */
export function createMutationEffect<T>(
  compute: (prev: T | undefined) => T,
  apply: (value: T, prev: T | undefined) => void | (() => void),
  options?: EffectOptions,
) {
  createEffect(compute, apply, frameMutation, { name: 'mutation', ...options, immediateApply: true });
}

/** The name the compiler-facing runtime uses. */
export const createRenderEffect = createMutationEffect;

// Apply-cleanups of DOM-writing effects must run in the mutate phase even when the dispose
// happened elsewhere (a memo recomputed inside an event handler disposing a subtree).
setApplyCleanupDisposer((node, cleanup) => {
  const run = () => {
    try {
      cleanup();
    } catch (error) {
      console.error(`[frameact] Error in effect cleanup${node._name ? ` "${node._name}"` : ''}`, error);
    }
  };
  const writesDom = node._schedule === frameMutation || node._schedule === frameForcedReflow;
  if (writesDom && getPhase() !== 'mutate') enqueue('mutate', run, null);
  else run();
});
```

```ts
// ---- heavy-animation gating ----------------------------------------------

function blockingScopeFor(
  scope: HeavyAnimationScope,
  cache: Map<HeavyAnimationScope, HeavyAnimationScope | null>,
): HeavyAnimationScope | null {
  // Sampled once per drain per scope: an applier that begins an animation mid-drain
  // does not split the frame it is part of.
  const path: HeavyAnimationScope[] = [];
  for (let s: HeavyAnimationScope | null = scope; s !== null; s = s.parent) {
    const cached = cache.get(s);
    if (cached !== undefined) {
      for (const p of path) cache.set(p, cached);
      return cached;
    }
    path.push(s);
    if (s.isBlockingAnimating.peek()) {
      for (const p of path) cache.set(p, s);
      return s;
    }
  }
  for (const p of path) cache.set(p, null);
  return null;
}

function park(scope: HeavyAnimationScope, entry: FrameEntry) {
  (scope._parked as FrameEntry[]).push(entry);
  if (scope._releaseArmed) return;
  scope._releaseArmed = true;
  scope.isBlockingAnimating.once(() => {
    scope._releaseArmed = false;
    const parked = scope._parked as FrameEntry[];
    scope._parked = [];
    // Release inside a measure task so that both measure and mutate work land in the SAME
    // next frame, in phase order. Measure entries are drained right here (a requestMeasure
    // issued from within the measure phase would slip to the frame after); mutate/reflow
    // entries go through their normal queues, which run later in this frame.
    requestMeasure(() => {
      for (const e of parked) {
        if (e.node !== null && e.node._state === STATE_DISPOSED) continue;
        if (e.phase === 'measure') queues.measure.push(e);
        else enqueue(e.phase, e.run, e.node);
      }
      if (!armed.measure && queues.measure.length) drain('measure');
    });
  });
}

drainHooks.park = park;

  options?: EffectOptions,

  createEffect(compute, apply, idle, { name: 'idle', ...options, immediateApply: false });
}

/**
 * Wrap a scheduler so the run also waits for heavy animations in the node's scope chain
 * (non-blocking by default; frame queues already wait for blocking ones).
 */
export function gateOnHeavyAnimation(schedule: Schedule, options: { blocking?: boolean } = {}): Schedule {
  const blocking = options.blocking ?? false;
  const gated: Schedule = (run, node) => {
    const animating = firstAnimatingScope(node._scope, blocking);
    if (animating === null) schedule(run, node);
    else (blocking ? animating.isBlockingAnimating : animating.isAnimating).once(() => gated(run, node));
  };
  return gated;
}

/**
 * Defer creating a heavy subtree until `scope` is idle: returns `placeholder` until then,
 * then a memoized `fn()`. Scopes gate *updates*, not creation — this is the creation gate.
 */
export function deferUntilIdle<T>(scope: HeavyAnimationScope, fn: () => T, placeholder: T): () => T {
  const ready = signal(false);
  createEffect(() => undefined, () => { ready.set(true); }, (run) => onFullyIdle(run, scope), { name: 'deferUntilIdle' });
  return computed(() => (ready() ? fn() : placeholder));
}
```

```ts
// ---- frameact: keyed-by-function map -----------------------------------------

interface KeyedByData<Item, Key, Mapped> {
  _scope: Scope;
  _len: number;
  _list: ReadSignal<Maybe<readonly Item[]>>;
  _keyFn: (item: Item) => Key;
  _map: (item: ReadSignal<Item>, index: ReadSignal<number>) => Mapped;
  _keys: Key[];
  _items: Item[];
  _mappings: Mapped[];
  _itemNodes: Computation<Item>[];
  _indexNodes: Computation<number>[];
}

/**
 * Keyed map where identity is `keyFn(item)`, not the reference. The row's owner is its item
 * signal node: disposing it disposes everything the mapper created (the index node included).
 */
export function computedKeyedMapBy<Item, Key, Mapped>(
  list: ReadSignal<Maybe<readonly Item[]>>,
  keyFn: (item: Item) => Key,
  map: (item: ReadSignal<Item>, index: ReadSignal<number>) => Mapped,
  options?: { id?: string },
): ReadSignal<Mapped[]> {
  return read.bind(
    createComputation<Mapped[]>(
      [],
      updateKeyedMapBy.bind({
        _scope: createScope(),
        _len: 0,
        _list: list,
        _keyFn: keyFn,
        _map: map,
        _keys: [],
        _items: [],
        _mappings: [],
        _itemNodes: [],
        _indexNodes: [],
      } satisfies KeyedByData<Item, Key, Mapped>),
      options,
    ),
  );
}

function updateKeyedMapBy<Item, Key, Mapped>(this: KeyedByData<Item, Key, Mapped>): Mapped[] {
  const newItems = this._list() || [];
  const newLen = newItems.length;

  // Resolve keys; a duplicate falls back to an index key (like teact's `key` handling).
  const newKeys: Key[] = new Array(newLen);
  const seen = new Set<Key>();
  for (let j = 0; j < newLen; j++) {
    let key = this._keyFn(newItems[j]);
    if (seen.has(key)) {
      if (DEV) console.warn('[frameact] mapArray: duplicate key', key, '— falling back to index');
      key = `__index#${j}` as unknown as Key;
    }
    seen.add(key);
    newKeys[j] = key;
  }

  scoped(() => {
    if (newLen === 0) {
      if (this._len !== 0) {
        dispose.call(this._scope, false);
        this._keys = []; this._items = []; this._mappings = []; this._itemNodes = []; this._indexNodes = []; this._len = 0;
      }
      return;
    }

    const oldIndexByKey = new Map<Key, number>();
    for (let i = 0; i < this._len; i++) oldIndexByKey.set(this._keys[i], i);

    const mappings: Mapped[] = new Array(newLen);
    const itemNodes: Computation<Item>[] = new Array(newLen);
    const indexNodes: Computation<number>[] = new Array(newLen);
    const kept = new Uint8Array(this._len);

    for (let j = 0; j < newLen; j++) {
      const i = oldIndexByKey.get(newKeys[j]);
      if (i !== undefined && !kept[i]) {
        kept[i] = 1;
        mappings[j] = this._mappings[i];
        itemNodes[j] = this._itemNodes[i];
        indexNodes[j] = this._indexNodes[i];
        if (this._items[i] !== newItems[j]) write.call(itemNodes[j], newItems[j]);
        if (i !== j) write.call(indexNodes[j], j);
      } else {
        const itemNode = createComputation<Item>(newItems[j], null);
        let indexNode!: Computation<number>;
        itemNodes[j] = itemNode;
        mappings[j] = compute<Mapped>(
          itemNode,
          () => {
            indexNode = createComputation<number>(j, null); // owned by the row
            return this._map(read.bind(itemNode), read.bind(indexNode));
          },
          null,
        );
        indexNodes[j] = indexNode;
      }
    }

    for (let i = 0; i < this._len; i++) if (!kept[i]) dispose.call(this._itemNodes[i]);

    this._mappings = mappings;
    this._itemNodes = itemNodes;
    this._indexNodes = indexNodes;
    this._keys = newKeys;
    this._items = newItems.slice(0);
    this._len = newLen;
  }, this._scope);

  return this._mappings;
}

export interface MapArrayOptions<Item> {
  /** `true` (default): by reference; `false`: by index; a function: by key. */
  keyed?: boolean | ((item: Item) => unknown);
  id?: string;
}

export function mapArray<Item, Mapped>(
  list: ReadSignal<Maybe<readonly Item[]>>,
  mapFn: (item: any, index: any) => Mapped,
  options: MapArrayOptions<Item> = {},
): ReadSignal<Mapped[]> {
  const keyed = options.keyed ?? true;
  if (keyed === true) return computedKeyedMap(list, mapFn, options);
  if (keyed === false) return computedMap(list, mapFn, options);
  return computedKeyedMapBy(list, keyed, mapFn, options);
}
```
