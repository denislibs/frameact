# frameact DOM runtime — Implementation Plan (plan 2 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `frameact/dom` — the runtime the Solid 2.0 compiler (`@solidjs/babel-plugin@2.0.0-rc.14`, `moduleName: "frameact/dom"`) imports — plus `render`, the flow components (`For` with `order="manual"`, `Show`, `Switch`/`Match`, `Dynamic`, `Portal`), the `use:value`/`use:checked` controlled-input directives, `HeavyAnimationScope`, the context `Provider`, JSX typings, the `frameact/vite` plugin, and the compiler acceptance test — all on top of the plan-1 core (`feat/core`).

**Architecture:** Every DOM binding is a two-phase render effect: *compute* (tracked, pure, may create detached subtrees) and *apply* (untracked, no owner, the only place that writes the DOM; synchronous at creation, in the mutate drain afterwards). `insert` = compute `normalize(accessor())` / apply `insertExpression` with udomdiff `reconcileArrays`; a function value (a `For`'s row accessor, a memo) gets its **own nested render effect** so an outer conditional never tracks an inner list. Class writes (`class=`, `classList`, spread) are token diffs against an applied-set held per element, so imperative classes survive. The compiler lowers every namespaced attribute (`use:`, `on:`, `oncapture:`, `attr:`, `bool:`, `class:`, `style:`, `classList`) to `setAttribute(el, name, value)`, so `setAttribute` is the dispatcher — and the entry point of directives. Controlled inputs are directives backed by a mutation effect plus one document-level `input`/`change` listener registered *after* event delegation, so the rejected-input rollback runs synchronously after the user's handler and before paint.

**Tech Stack:** TypeScript 7 (Go-native `tsc`, strict), pnpm, Vite 8 + vitest 5 + jsdom 30, oxlint; `@babel/core` 7 + `@babel/preset-typescript` 7 + `@solidjs/babel-plugin@2.0.0-rc.14` (exact pin) for the Vite plugin and the acceptance test; `csstype` for the vendored JSX typings.

**Spec:** `docs/superpowers/specs/2026-10-11-frameact-design.md` — §3.3 (`dom`), §3.6 (`vite`), §5 (dom tests + acceptance). Context: `.superpowers/plan2-context.md`. Read both before Task 1.

## Scope decisions

Facts established while writing this plan (verified by compiling samples with `@solidjs/babel-plugin@2.0.0-rc.14`, `moduleName: 'frameact/dom'`, `builtIns: [For, Show, Switch, Match, Portal, Dynamic]`):

1. **The compiler does not emit `_$use(...)`.** `<input use:value={text}>` compiles to `_$setAttribute(el, "use:value", text)` (a one-time call with the raw expression; `text` — an accessor — is passed uncalled). `use:value={props.text}` (a member expression) compiles to an effect calling `setAttribute(el, "use:value", v)` with plain values. Likewise `on:x`, `oncapture:x`, `attr:x`, `bool:x`, `class:x`, `style:x` and `classList={…}` all compile to `setAttribute(el, "<name>", v)`; `prop:x` compiles to a direct property write. So (deviation from spec §3.3 text, same contract): **`setAttribute` dispatches on the name**, directives are resolved **by name from a registry** (`defineDirective(name, fn)`; `value`/`checked` are built in) and receive either an accessor (static form — the directive creates its own mutation effect, and only when it runs under an owner) or plain values (effect-driven form — the directive just writes). An accessor that arrives *inside an effect apply* (no owner — the compiler-wrapped `use:value={props.text}` where `props.text` is itself a function) gets a DEV `console.error` with a hint and a one-shot write instead of an owned effect (Task 8). `use(fn, el, arg)` is still exported for hand-written code. A valueless `use:tooltip` ends up inside the template HTML and never reaches the runtime — documented, unsupported.
2. **Controlled-input check timing.** The spec says "one delegated `input` listener executed after the user's handlers, synchronous rollback". Microtasks are *not* usable (a microtask checkpoint runs after each native listener, i.e. before the delegated user handler — it would roll back every keystroke). Implementation: the directive calls `delegateEvents(['input'])` and only then adds its own `document`-level `input`, `change`, `compositionstart`, `compositionend`, `focusout` listeners — listener order on `document` is registration order, so the check always runs after the delegated `onInput` dispatcher and after element-level `on:input` listeners. Caret `selectionStart/End` is read there (event time = measure phase) and stored per element; the mutate-phase applier only writes and restores from that snapshot (it never reads selection — stricterdom will forbid that in mutate).
3. **Reactive `value=`/`checked=` dev-warning "use `use:value`"**: impossible at runtime (the compiler assigns `el.value` directly). Implemented as a dev-time source lint in the Vite plugin (regex over the JSX source, `this.warn`).
4. **`For order="manual"`**: implemented as an array transform in `For`'s compute — new rows take their list index, kept rows fill the remaining slots in their previous DOM order, a kept row whose `orderKey` changed is treated as new — and the DOM-ordered array is returned to `insert`, whose `reconcileArrays` then performs only insertions/removals (contiguous runs of `insertBefore` on one anchor) and the moves for changed `orderKey`. **No `DocumentFragment`**: `For` cannot write the DOM from its compute, and letting it do so would make `insert`'s reconcile re-insert already-placed nodes (DOM moves). Benchmark criterion (0 DOM moves, stable DOM order, batch insertion) holds. Because positioning is done by `reconcileArrays` relative to the slot (not `childNodes[i]`), the "only child, no fallback" dev-assert is unnecessary and dropped; `fallback` is allowed. The transform's compute **tracks** `each()` (not only the mapped rows): when an item is replaced by one with a different `orderKey` at the same list position, `mapArray` returns the very same rows array, and only the tracked `each()` triggers the recompute that moves the row.
5. **`className=` on intrinsic elements** → `setAttribute(el, 'className', v)` → DEV `console.error('use class')` and the value is still applied through the token diff (so the app keeps working).
6. **Deferred items from the brief**: *included* — the DOM security minimum (text via text nodes, URL protocol allowlist on URL attributes, no string event handlers, spread reads own enumerable keys only, HTML only via explicit `innerHTML`/`template()`). *Excluded (core/other plans)*: `flushSync` reentrancy inside a pass, `update()` catch skipping `checkNewSources`, keyed-map rollback with a throwing custom scheduler, prod warning for `onCleanup` inside apply, `setErrorReporter` (belongs with plan-4 attribution), a prod-bundle "no DEV strings" test (no build step exists yet; plan 5 adds one), Trusted Types and `rel=noopener` (modern browsers imply `noopener` for `target=_blank`).
7. **Not included (spec lists them nowhere for v1):** `splitProps`, `lazy`, hydration, `dynamicProperty` (1.x-only compiler helper; 2.0 does not emit it), `Loading`/`Reveal`/`Errored`/`Repeat` built-ins (explicitly excluded by §3.6).
8. **Core touch-ups in this plan:** `createContext` gains `Provider` (core-only primitives; exported from `frameact`), `useContext` uses an `in` check so a provided `undefined` is honoured (brief); nothing else in `src/core` changes.
9. **Unit tests are plain `.ts`** calling the runtime exactly as the compiler emits it (`insert`, `createComponent(For, {...})`, `setAttribute(el, 'use:value', sig)`), so each task tests the real contract without the plugin. The plugin pipeline is covered by one `.tsx` smoke test (Task 12) and the fixture acceptance test (Task 13).

```ts
// Adapted from solidjs/solid packages/web/src/client.ts (MIT, © 2016-2025 Ryan Carniato) and
// dom-expressions packages/dom-expressions/src/client.js (MIT, © 2017 Ryan Carniato).
import { DEV } from '../env';

export type TemplateFactory = () => Element;

/**
 * The only innerHTML sink in the runtime: `html` is the compiler's static template string, never
 * runtime data.
 */
function create(html: string, flag: 1 | 2 | undefined): Element {
  if (DEV && /^<(html|head|body)[\s>]/i.test(html)) {
    throw new Error('[frameact] Document shell templates (<html>, <head>, <body>) cannot be client-created.');
  }
  const t = document.createElement('template');
  t.innerHTML = html;
  const root = t.content.firstChild as Element;
  return flag === 2 ? (root.firstChild as Element) : root;
}

/**
 * Compiler primitive. `flag` 1 → clone with `document.importNode` (custom elements must be
 * upgraded); 2 → the html is wrapped in a namespace element (`<svg>…</svg>`) that is stripped.
 */
export function template(html: string, flag?: 1 | 2): TemplateFactory {
  let node: Element | undefined;
  return flag === 1
    ? () => document.importNode((node ??= create(html, flag)), true)
    : () => (node ??= create(html, flag)).cloneNode(true) as Element;
}
```

```ts
import { installFakeRaf } from './raf';
import { frame as fireFrame } from './frame';
import { flushMicrotasks } from './micro';

/**
 * Per-file DOM harness: fake rAF (frames fire only through `frame()`), pending frames drained in
 * afterEach (fasterdom/fastRaf throttle state is module-global), body cleared.
 */
export function useDomHarness() {
  let raf: ReturnType<typeof installFakeRaf>;
  beforeEach(() => {
    raf = installFakeRaf();
  });
  afterEach(async () => {
    for (let i = 0; i < 10 && raf.pending(); i++) {
      raf.frame();
      await flushMicrotasks();
    }
    raf.uninstall();
    document.body.textContent = '';
  });
  return {
    frame: () => fireFrame(raf),
    pending: () => raf.pending(),
  };
}

/** An attached, empty container. */
export function container(): HTMLDivElement {
  const el = document.createElement('div');
  document.body.appendChild(el);
  return el;
}
```

### Task 2: `insert` — normalize/flatten, nested effects for function values, `insertExpression`, `reconcileArrays`, `render`

The riskiest piece. Compute = `normalize(accessor())` (tracked, creates subtrees); apply = `insertExpression` (DOM write). A function value gets its own render effect **created inside the outer compute** (owned by it, disposed when the outer recomputes), so `{cond() ? <For/> : null}` tracks only `cond()` in the outer effect.

```ts
// Adapted from solidjs/solid packages/web/src/reconcile.ts (MIT, © 2016-2025 Ryan Carniato),
// itself a modified https://github.com/WebReflection/udomdiff (ISC, © 2020 Andrea Giammarchi).

/** Nodes inserted under a marker are tagged with it: a node that migrated to another slot of the same parent is not ours. */
export const SLOT: unique symbol = Symbol('frameact.slot');

function ownedBy(n: any, parentNode: any, marker: any): boolean {
  if (!n) return false;
  const tag = n[SLOT];
  return n.parentNode === parentNode && (!tag || tag === marker);
}

/** Diff `a` (current nodes) → `b` (next nodes) inside `parentNode`, minimal moves. `a` must be non-empty. */
export function reconcileArrays(parentNode: any, a: any[], b: any[], marker?: Node | null): void {
  const bLength = b.length;
  let aEnd = a.length,
    bEnd = bLength,
    aStart = 0,
    bStart = 0,
    map: Map<any, number> | null = null;
  const tail = a[aEnd - 1];
  const after = ownedBy(tail, parentNode, marker) ? tail.nextSibling : marker || null;

  while (aStart < aEnd || bStart < bEnd) {
    // common prefix
    if (a[aStart] === b[bStart] && ownedBy(a[aStart], parentNode, marker)) {
      aStart++;
      bStart++;
      continue;
    }
    // common suffix
    while (a[aEnd - 1] === b[bEnd - 1] && ownedBy(a[aEnd - 1], parentNode, marker)) {
      aEnd--;
      bEnd--;
    }
    if (aEnd === aStart) {
      // append
      let node: any;
      if (bEnd < bLength) {
        if (bStart) {
          const prev = b[bStart - 1];
          node = ownedBy(prev, parentNode, marker) ? prev.nextSibling : after;
        } else node = b[bEnd - bStart];
      } else node = after;
      while (bStart < bEnd) {
        const n = b[bStart++];
        parentNode.insertBefore(n, node);
        if (marker) n[SLOT] = marker;
      }
    } else if (bEnd === bStart) {
      // remove
      while (aStart < aEnd) {
        const n = a[aStart++];
        if ((!map || !map.has(n)) && ownedBy(n, parentNode, marker)) n.remove();
      }
    } else if (a[aStart] === b[bEnd - 1] && b[bStart] === a[aEnd - 1] && ownedBy(a[aStart], parentNode, marker)) {
      // swap backward: walk inward with a stable front anchor
      const anchor = a[aStart];
      do {
        const n = a[--aEnd];
        parentNode.insertBefore(n, anchor);
        if (marker) n[SLOT] = marker;
        bStart++;
        if (aStart >= aEnd - 1 || bStart >= bEnd) break;
      } while (a[aStart] === b[bEnd - 1] && b[bStart] === a[aEnd - 1]);
    } else {
      // fallback to map
      if (!map) {
        map = new Map();
        let i = bStart;
        while (i < bEnd) map.set(b[i], i++);
      }
      const index = map.get(a[aStart]);
      if (index != null) {
        if (bStart < index && index < bEnd) {
          let i = aStart,
            sequence = 1,
            t: number | undefined;
          while (++i < aEnd && i < bEnd) {
            if ((t = map.get(a[i])) == null || t !== index + sequence) break;
            sequence++;
          }
          if (sequence > index - bStart) {
            const head = a[aStart];
            const node = ownedBy(head, parentNode, marker) ? head : after;
            while (bStart < index) {
              const n = b[bStart++];
              parentNode.insertBefore(n, node);
              if (marker) n[SLOT] = marker;
            }
          } else {
            const oldNode = a[aStart++];
            const newNode = b[bStart++];
            if (ownedBy(oldNode, parentNode, marker)) parentNode.replaceChild(newNode, oldNode);
            else parentNode.insertBefore(newNode, after);
            if (marker) newNode[SLOT] = marker;
          }
        } else aStart++;
      } else {
        const n = a[aStart++];
        if (ownedBy(n, parentNode, marker)) n.remove();
      }
    }
  }
}
```

```ts
// Adapted from solidjs/solid packages/web/src/client.ts (MIT, © 2016-2025 Ryan Carniato) and
// dom-expressions packages/dom-expressions/src/client.js (MIT, © 2017 Ryan Carniato).
// frameact: `insert` is a two-phase render effect — compute = normalize (pure; creates subtrees on
// detached DOM), apply = insertExpression (the DOM write: synchronous at creation, mutate phase later).
import { DEV } from '../env';
import { createRenderEffect } from '../core/frame';
import type { EffectOptions } from '../core/effects';
import { reconcileArrays, SLOT } from './reconcile';

// No `Document`: lib.dom types its `textContent` as a read-only `null`, and mounting into a Document is meaningless anyway.
export type MountableElement = Element | ShadowRoot | DocumentFragment;

export interface InsertOptions {
  /** Portal: the slot's logical host. Inserted top-level nodes get a `_$host` getter for event retargeting. */
  host?: () => Node | null;
  /** Dev label from the compiler's sourceNames (`div.children`). */
  name?: string;
}

/** Returned by the outer insert compute when a nested effect owns the slot (its apply then does nothing). */
const INNER_OWNED: unique symbol = Symbol('frameact.innerOwned');
/** Compiler/portal contract: a getter on portal content nodes pointing at the logical parent. */
export const HOST_KEY = '_$host';
const HOST_TAG: unique symbol = Symbol('frameact.hostTag');

/**
 * Resolve nested accessors and arrays. Functions with parameters (row mappers) are values, not
 * accessors. `doNotUnwrap`: keep a top-level function (and any function inside an array — the
 * array then resolves to a wrapper function) so the caller can give it its own effect.
 */
export function flatten(children: any, skipNonRendered: boolean, doNotUnwrap: boolean): any {
  if (typeof children === 'function' && !children.length) {
    if (doNotUnwrap) return children;
    do children = children();
    while (typeof children === 'function' && !children.length);
  }
  if (skipNonRendered && (children == null || children === true || children === false || children === '')) {
    return undefined;
  }
  if (Array.isArray(children)) {
    const results: any[] = [];
    if (flattenArray(children, results, skipNonRendered, doNotUnwrap)) {
      return () => {
        const nested: any[] = [];
        flattenArray(results, nested, skipNonRendered, false);
        return nested;
      };
    }
    return results;
  }
  return children;
}

function flattenArray(children: any[], results: any[], skipNonRendered: boolean, doNotUnwrap: boolean): boolean {
  let needsUnwrap = false;
  for (let i = 0; i < children.length; i++) {
    let child = children[i];
    if (typeof child === 'function' && !child.length) {
      if (doNotUnwrap) {
        results.push(child);
        needsUnwrap = true;
        continue;
      }
      do child = child();
      while (typeof child === 'function' && !child.length);
    }
    if (Array.isArray(child)) {
      needsUnwrap = flattenArray(child, results, skipNonRendered, doNotUnwrap) || needsUnwrap;
    } else if (skipNonRendered && (child == null || child === true || child === false || child === '')) {
      // not rendered
    } else results.push(child);
  }
  return needsUnwrap;
}

/** Compute-half value shape: primitives stay raw (text nodes are materialised in the apply, reusing positional ones). */
export function normalize(value: any, multi: boolean, doNotUnwrap: boolean): any {
  value = flatten(value, true, doNotUnwrap);
  if (doNotUnwrap && typeof value === 'function') return value;
  if (multi && !Array.isArray(value)) value = [value != null ? value : ''];
  return value;
}

/**
 * Compiler primitive. `marker === undefined`: the hole is the element's only content (root mode:
 * textContent fast path). `marker` a node or `null`: multi mode, content lives before the marker
 * (`null` = at the end).
 */
export function insert(
  parent: MountableElement,
  accessor: unknown,
  marker?: Node | null,
  initial?: unknown,
  options?: InsertOptions,
): void {
  const multi = marker !== undefined;
  const host = options?.host;
  if (multi && !initial) initial = [];
  if (typeof accessor !== 'function') {
    const value = normalize(accessor, multi, true);
    if (typeof value !== 'function') {
      const inserted = insertExpression(parent, value, initial, marker);
      if (host) tagHost(inserted, host);
      return;
    }
    accessor = value;
  }
  if (multi && (initial as unknown[]).length === 0) {
    const placeholder = document.createTextNode('');
    parent.insertBefore(placeholder, marker ?? null);
    initial = [placeholder];
  }
  let current: any = initial;
  const effectOptions: EffectOptions | undefined = options?.name === undefined ? undefined : { name: options.name };
  const read = accessor as () => unknown;
  createRenderEffect<any>(
    () => {
      const value = normalize(read(), multi, true);
      if (typeof value !== 'function') return value;
      // A function value (a For's row accessor, a memo, a fragment holding one) gets its own effect:
      // the outer tracks only what produced the function. Owned by this compute → disposed when the
      // outer recomputes.
      createRenderEffect<any>(
        () => normalize(value, multi, false),
        (inner) => {
          current = insertExpression(parent, inner, current, marker);
          if (host) tagHost(current, host);
        },
        effectOptions,
      );
      return INNER_OWNED;
    },
    (value) => {
      if (value === INNER_OWNED) return;
      current = insertExpression(parent, value, current, marker);
      if (host) tagHost(current, host);
    },
    effectOptions,
  );
}

/** Apply half: write `value` into the slot described by `current`, return the new `current`. */
export function insertExpression(parent: MountableElement, value: any, current: any, marker?: Node | null): any {
  if (value === current) return value;
  const t = typeof value;
  const multi = marker !== undefined;

  if (t === 'string' || t === 'number') {
    const text = String(value);
    if (multi) {
      // Direct callers only: insert() wraps primitives into an array in multi mode.
      let node = Array.isArray(current) ? current[0] : undefined;
      if (node && node.nodeType === 3) {
        if (node.data !== text) node.data = text;
      } else node = document.createTextNode(text);
      return cleanChildren(parent, current, marker, node);
    }
    const tc = typeof current;
    const first = parent.firstChild;
    if ((tc === 'string' || tc === 'number') && current !== '' && first && first.nodeType === 3) {
      (first as Text).data = text;
    } else parent.textContent = text;
    return value;
  }
  if (value == null || t === 'boolean') return cleanChildren(parent, current, marker);
  if (t === 'function') {
    if (DEV) console.error('[frameact] insertExpression: unexpected function value (normalize first)', value);
    return current;
  }
  if (Array.isArray(value)) {
    const currentArray = Array.isArray(current);
    for (let i = 0; i < value.length; i++) {
      const item = value[i];
      const ti = typeof item;
      if (ti === 'string' || ti === 'number') {
        const text = String(item);
        const prev = currentArray ? current[i] : undefined;
        if (prev && prev.nodeType === 3) {
          if (prev.data !== text) prev.data = text;
          value[i] = prev;
        } else value[i] = document.createTextNode(text);
      } else if (item == null || !item.nodeType) {
        // Not renderable: a function with parameters (a row mapper is a value, not an accessor), a plain
        // object, a stray null. Placing it into the DOM would throw `insertBefore: not of type Node`, so it
        // renders as nothing (Solid 2.0's client.ts has no such guard and throws).
        if (DEV) console.warn('[frameact] Unrecognized child value. Rendered as nothing', item);
        value[i] = document.createTextNode('');
      }
    }
    if (value.length === 0) {
      cleanChildren(parent, current, marker);
    } else if (currentArray) {
      if (current.length === 0) appendNodes(parent, value, marker ?? null);
      else reconcileArrays(parent, current, value, marker);
    } else {
      if (current != null && current !== '') {
        if (!multi) parent.textContent = '';
        else if (current.nodeType && current.parentNode === parent) current.remove();
      }
      appendNodes(parent, value, marker ?? null);
    }
    return value;
  }
  if (value.nodeType) {
    if (Array.isArray(current)) {
      cleanChildren(parent, current, multi ? marker : null, value);
    } else if (current != null && current.nodeType) {
      if (current.parentNode === parent) parent.replaceChild(value, current);
      else parent.insertBefore(value, marker ?? null);
    } else if (current != null && current !== '' && parent.firstChild) {
      // a sole text child holds the previous primitive (`0`/`NaN` are falsy, hence `!= null`)
      parent.replaceChild(value, parent.firstChild);
    } else parent.insertBefore(value, marker ?? null);
    if (marker) value[SLOT] = marker;
    return value;
  }
  if (DEV) console.warn('[frameact] Unrecognized value. Skipped inserting', value);
  return current;
}

/** Remove the slot's nodes (optionally replacing them with one node). Returns the new `current`. */
function cleanChildren(parent: MountableElement, current: any, marker?: Node | null, replacement?: any): any {
  if (marker === undefined) {
    parent.textContent = '';
    if (replacement) parent.appendChild(replacement);
    return replacement ?? '';
  }
  const list: any[] = Array.isArray(current) ? current : current != null && current !== '' ? [current] : [];
  if (list.length) {
    let inserted = false;
    for (let i = list.length - 1; i >= 0; i--) {
      const el = list[i];
      if (replacement !== el) {
        const tag = el[SLOT];
        const owns = el.parentNode === parent && (!tag || tag === marker);
        if (replacement && !inserted && !i) {
          if (owns) parent.replaceChild(replacement, el);
          else parent.insertBefore(replacement, marker);
        } else if (owns) el.remove();
      } else inserted = true;
    }
  } else if (replacement) parent.insertBefore(replacement, marker);
  if (replacement && marker) replacement[SLOT] = marker;
  return replacement ? [replacement] : [];
}

function appendNodes(parent: MountableElement, array: any[], marker: Node | null): void {
  for (let i = 0; i < array.length; i++) {
    const n = array[i];
    parent.insertBefore(n, marker);
    if (marker) n[SLOT] = marker;
  }
}

/** Portal content: top-level nodes learn their logical host (delegated events bubble through it). */
function tagHost(value: any, host: () => Node | null): void {
  if (Array.isArray(value)) {
    for (let i = 0; i < value.length; i++) tagHost(value[i], host);
  } else if (value && value.nodeType && value[HOST_TAG] !== host) {
    value[HOST_TAG] = host;
    Object.defineProperty(value, HOST_KEY, { get: host, configurable: true });
  }
}
```

```ts
import { DEV } from '../env';
import { createRoot } from '../index';
import { insert, type MountableElement } from './insert';
import { strictHooks } from './strict';

/**
 * Mount `code()` into `element` (appended after existing children). Synchronous: the root insert's
 * first apply runs at creation; the write into an attached container goes through the stricterdom
 * seam. Returns a disposer that also clears the container.
 */
export function render(code: () => unknown, element: MountableElement, init?: unknown): () => void {
  if (DEV && !element) {
    throw new Error("[frameact] render(): the container element doesn't exist. Make sure it is in the document.");
  }
  let disposer!: () => void;
  strictHooks.forceMutation(() => {
    createRoot((dispose) => {
      disposer = dispose;
      insert(element, code(), element.firstChild ? null : undefined, init);
    });
  }, element);
  return () => {
    disposer();
    strictHooks.forceMutation(() => {
      element.textContent = '';
    }, element);
  };
}
```

```ts
// Adapted from dom-expressions / solid-js mergeProps semantics (MIT, © 2017 Ryan Carniato).

export type PropsSource =
  | Record<PropertyKey, any>
  | (() => Record<PropertyKey, any> | null | undefined | false)
  | null
  | undefined
  | false;

/** A function source is resolved on every access (its key set may change). */
export function resolveSource(source: PropsSource): Record<PropertyKey, any> | null {
  const resolved = typeof source === 'function' ? source() : source;
  return resolved || null;
}

function getFrom(sources: PropsSource[], key: PropertyKey): unknown {
  for (let i = sources.length - 1; i >= 0; i--) {
    const s = resolveSource(sources[i]);
    if (s && key in s) {
      const v = s[key];
      if (v !== undefined) return v;
    }
  }
  return undefined;
}

function hasIn(sources: PropsSource[], key: PropertyKey): boolean {
  for (let i = sources.length - 1; i >= 0; i--) {
    const s = resolveSource(sources[i]);
    if (s && key in s) return true;
  }
  return false;
}

function keysOf(sources: PropsSource[]): string[] {
  const keys = new Set<string>();
  for (const source of sources) {
    const s = resolveSource(source);
    if (s) for (const key of Object.keys(s)) keys.add(key);
  }
  return [...keys];
}

/**
 * Compiler primitive: merge props objects right-to-left (later wins, `undefined` falls through to an
 * earlier source), keeping getters lazy. With a function source the result is a Proxy whose key set
 * follows the source; otherwise a plain object of getters.
 */
export function mergeProps(...sources: PropsSource[]): any {
  if (sources.some((s) => typeof s === 'function')) {
    return new Proxy({} as Record<PropertyKey, unknown>, {
      get: (_target, key) => getFrom(sources, key),
      has: (_target, key) => hasIn(sources, key),
      ownKeys: () => keysOf(sources),
      getOwnPropertyDescriptor: (_target, key) =>
        hasIn(sources, key)
          ? { configurable: true, enumerable: true, get: () => getFrom(sources, key) }
          : undefined,
    });
  }
  const target: Record<string, unknown> = {};
  for (const key of keysOf(sources)) {
    Object.defineProperty(target, key, { configurable: true, enumerable: true, get: () => getFrom(sources, key) });
  }
  return target;
}
```

```ts
import { createMemo, mapArray, untrack } from '../index';

export type Accessor<T> = () => T;
export type Each<T> = readonly T[] | undefined | null | false;

export interface ForBaseProps<T> {
  each: Each<T>;
  /** Rendered while the list is empty (created under For's owner, disposed when rows arrive). */
  fallback?: unknown;
}

/**
 * `<For each keyed fallback>` over `mapArray` (spec §3.3 "Списки"). `keyed` defaults to `true`
 * (identity by reference); `false` maps by index (item is an accessor); a function keys by
 * `keyFn(item)` — the pattern for immutable data: a replaced object with the same key updates the
 * row in place and `insert` sees no array change.
 */
export function For<T>(
  props: ForBaseProps<T> & { keyed?: true; children: (item: T, index: Accessor<number>) => unknown },
): unknown;
export function For<T>(
  props: ForBaseProps<T> & { keyed: false; children: (item: Accessor<T>, index: number) => unknown },
): unknown;
export function For<T>(
  props: ForBaseProps<T> & {
    keyed: (item: T) => unknown;
    children: (item: Accessor<T>, index: Accessor<number>) => unknown;
  },
): unknown;
export function For<T>(
  props: ForBaseProps<T> & { keyed?: boolean | ((item: T) => unknown); children: (item: any, index: any) => unknown },
): unknown {
  const rows = mapArray<T, unknown>(() => props.each, props.children, { keyed: props.keyed });
  if (!('fallback' in props)) return rows;
  return createMemo(() => {
    const list = rows();
    return list.length === 0 ? untrack(() => props.fallback) : list;
  });
}
```

```ts
export interface ForBaseProps<T> {

  /** Rendered while the list is empty (created under For's owner, disposed when rows arrive). */
  fallback?: unknown;
  /**
   * `manual`: the DOM order is not the list order. Kept rows stay where they are, new rows are
   * inserted at their list index, and a kept row moves only when its `orderKey` changes. For lists
   * whose visual order is a CSS transform of `index()` (ChatList): zero DOM moves on reorder.
   */
  order?: 'manual';
  /** Computed per item, untracked, whenever `each` changes (it is not reactive on its own); a changed key moves that row to its list index. */
  orderKey?: (item: T) => unknown;
}

export function For<T>(
  props: ForBaseProps<T> & { keyed?: true; children: (item: T, index: Accessor<number>) => unknown },
): unknown;
export function For<T>(
  props: ForBaseProps<T> & { keyed: false; children: (item: Accessor<T>, index: number) => unknown },
): unknown;
export function For<T>(
  props: ForBaseProps<T> & {
    keyed: (item: T) => unknown;
    children: (item: Accessor<T>, index: Accessor<number>) => unknown;
  },
): unknown;
export function For<T>(
  props: ForBaseProps<T> & { keyed?: boolean | ((item: T) => unknown); children: (item: any, index: any) => unknown },
): unknown {
  const mapped = mapArray<T, unknown>(() => props.each, props.children, { keyed: props.keyed });
  const rows = props.order === 'manual' ? manualOrder(mapped, () => props.each, () => props.orderKey) : mapped;
  if (!('fallback' in props)) return rows;
  return createMemo(() => {
    const list = rows();
    return list.length === 0 ? untrack(() => props.fallback) : list;
  });
}

let warnedManualRow = false;

/**
 * The array handed to `insert` is in DOM order. `reconcileArrays` then performs only insertions,
 * removals and the moves caused by an `orderKey` change — never a reorder of kept rows.
 */
function manualOrder<T>(
  mapped: () => unknown[],
  each: () => Each<T>,
  orderKey: () => ((item: T) => unknown) | undefined,
): () => unknown[] {
  let prevOrder: unknown[] = [];
  let prevKeys = new Map<unknown, unknown>();
  return createMemo(() => {
    const rows = mapped(); // list order; row identity is stable per key (mapArray)
    // Tracked on purpose: when only an item's orderKey changes (same ids at the same list positions),
    // mapArray returns the very same rows array, so reading `each()` is what re-runs this memo and
    // lets the changed row move.
    const items = each() || [];
    const keyFn = untrack(orderKey);
    const prevSet = new Set(prevOrder);
    const nextKeys = new Map<unknown, unknown>();
    const moved = new Set<unknown>();
    for (let j = 0; j < rows.length; j++) {
      const row = rows[j];
      if (DEV && !warnedManualRow && row != null && !(row as Node).nodeType) {
        warnedManualRow = true;
        console.error('[frameact] <For order="manual">: every row must be a single DOM node', row);
      }
      if (!keyFn) continue;
      const key = untrack(() => keyFn(items[j]));
      nextKeys.set(row, key);
      if (prevSet.has(row) && prevKeys.get(row) !== key) moved.add(row);
    }
    const rowSet = new Set(rows);
    const kept: unknown[] = [];
    for (const row of prevOrder) if (rowSet.has(row) && !moved.has(row)) kept.push(row);
    const out: unknown[] = [];
    let k = 0;
    for (let j = 0; j < rows.length; j++) {
      const row = rows[j];
      out.push(prevSet.has(row) && !moved.has(row) ? kept[k++] : row);
    }
    prevOrder = out;
    prevKeys = nextKeys;
    return out;
  });
}
```

```ts
// Token-diff class writes (spec §3.3). Class-shape handling adapted from solidjs/solid
// packages/web/src/client.ts (MIT, © 2016-2025 Ryan Carniato); extra-class helpers mirror teact's
// addExtraClass/removeExtraClass/toggleExtraClass (MIT, © 2022 Alexander Zinchuk) without its registry.
//
// The set of tokens a binding applied lives on the element (WeakMap). Every write path — `class=`,
// `classList=`, spreads — adds/removes only the tokens that changed, so imperative classes
// (addExtraClass, third-party code) survive reactive updates. `class` and `classList` are two
// independent channels; `class:x` toggles are per token and tracked by neither. The channels share
// the element's one DOM token list: a token that BOTH channels (or `class:x`) apply is removed as
// soon as either of them drops it. Keep the tokens of the channels disjoint.

interface Applied {
  raw: unknown;
  tokens: Set<string>;
}

const classChannel = new WeakMap<Element, Applied>();
const classListChannel = new WeakMap<Element, Applied>();
const WHITESPACE = /\s/;
const SPLIT = /\s+/;

function addTokens(str: string, out: Set<string>): void {
  if (!str) return;
  if (!WHITESPACE.test(str)) {
    out.add(str);
    return;
  }
  for (const token of str.split(SPLIT)) if (token) out.add(token);
}

/** Collect the tokens of a class value: string | number | { token: truthy } | nested arrays; booleans/null ignored. */
export function classTokens(value: unknown, out: Set<string>): void {
  if (value == null || typeof value === 'boolean') return;
  if (typeof value === 'string') return addTokens(value, out);
  if (typeof value === 'number') return addTokens(String(value), out);
  if (Array.isArray(value)) {
    for (const item of value) classTokens(item, out);
    return;
  }
  if (typeof value === 'object') {
    const record = value as Record<string, unknown>;
    for (const key in record) if (key && key !== 'undefined' && record[key]) addTokens(key, out);
  }
}

function applyTokens(node: Element, channel: WeakMap<Element, Applied>, value: unknown): void {
  const state = channel.get(node);
  // Same primitive as last time (merged effects call className unconditionally): nothing to do.
  if (state && state.raw === value && (typeof value !== 'object' || value === null)) return;
  const next = new Set<string>();
  classTokens(value, next);
  const list = node.classList;
  if (state) {
    for (const token of state.tokens) if (!next.has(token)) list.remove(token);
    for (const token of next) if (!state.tokens.has(token)) list.add(token);
    state.raw = value;
    state.tokens = next;
  } else {
    for (const token of next) list.add(token);
    channel.set(node, { raw: value, tokens: next });
  }
}

/**
 * Compiler primitive for `class=`. `prev` (the compiler's previous compute value) is accepted for
 * signature parity; the element's applied set is authoritative so spreads and `setAttribute` share it.
 */
export function className(node: Element, value: unknown, _prev?: unknown): void {
  applyTokens(node, classChannel, value);
}

/** `classList={{ token: boolean }}` — same diff, its own channel. */
export function classList(node: Element, value: unknown): void {
  applyTokens(node, classListChannel, value);
}

/** `class:name={bool}` — one binding per token. */
export function toggleClassToken(node: Element, name: string, on: boolean): void {
  if (!WHITESPACE.test(name)) {
    if (name) node.classList.toggle(name, on);
    return;
  }
  for (const token of name.split(SPLIT)) if (token) node.classList.toggle(token, on);
}

// Imperative helpers (teact API). Thin: reactive writes only touch their own tokens.
export function addExtraClass(el: Element, cls: string): void {
  el.classList.add(cls);
}
export function removeExtraClass(el: Element, cls: string): void {
  el.classList.remove(cls);
}
export function toggleExtraClass(el: Element, cls: string, force?: boolean): void {
  el.classList.toggle(cls, force);
}
```

```ts
// Adapted from solidjs/solid packages/web/src/client.ts style() (MIT, © 2016-2025 Ryan Carniato);
// setExtraStyles mirrors teact (MIT, © 2022 Alexander Zinchuk).
//
// Object form: per-property diff against the declarations this binding applied (held on the
// element), so imperative styles survive. String form: `cssText` — documented as incompatible with
// `setExtraStyles` (a cssText write replaces everything).

const appliedStyles = new WeakMap<Element, Record<string, unknown>>();

type Styled = Element & { style: CSSStyleDeclaration };

/** Compiler primitive for `style=`. */
export function style(node: Element, value: unknown, prev?: unknown): void {
  const nodeStyle = (node as Styled).style;
  const applied = appliedStyles.get(node);
  if (!value) {
    if (typeof prev === 'string') nodeStyle.cssText = '';
    if (applied) {
      for (const name in applied) nodeStyle.removeProperty(name);
      appliedStyles.delete(node);
    }
    return;
  }
  if (typeof value === 'string') {
    if (applied) appliedStyles.delete(node);
    nodeStyle.cssText = value;
    return;
  }
  if (typeof prev === 'string') nodeStyle.cssText = '';
  const next: Record<string, unknown> = {};
  const obj = value as Record<string, unknown>;
  if (applied) {
    for (const name in applied) if (!(name in obj) || obj[name] == null) nodeStyle.removeProperty(name);
  }
  for (const name in obj) {
    const v = obj[name];
    if (v == null) continue;
    if (!applied || applied[name] !== v) nodeStyle.setProperty(name, String(v));
    next[name] = v;
  }
  appliedStyles.set(node, next);
}

/** Compiler primitive for `style:name=` and inline style literals. */
export function setStyleProperty(node: Element, name: string, value: unknown): void {
  const nodeStyle = (node as Styled).style;
  if (value == null) nodeStyle.removeProperty(name);
  else nodeStyle.setProperty(name, String(value));
}

/** Imperative styles (teact API): camelCase properties are assigned, `--custom` ones set; null removes. */
export function setExtraStyles(el: Element, styles: Record<string, string | number | null | undefined>): void {
  const nodeStyle = (el as Styled).style;
  for (const name in styles) {
    const v = styles[name];
    if (name.startsWith('--')) {
      if (v == null) nodeStyle.removeProperty(name);
      else nodeStyle.setProperty(name, String(v));
    } else (nodeStyle as unknown as Record<string, string>)[name] = v == null ? '' : String(v);
  }
}
```

```ts
// Adapted from dom-expressions packages/dom-expressions/src/client.js (MIT, © 2017 Ryan Carniato):
// event delegation on `document`; handlers live on nodes under the compiler's `_$$<event>` keys.
import { HOST_KEY } from './insert';

/** Compiler contract: `el._$$click = handler`, `el._$$clickData = data` (accessed as strings: oxlint no-underscore-dangle). */
export const EVENT_KEY = '_$$';

const delegated = new WeakMap<Document, Set<string>>();
const clearHooks = new Set<(doc: Document) => void>();

/** Compiler primitive: attach one document listener per event type (idempotent). */
export function delegateEvents(eventNames: readonly string[], doc: Document = window.document): void {
  let names = delegated.get(doc);
  if (!names) delegated.set(doc, (names = new Set()));
  for (const name of eventNames) {
    if (!names.has(name)) {
      names.add(name);
      doc.addEventListener(name, eventHandler);
    }
  }
}

/** Tests/teardown: remove every delegated listener (and whatever registered through `onClearDelegated`). */
export function clearDelegatedEvents(doc: Document = window.document): void {
  const names = delegated.get(doc);
  if (names) {
    for (const name of names) doc.removeEventListener(name, eventHandler);
    delegated.delete(doc);
  }
  for (const hook of clearHooks) hook(doc);
}

/** Modules that add their own document listeners next to delegation (controlled inputs) clean up here. */
export function onClearDelegated(fn: (doc: Document) => void): void {
  clearHooks.add(fn);
}

/** Compiler primitive: `addEvent(el, name, handler, delegate)`; tuple handlers carry bound data. */
export function addEvent(node: Element, name: string, handler: unknown, delegate?: boolean): void {
  const target = node as unknown as Record<string, unknown>;
  if (delegate) {
    if (Array.isArray(handler)) {
      target[EVENT_KEY + name] = handler[0];
      target[EVENT_KEY + name + 'Data'] = handler[1];
    } else {
      target[EVENT_KEY + name] = handler;
      target[EVENT_KEY + name + 'Data'] = undefined; // a plain handler replaces a tuple's data
    }
    return;
  }
  if (Array.isArray(handler)) {
    const fn = handler[0] as (data: unknown, e: Event) => void;
    node.addEventListener(name, (handler[0] = (e: Event) => fn.call(node, handler[1], e)));
  } else {
    node.addEventListener(
      name,
      handler as EventListener,
      typeof handler === 'function' ? undefined : (handler as AddEventListenerOptions),
    );
  }
}

const listeners = new WeakMap<Element, Map<string, EventListenerOrEventListenerObject>>();

/** `on:name` / `oncapture:name`: a native listener per element and name, replaced or removed on update. */
export function setListener(node: Element, name: string, value: unknown, capture: boolean): void {
  let map = listeners.get(node);
  const key = capture ? `c:${name}` : name;
  const prev = map?.get(key);
  if (prev) {
    node.removeEventListener(name, prev, capture || (typeof prev === 'function' ? undefined : (prev as EventListenerOptions)));
    map!.delete(key);
  }
  if (!value) return;
  if (!map) listeners.set(node, (map = new Map()));
  const listener = value as EventListenerOrEventListenerObject;
  map.set(key, listener);
  node.addEventListener(name, listener, capture || (typeof listener === 'function' ? undefined : (listener as AddEventListenerOptions)));
}

function eventHandler(e: Event): void {
  let node: any = e.target;
  const key = EVENT_KEY + e.type;
  const oriTarget = e.target;
  const oriCurrentTarget = e.currentTarget;
  const retarget = (value: unknown) => Object.defineProperty(e, 'target', { configurable: true, value });
  const handleNode = (): boolean => {
    const handler = node[key];
    if (handler && !node.disabled) {
      const data = node[`${key}Data`];
      if (data !== undefined) handler.call(node, data, e);
      else if (typeof handler === 'function') handler.call(node, e);
      else handler.handleEvent(e);
      if (e.cancelBubble) return false;
    }
    if (node.host && typeof node.host !== 'string' && !node.host[HOST_KEY] && node.contains(e.target)) {
      retarget(node.host);
    }
    return true;
  };
  const walkUpTree = () => {
    while (handleNode() && (node = node[HOST_KEY] || node.parentNode || node.host)) {
      // keep walking: portal hosts, parents, shadow hosts
    }
  };
  // simulate currentTarget
  Object.defineProperty(e, 'currentTarget', {
    configurable: true,
    get() {
      return node || document;
    },
  });
  if (e.composedPath) {
    const path = e.composedPath();
    retarget(path[0]);
    for (let i = 0; i < path.length - 2; i++) {
      node = path[i];
      if (!handleNode()) break;
      if (node[HOST_KEY]) {
        node = node[HOST_KEY];
        walkUpTree(); // bubble up from the portal's logical position
        break;
      }
      if (node.parentNode === oriCurrentTarget) break; // never above the delegation root
    }
  } else walkUpTree();
  // Mixing portals and shadow DOM can leave a nonstandard target: restore it.
  retarget(oriTarget);
}
```

```ts
import { untrack } from '../index';

/**
 * A directive receives the raw attribute expression: for `use:x={sig}` the compiler passes the
 * accessor itself (one call at creation — the directive owns any effect); for `use:x={props.v}` it
 * emits an effect that calls `setAttribute(el, 'use:x', value)` with plain values on every change.
 */
export type Directive = (el: Element, value: unknown) => void;

const registry = new Map<string, Directive>();

/** Register `use:<name>` (built-ins: `value`, `checked`). */
export function defineDirective(name: string, fn: Directive): void {
  registry.set(name, fn);
}

/** `setAttribute(el, 'use:<name>', value)` lands here. */
export function runDirective(el: Element, name: string, value: unknown): void {

  if (!directive) {
    if (DEV) console.error(`[frameact] unknown directive use:${name} — register it with defineDirective('${name}', fn)`);
    return;
  }
  directive(el, value);
}

/** Hand-written form (dom-expressions 1.x API): `use(fn, el, arg)`. */
export function use<A>(fn: (el: Element, arg: A) => void, el: Element, arg: A): void {
  untrack(() => fn(el, arg));
}
```

```ts
// Adapted from solidjs/solid packages/web/src/client.ts and dom-expressions client.js (MIT, © Ryan Carniato).
// frameact: the 2.0 compiler lowers every namespaced attribute to `setAttribute(el, name, value)`,
// so this is the dispatcher for `use:`, `class:`, `style:`, `on:`, `oncapture:`, `attr:`, `bool:`,
// `prop:`, `xlink:` and for `class`/`classList`/`className`. `class` and `classList` stay independent
// channels over one token list: a token that both apply is removed as soon as either drops it.
import { DEV } from '../env';
import { className, classList, toggleClassToken } from './classes';
import { SVGNamespace } from './constants';
import { runDirective } from './directives';
import { setListener } from './events';
import { setStyleProperty } from './styles';

const URL_ATTRIBUTES = new Set(['href', 'src', 'action', 'formaction', 'xlink:href']);
const LOWERCASE_EVENT = /^on[a-z]+$/;
// oxlint-disable-next-line no-control-regex -- the URL parser ignores C0 controls, so we must strip them
const CONTROL_CHARS = /[\u0000-\u001F]/g;

/** `javascript:` URLs — after stripping the control characters the URL parser ignores — are refused. */
function isUnsafeUrl(value: unknown): boolean {
  return typeof value === 'string' && value.replace(CONTROL_CHARS, '').trimStart().toLowerCase().startsWith('javascript:');
}

function camelEvent(name: string): string {
  return `on${name.slice(2, 3).toUpperCase()}${name.slice(3)}`;
}

/** Compiler primitive. */
export function setAttribute(node: Element, name: string, value: unknown): void {
  if (name.indexOf(':') > -1) {
    if (name.startsWith('use:')) return runDirective(node, name.slice(4), value);
    if (name.startsWith('class:')) return toggleClassToken(node, name.slice(6), !!value);
    if (name.startsWith('style:')) return setStyleProperty(node, name.slice(6), value);
    if (name.startsWith('on:')) return setListener(node, name.slice(3), value, false);
    if (name.startsWith('oncapture:')) return setListener(node, name.slice(10), value, true);
    if (name.startsWith('bool:')) return setBoolAttribute(node, name.slice(5), value);
    if (name.startsWith('prop:')) {
      (node as unknown as Record<string, unknown>)[name.slice(5)] = value;
      return;
    }
    if (name.startsWith('attr:')) name = name.slice(5);
    else {
      const ns = SVGNamespace[name.split(':')[0]];
      if (ns) return setAttributeNS(node, ns, name, value);
    }
  } else if (name === 'class') return className(node, value);
  else if (name === 'classList') return classList(node, value);
  else if (name === 'className') {
    if (DEV) console.error('[frameact] className= on an element: use class= (className bypasses the token diff).');
    return className(node, value);
  } else if (name.charCodeAt(0) === 111 && name.charCodeAt(1) === 110 && LOWERCASE_EVENT.test(name)) {
    if (typeof value === 'string') {
      if (DEV) console.error(`[frameact] ${name}="…": string event handlers are an inline-script sink. Use ${camelEvent(name)}={fn}.`);
      node.removeAttribute(name);
      return;
    }
    if (typeof value === 'function') {
      if (DEV) console.warn(`[frameact] ${name}={fn}: a lowercase event attribute attaches nothing. Use ${camelEvent(name)}={fn}.`);
      node.removeAttribute(name);
      return;
    }
  }
  if (value == null || value === false) node.removeAttribute(name);
  else if (URL_ATTRIBUTES.has(name) && isUnsafeUrl(value)) {
    if (DEV) console.error(`[frameact] refused an unsafe URL in ${name}=`, value);
    node.removeAttribute(name);
  } else node.setAttribute(name, value === true ? '' : String(value));
}

/** Compiler primitive (`xlink:href`, `xml:lang`). */
export function setAttributeNS(node: Element, namespace: string, name: string, value: unknown): void {
  const local = name.indexOf(':') > -1 ? name.slice(name.indexOf(':') + 1) : name;
  if (value == null || value === false) node.removeAttributeNS(namespace, local);
  else if (URL_ATTRIBUTES.has(name) && isUnsafeUrl(value)) {
    if (DEV) console.error(`[frameact] refused an unsafe URL in ${name}=`, value);
    node.removeAttributeNS(namespace, local);
  } else node.setAttributeNS(namespace, name, value === true ? '' : String(value));
}

/** `bool:name=` and spread booleans. */
export function setBoolAttribute(node: Element, name: string, value: unknown): void {
  if (value) node.setAttribute(name, '');
  else node.removeAttribute(name);
}

/** Compiler primitive for property writes it cannot inline (e.g. `<select value>`). */
export function setProperty(node: Element, name: string, value: unknown): void {
  const el = node as unknown as Record<string, unknown>;
  const tag = node.nodeName;
  if ((name === 'value' || name === 'defaultValue') && (tag === 'INPUT' || tag === 'TEXTAREA')) {
    el[name] = value ?? '';
  } else if (name === 'value' && tag === 'SELECT') {
    el.value = value;
    // Options inserted later in the same turn: reapply once they exist.
    if (value != null && el.value !== String(value)) {
      queueMicrotask(() => {
        el.value = value;
      });
    }
  } else el[name] = value;
}
```

### Task 8: Controlled inputs — `use:value` and `use:checked`

Spec §3.3 "Контролируемые инпуты", Scope decision 2. One mutation effect per controlled element (writes only when `el.value !== v`, restores the caret from the last event-time snapshot); document-level `input`/`change` listeners registered after delegation reject or format input synchronously, in the event, before paint; no writes during IME composition.

**Three entry forms**, chosen by what `setAttribute(el, 'use:value', x)` receives (`use:checked` follows the same rules):

1. **An accessor under an owner** (`use:value={text}`, the static form): the directive creates one owned mutation effect. Its compute returns a *fresh box* `{ v }` on every change, so the apply always compares with the live DOM instead of with the last applied value — otherwise an input the user already typed (`'abc'`, accepted) followed by a programmatic `setText('ab')` in the same frame would be skipped as "unchanged" and the DOM would keep `'abc'`. The document-level check reads the live accessor.
2. **A plain value** (`use:value={props.text()}`, the compiler-wrapped form): the compiler's own effect calls `setAttribute(el, 'use:value', v)` with plain values; the directive writes with the same caret logic, and the rollback check compares the input against the last delivered value. A rejected keystroke is rolled back; an accepted one is rolled back too and re-applied when the compiler's effect delivers the new value in the next frame — so for text people type into, prefer form 1.
3. **An accessor inside an effect apply** (no owner): the compiler wraps `use:value={props.text}` into `effect(() => props.text, v => setAttribute(el, 'use:value', v))`, and when `props.text` is itself an accessor the directive receives a function while it runs inside an apply. It must NOT create an effect there (it would be unowned; in DEV `createMutationEffect` throws). Instead it reports `console.error` with the hint "pass the accessor directly: `use:value={text}`, or a value: `use:value={props.text()}`", writes `untrack(accessor)` once with the normal caret-preserving write, and keeps the accessor for the rollback check. Programmatic changes are *not* followed in this fallback — which is what the error tells the author.

```ts
// ---- built-in controlled inputs (spec §3.3) ---------------------------------
// Adapted in spirit from teact's processControlled / setAttribute('value') caret logic
// (MIT, © 2022 Alexander Zinchuk).
import { createMutationEffect } from '../core/frame';
import { delegateEvents, onClearDelegated } from './events';

type TextControl = HTMLInputElement | HTMLTextAreaElement | HTMLSelectElement;

interface CaretSnapshot {
  start: number;
  end: number;
  atEnd: boolean;
}

interface ValueState {
  read: () => unknown;
  /** Taken at event time (measure phase); the mutate-phase applier only restores from it. */
  selection: CaretSnapshot | null;
  composing: boolean;
}

interface CheckedState {
  read: () => unknown;
}

const valueControlled = new WeakMap<TextControl, ValueState>();
const checkedControlled = new WeakMap<HTMLInputElement, CheckedState>();
const installed = new WeakSet<Document>();

function toText(v: unknown): string {
  return v == null ? '' : String(v);
}

function snapshot(el: TextControl, state: ValueState): void {
  const input = el as HTMLInputElement;
  const start = 'selectionStart' in input ? input.selectionStart : null;
  if (start == null) {
    state.selection = null; // selects, inputs without a text selection
    return;
  }
  const end = input.selectionEnd ?? start;
  state.selection = { start, end, atEnd: start === end && end === input.value.length };
}

function writeValue(el: TextControl, state: ValueState, v: unknown): void {
  if (state.composing) return; // IME: never write mid-composition
  const next = toText(v);
  if (el.value === next) return;
  el.value = next;
  const sel = state.selection;
  if (sel && document.activeElement === el && 'setSelectionRange' in el) {
    try {
      if (sel.atEnd) el.setSelectionRange(next.length, next.length);
      else el.setSelectionRange(sel.start, sel.end);
    } catch {
      // input types without a selection API
    }
  }
}

function check(el: TextControl, state: ValueState): void {
  const v = untrack(state.read);
  if (el.value !== toText(v)) writeValue(el, state, v);
}

function onInput(e: Event): void {
  const el = e.target as TextControl;
  const state = valueControlled.get(el);
  if (!state || (e as InputEvent).isComposing || state.composing) return;
  snapshot(el, state);
  check(el, state);
}

function onCompositionStart(e: Event): void {
  const state = valueControlled.get(e.target as TextControl);
  if (state) state.composing = true;
}

function onCompositionEnd(e: Event): void {
  const el = e.target as TextControl;
  const state = valueControlled.get(el);
  if (!state) return;
  state.composing = false;
  snapshot(el, state);
  check(el, state);
}

function onFocusOut(e: Event): void {
  const state = valueControlled.get(e.target as TextControl);
  if (state) state.selection = null;
}

function onChange(e: Event): void {
  const el = e.target as HTMLInputElement;
  const state = checkedControlled.get(el);
  if (!state) return;
  const v = !!untrack(state.read);
  if (el.checked !== v) el.checked = v;
}

/**
 * Document listeners, registered AFTER `input` delegation: on one document, listeners run in
 * registration order, so the controlled check always follows the delegated `onInput` dispatcher
 * (and element-level `on:input` listeners, which bubble first).
 */
function installListeners(doc: Document): void {
  if (installed.has(doc)) return;
  installed.add(doc);
  delegateEvents(['input'], doc);
  doc.addEventListener('input', onInput);
  doc.addEventListener('change', onChange);
  doc.addEventListener('compositionstart', onCompositionStart);
  doc.addEventListener('compositionend', onCompositionEnd);
  doc.addEventListener('focusout', onFocusOut);
}

onClearDelegated((doc) => {
  if (!installed.has(doc)) return;
  installed.delete(doc);
  doc.removeEventListener('input', onInput);
  doc.removeEventListener('change', onChange);
  doc.removeEventListener('compositionstart', onCompositionStart);
  doc.removeEventListener('compositionend', onCompositionEnd);
  doc.removeEventListener('focusout', onFocusOut);
});

const APPLY_HINTS = {
  value: ['use:value={text}', 'use:value={props.text()}'],
  checked: ['use:checked={flag}', 'use:checked={props.flag()}'],
} as const;

/** DEV: an accessor reached a controlled-input directive from inside an effect apply (no owner). */
function reportAccessorInApply(name: keyof typeof APPLY_HINTS): void {
  const [accessorForm, valueForm] = APPLY_HINTS[name];
  console.error(
    `[frameact] use:${name} received an accessor inside an effect apply (a compiler-wrapped use:${name}={props.x} where props.x is a function), so it cannot own a binding effect and will not follow later changes. Pass the accessor directly: ${accessorForm}, or a value: ${valueForm}.`,
  );
}

function valueDirective(el: Element, value: unknown): void {
  const control = el as TextControl;
  if (DEV && !('value' in control)) console.error('[frameact] use:value expects an input, textarea or select', el);
  installListeners(el.ownerDocument);
  let state = valueControlled.get(control);
  if (!state) valueControlled.set(control, (state = { read: () => undefined, selection: null, composing: false }));
  if (typeof value === 'function') {
    const accessor = value as () => unknown;
    const owned = state;
    owned.read = accessor; // the document-level rollback check always reads the live accessor
    if (getOwner() === null) {
      // Inside an effect apply (no owner): the compiler wrapped `use:value={props.text}` where
      // `props.text` is itself an accessor. An effect created here would be unowned (DEV throws), so
      // write once and tell the author how to get a live binding.
      if (DEV) reportAccessorInApply('value');
      writeValue(control, owned, untrack(accessor));
      return;
    }
    // Static form: the directive owns the binding effect (created under the component's owner). The
    // compute returns a fresh box so the apply runs on every change and compares with the DOM: input
    // the user already typed ('abc', accepted) followed by a programmatic change back to the last
    // applied value ('ab') in the same frame must still be written.
    createMutationEffect(
      () => ({ v: accessor() }),
      ({ v }) => {
        writeValue(control, owned, v);
      },
      { name: 'use:value' },
    );
  } else {
    // Effect-driven form: the compiler's effect calls us with plain values.
    state.read = () => value;
    writeValue(control, state, value);
  }
}

function checkedDirective(el: Element, value: unknown): void {
  const box = el as HTMLInputElement;
  if (DEV && !('checked' in box)) console.error('[frameact] use:checked expects a checkbox or radio input', el);
  installListeners(el.ownerDocument);
  let state = checkedControlled.get(box);
  if (!state) checkedControlled.set(box, (state = { read: () => undefined }));
  if (typeof value === 'function') {
    const accessor = value as () => unknown;
    state.read = accessor;
    if (getOwner() === null) {
      // Inside an effect apply (no owner): see valueDirective. One-shot write, no owned effect.
      if (DEV) reportAccessorInApply('checked');
      const next = !!untrack(accessor);
      if (box.checked !== next) box.checked = next;
      return;
    }
    // A fresh box per change (see valueDirective): the apply compares with the DOM, not with the last applied value.
    createMutationEffect(
      () => ({ v: !!accessor() }),
      ({ v }) => {
        if (box.checked !== v) box.checked = v;
      },
      { name: 'use:checked' },
    );
  } else {
    state.read = () => value;
    if (box.checked !== !!value) box.checked = !!value;
  }
}

defineDirective('value', valueDirective);
defineDirective('checked', checkedDirective);
```

```ts
/** Compiler primitive: frameact has no store proxies, so a shallow read is the value itself. */
export function readShallow<T>(value: T): T {
  return value;
}

/** Compiler primitive: a ref is a function or a (nested) array of functions; anything else is ignored. */
export function applyRef(r: unknown, element: Element): void {
  if (Array.isArray(r)) {
    for (const f of (r as unknown[]).flat(Infinity)) if (typeof f === 'function') f(element);
  } else if (typeof r === 'function') r(element);
}

/** Compiler primitive: `ref(() => expr, el)`. Refs own nothing — the callback runs with no owner. */
export function ref(fn: () => unknown, element: Element): void {
  const resolved = untrack(fn);
  runWithOwner(null, () => applyRef(resolved, element));
}

/**
 * Compiler primitive: `spread(el, props | [sources], skipChildren, skip, name)`. One render effect
 * reads every prop (compute) and assigns the changed ones (apply); `children`, when not skipped,
 * get their own `insert` so an attribute change never rebuilds the subtree.
 */
export function spread(
  node: Element,
  props: PropsSource | PropsSource[],
  skipChildren?: boolean,
  skip?: (key: string) => boolean,
  name?: string,
): Record<string, unknown> {
  const prevProps: Record<string, unknown> = {};
  const sources: PropsSource[] = Array.isArray(props) ? props : [props];
  createRenderEffect(
    () => collectProps(sources, skip),
    (next) => {
      const r = next.ref;
      if (r !== prevProps.ref && (typeof r === 'function' || Array.isArray(r))) ref(() => r, node);
      assign(node, next, true, prevProps, true);
    },
    name === undefined ? undefined : { name: `${name}.spread` },
  );
  if (!skipChildren && !(skip !== undefined && skip('children'))) {
    insert(node, () => childrenOf(sources), undefined, undefined, name === undefined ? undefined : { name: `${name}.children` });
  }
  return prevProps;
}

/** Own enumerable keys only (never prototype properties of untrusted objects); later sources win. */
function collectProps(sources: PropsSource[], skip?: (key: string) => boolean): Record<string, unknown> {
  const out: Record<string, unknown> = {};
  for (let i = 0; i < sources.length; i++) {
    const s = resolveSource(sources[i]);
    if (!s) continue;
    for (const key of Object.keys(s)) {
      if (key === 'children' || (skip !== undefined && skip(key))) continue;
      out[key] = s[key];
    }
  }
  return out;
}

function childrenOf(sources: PropsSource[]): unknown {
  for (let i = sources.length - 1; i >= 0; i--) {
    const s = resolveSource(sources[i]);
    if (s && 'children' in s) return s.children;
  }
  return undefined;
}

/** Compiler/author primitive: write `props` onto `node`, removing props present in `prevProps` but absent now. */
export function assign(
  node: Element,
  props: Record<string, unknown> | null | undefined,
  skipChildren?: boolean,
  prevProps: Record<string, unknown> = {},
  skipRef = false,
): void {
  const next = props || {};
  const isSVG = node.namespaceURI === SVG_NS;
  const isCE = node.nodeName.includes('-') || 'is' in next;
  for (const prop in prevProps) {
    if (!(prop in next)) {
      if (prop === 'children') continue;
      prevProps[prop] = assignProp(node, prop, null, prevProps[prop], isSVG, isCE, skipRef);
    }
  }
  for (const prop in next) {
    if (prop === 'children') {
      if (!skipChildren) insertExpression(node, normalize(next.children, false, false), undefined);
      continue;
    }
    prevProps[prop] = assignProp(node, prop, next[prop], prevProps[prop], isSVG, isCE, skipRef);
  }
}

function toPropertyName(name: string): string {
  return name.toLowerCase().replace(/-([a-z])/g, (_match, letter: string) => letter.toUpperCase());
}

function assignProp(
  node: Element,
  prop: string,
  value: unknown,
  prev: unknown,
  isSVG: boolean,
  isCE: boolean,
  skipRef: boolean,
): unknown {
  if (prop === 'style') {
    style(node, value, prev);
    return value;
  }
  if (prop === 'class' || prop === 'className') {
    className(node, value, prev);
    return value;
  }
  if (prop === 'classList') {
    classList(node, value);
    return value;
  }
  if (value === prev) return prev;
  if (prop === 'ref') {
    if (!skipRef && value) ref(() => value, node);
    return value;
  }
  const el = node as unknown as Record<string, unknown>;
  if (prop.indexOf(':') > -1) {
    if (prop.startsWith('on:')) setListener(node, prop.slice(3), value, false);
    else if (prop.startsWith('oncapture:')) setListener(node, prop.slice(10), value, true);
    else if (prop.startsWith('attr:')) setAttribute(node, prop.slice(5), value);
    else if (prop.startsWith('bool:')) setBoolAttribute(node, prop.slice(5), value);
    else if (prop.startsWith('prop:')) el[prop.slice(5)] = value;
    else if (prop.startsWith('use:')) {
      if (DEV) console.error(`[frameact] ${prop} inside a spread is not supported (a directive needs an owner); write it as an attribute.`);
    } else if (prop.startsWith('class:') || prop.startsWith('style:')) setAttribute(node, prop, value);
    else {
      const ns = isSVG ? SVGNamespace[prop.split(':')[0]] : undefined;
      if (ns) setAttributeNS(node, ns, prop, value);
      else setAttribute(node, prop, value);
    }
    return value;
  }
  // `on` + an uppercase letter is an event; a lowercase `onclick` is an attribute (setAttribute refuses strings).
  if (prop.length > 2 && prop.startsWith('on')) {
    const c = prop.charCodeAt(2);
    if (c > 64 && c < 91) {
      const event = prop.slice(2).toLowerCase();
      const delegate = DelegatedEvents.has(event);
      if (!delegate && prev) node.removeEventListener(event, (Array.isArray(prev) ? prev[0] : prev) as EventListener);
      if (delegate || value) {
        addEvent(node, event, value, delegate);
        if (delegate) delegateEvents([event], node.ownerDocument);
      }
      return value;
    }
  }
  const propAlias = isSVG ? undefined : getPropAlias(prop, node.tagName);
  if (ChildProperties.has(prop) || (!isSVG && (propAlias !== undefined || Properties.has(prop))) || isCE) {
    const target = propAlias ?? prop;
    if (isCE && propAlias === undefined && !Properties.has(prop) && !ChildProperties.has(prop)) {
      // custom elements take properties: `some-prop` → `someProp`, camelCase names as written
      el[prop.includes('-') ? toPropertyName(prop) : prop] = value;
    } else if (
      (target === 'value' || target === 'defaultValue') &&
      (node.nodeName === 'INPUT' || node.nodeName === 'TEXTAREA')
    ) {
      el[target] = value ?? '';
    } else el[target] = value;
    return value;
  }
  setAttribute(node, Aliases[prop] || prop, value);
  return value;
}
```

```ts
// Show/Switch/Match follow solid-js's flow components (MIT, © 2016-2025 Ryan Carniato) on frameact's
// core; Portal follows solidjs/solid packages/web (2.0) with the stricterdom seam.
import { DEV } from '../env';
import { createRenderEffect } from '../core/frame';
import type { Scope } from '../core/types';
import { createMemo, createRoot, getOwner, runWithOwner, untrack } from '../index';
import { children, createComponent } from './component';
import { SVG_NS, SVGElements } from './constants';
import { insert } from './insert';
import { spread } from './props';
import { strictHooks } from './strict';

type Falsy = undefined | null | false;
type ChildOrFn = unknown | ((item: any) => unknown);

const sameTruthiness = (a: unknown, b: unknown) => !a === !b;

function staleError(name: string) {
  return new Error(`[frameact] <${name}>: the narrowed accessor was read after the condition turned falsy`);
}

/**
 * `<Show when keyed fallback>`. A function child receives an accessor (non-keyed: the child is kept
 * while `when` stays truthy) or the value itself (keyed: recreated when the identity changes).
 */
export function Show<T>(props: { when: T | Falsy; keyed?: boolean; fallback?: unknown; children: ChildOrFn }): unknown {
  const keyed = props.keyed;
  const condition = createMemo<T | Falsy>(() => props.when, keyed ? undefined : { equals: sameTruthiness });
  return createMemo(() => {
    const c = condition();
    if (c) {
      const child = props.children;
      const fn = typeof child === 'function' && child.length > 0;
      if (!fn) return child;
      return untrack(() =>
        (child as (item: unknown) => unknown)(
          keyed
            ? c
            : () => {
                if (!untrack(condition)) throw staleError('Show');
                return props.when;
              },
        ),
      );
    }
    return props.fallback;
  });
}

export interface MatchProps<T> {
  when: T | Falsy;
  keyed?: boolean;
  children: ChildOrFn;
}

/** A branch of `<Switch>`: returns its props, which Switch reads. */
export function Match<T>(props: MatchProps<T>): unknown {
  return props;
}

type Selected = [index: number, conditionValue: () => unknown, match: MatchProps<unknown>];

const noMatch = (): Selected | undefined => undefined;

/** `<Switch fallback>`: the first `<Match>` whose `when` is truthy wins. */
export function Switch(props: { fallback?: unknown; children: unknown }): unknown {
  const branches = children(() => props.children);
  const switchFunc = createMemo<() => Selected | undefined>(() => {
    const matches = branches.toArray() as MatchProps<unknown>[];
    let func: () => Selected | undefined = noMatch;
    for (let i = 0; i < matches.length; i++) {
      const index = i;
      const mp = matches[i];
      if (mp == null) continue;
      const prevFunc = func;
      const conditionValue = createMemo(() => (prevFunc() ? undefined : mp.when));
      const condition = mp.keyed ? conditionValue : createMemo(conditionValue, { equals: sameTruthiness });
      func = () => prevFunc() || (condition() ? [index, conditionValue, mp] : undefined);
    }
    return func;
  });
  return createMemo(() => {
    const selected = switchFunc()();
    if (!selected) return props.fallback;
    const [index, conditionValue, mp] = selected;
    const child = mp.children;
    const fn = typeof child === 'function' && child.length > 0;
    if (!fn) return child;
    return untrack(() =>
      (child as (item: unknown) => unknown)(
        mp.keyed
          ? conditionValue()
          : () => {
              if (untrack(switchFunc)()?.[0] !== index) throw staleError('Match');
              return conditionValue();
            },
      ),
    );
  });
}

/** Everything but `omit`, as forwarding getters (key set fixed at creation — compiled props objects are). */
function omitProp(props: Record<string, unknown>, omit: string): Record<string, unknown> {
  const out: Record<string, unknown> = {};
  for (const key of Object.keys(props)) {
    if (key !== omit) Object.defineProperty(out, key, { enumerable: true, configurable: true, get: () => props[key] });
  }
  return out;
}

/** `<Dynamic component={tagOrComponent} …props>`. */
export function Dynamic(props: { component?: ((props: any) => unknown) | string | Falsy; [prop: string]: unknown }): unknown {
  const others = omitProp(props, 'component');
  return createMemo(() => {
    const component = props.component;
    if (!component) return undefined;
    if (typeof component === 'function') return untrack(() => createComponent(component, others));
    if (typeof component === 'string') {
      const node = SVGElements.has(component) ? document.createElementNS(SVG_NS, component) : document.createElement(component);
      spread(node, others, false);
      return node;
    }
    if (DEV) console.error('[frameact] <Dynamic component={…}>: expected a component function or a tag name', component);
    return undefined;
  });
}

/**
 * `<Portal mount>`: children render into `mount` (default `document.body`) between two markers, in
 * their own root parented to the Portal's owner (context flows, disposal follows the Portal). The
 * attach is a live-DOM write at creation and goes through the stricterdom seam. Delegated events
 * from the content bubble to the Portal's logical position (`host`).
 */
export function Portal(props: { mount?: Element; children: unknown }): unknown {
  const treeMarker = document.createTextNode('');
  const startMarker = document.createTextNode('');
  const endMarker = document.createTextNode('');
  const mount = () => props.mount || document.body;
  const content = createMemo(() => [startMarker, props.children]);
  createRenderEffect<[Element, unknown, Scope | null]>(
    () => [mount(), content(), getOwner()],
    ([, c, owner]) => {
      const m = untrack(mount);
      const dispose = strictHooks.forceMutation(() => {
        m.appendChild(endMarker);
        return runWithOwner(owner, () =>
          createRoot((d) => {
            insert(m, c, endMarker, undefined, { host: () => treeMarker.parentNode });
            return d;
          }),
        )!;
      }, m);
      return () => {
        dispose();
        strictHooks.forceMutation(() => {
          // remove [startMarker, endMarker] inclusive
          let n: Node | null = startMarker;
          while (n) {
            const next: Node | null = n.nextSibling;
            if (n.parentNode === m) m.removeChild(n);
            if (n === endMarker) break;
            n = next;
          }
        }, m);
      };
    },
    { name: 'Portal' },
  );
  return treeMarker;
}
```

```ts
import { compute, createScope, getScope, setContext } from './core';

export interface Context<T> {
  readonly id: symbol;
  readonly defaultValue: T;
  /** `<Ctx.Provider value>`: provides `value` to everything created in `children` (a child scope of the current owner). */
  readonly Provider: (props: { value: T; children?: unknown }) => unknown;
}

export function createContext<T>(defaultValue: T, name = 'context'): Context<T> {
  const id = Symbol(name);
  return {
    id,
    defaultValue,
    Provider(props) {
      const scope = createScope();
      return compute(
        scope,
        () => {
          setContext(id, props.value);
          return props.children;
        },
        null,
      );
    },
  };
}

/** Provide `value` to every owner created under the current one. */
export function provideContext<T>(ctx: Context<T>, value: T): void {
  setContext(ctx.id, value);
}

/** Nearest provided value for `ctx` (a provided `undefined` counts), or its default. */
export function useContext<T>(ctx: Context<T>): T {
  const record = getScope()?._context;
  if (record && ctx.id in record) return record[ctx.id] as T;
  return ctx.defaultValue;
}
```

```ts
import { transformAsync } from '@babel/core';
import typescript from '@babel/preset-typescript';
import solid from '@solidjs/babel-plugin';
import type { Plugin } from 'vite';

export const BUILT_INS = ['For', 'Show', 'Switch', 'Match', 'Portal', 'Dynamic'] as const;

/**
 * The compiler configuration frameact pins (spec §3.6): `@solidjs/babel-plugin@2.0.0-rc.14` with
 * `moduleName: "frameact/dom"`, an explicit `builtIns` list (no Loading/Reveal/Errored/Repeat) and,
 * in dev, `sourceNames` (component and binding labels for attribution). The acceptance test compiles
 * the compiler's own fixtures with it.
 */
export function compilerOptions(dev: boolean) {
  return {
    moduleName: 'frameact/dom',
    generate: 'dom',
    hydratable: false,
    delegateEvents: true,
    builtIns: [...BUILT_INS],
    dev,
    sourceNames: dev,
    requireImportSource: false,
  };
}

export interface FrameactPluginOptions {
  /** Defaults to Vite's `!isProduction`. Dev: names for attribution, source lints. */
  dev?: boolean;
  /** Files to compile (default `/\.[jt]sx$/`). */
  include?: RegExp;
  /** Files to skip (default `/node_modules/`). */
  exclude?: RegExp;
}

/**
 * `<input value={…}>` is written as a property by the compiler — only `use:value` controls it (spec §3.3).
 * The scan walks the opening tag up to the first `>`, stepping over `=>`, so an arrow function in an
 * earlier attribute (`onInput={e => …}`) does not end it. Known false negative: a bare `>` in an earlier
 * attribute expression (`disabled={n() > 1} value={v()}`) ends the scan early and the lint stays silent.
 * A source lint, not a parser; the runtime cannot see this misuse at all.
 */
const CONTROLLED_PROP = /<(input|textarea|select)\b(?:=>|[^>])*?\s(value|checked)=\{/g;

/** Vite plugin: compile JSX/TSX with the Solid 2.0 compiler targeting `frameact/dom`. */
export default function frameact(options: FrameactPluginOptions = {}): Plugin {
  const include = options.include ?? /\.[jt]sx$/;
  const exclude = options.exclude ?? /node_modules/;
  let dev = options.dev ?? true;
  return {
    name: 'frameact',
    enforce: 'pre',
    configResolved(config) {
      dev = options.dev ?? !config.isProduction;
    },
    async transform(code, id) {
      const file = id.split('?')[0];
      if (!include.test(file) || exclude.test(file)) return null;
      if (dev) {
        for (const match of code.matchAll(CONTROLLED_PROP)) {
          this.warn(
            `<${match[1]} ${match[2]}={…}> is not controlled in frameact (the compiler writes the property directly). Use use:${match[2]}={accessor}.`,
          );
        }
      }
      const result = await transformAsync(code, {
        filename: file,
        babelrc: false,
        configFile: false,
        sourceMaps: true,
        presets: file.endsWith('.tsx') ? [[typescript, {}]] : [],
        plugins: [[solid, compilerOptions(dev)]],
      });
      if (!result || result.code == null) return null;
      return { code: result.code, map: result.map as any };
    },
  };
}

export { frameact };
```

```ts
import { readdirSync, readFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { transformSync, types as t, type PluginObj } from '@babel/core';
import solid from '@solidjs/babel-plugin';
import * as dom from '../../src/dom/index';
import { createRoot } from '../../src/index';
import { compilerOptions } from '../../src/vite/index';

// Not `new URL('./fixtures/', import.meta.url)`: under the jsdom environment that URL is not a file: URL.
const fixturesDir = join(dirname(fileURLToPath(import.meta.url)), 'fixtures');
const fixtures = readdirSync(fixturesDir, { withFileTypes: true })
  .filter((entry) => entry.isDirectory())
  .map((entry) => entry.name);

function compileFixture(name: string, dev: boolean): string {
  const file = join(fixturesDir, name, 'code.js');
  const result = transformSync(readFileSync(file, 'utf8'), {
    filename: file,
    babelrc: false,
    configFile: false,
    plugins: [[solid, compilerOptions(dev)]],
  });
  return result!.code!;
}

// `let`: fixtures assign to their free identifiers (`ref={el => (e = el)}`) and the compiler itself
// emits `r = _el$` for non-function refs.
const stubCall = (name: string) =>
  t.variableDeclaration('let', [
    t.variableDeclarator(t.identifier(name), t.callExpression(t.identifier('__stub'), [t.stringLiteral(name)])),
  ]);

/**
 * Compiled module → function body: `import { x as _$x } from "frameact/dom"` becomes
 * `const _$x = __dom.x`; every other import and every free identifier becomes `__stub(name)`.
 */
function toFunctionBody(code: string): { body: string; domImports: string[] } {
  const domImports: string[] = [];
  const rewrite = (): PluginObj => ({
    visitor: {
      Program: {
        exit(path) {
          const body = path.node.body;
          for (let i = body.length - 1; i >= 0; i--) {
            const node = body[i];
            if (!t.isImportDeclaration(node)) continue;
            const decls: t.Statement[] = [];
            for (const specifier of node.specifiers) {
              const local = specifier.local.name;
              if (node.source.value === 'frameact/dom' && t.isImportSpecifier(specifier)) {
                const imported = t.isIdentifier(specifier.imported) ? specifier.imported.name : specifier.imported.value;
                domImports.push(imported);
                decls.push(
                  t.variableDeclaration('const', [
                    t.variableDeclarator(t.identifier(local), t.memberExpression(t.identifier('__dom'), t.identifier(imported))),
                  ]),
                );
              } else decls.push(stubCall(local));
            }
            body.splice(i, 1, ...decls);
          }
          path.scope.crawl();
          const globals = Object.keys(path.scope.globals).filter(
            (name) => name !== '__dom' && name !== '__stub' && !(name in globalThis),
          );
          body.unshift(...globals.map(stubCall));
        },
      },
    },
  });
  const out = transformSync(code, { babelrc: false, configFile: false, sourceType: 'module', plugins: [rewrite] });
  return { body: out!.code!, domImports };
}

/** The Proxy target: a function, so a stub is callable and constructible. */
function stubTarget() {}

/**
 * A value that survives whatever compiled output does with a free identifier: callable (two levels
 * deep, so accessor unwrapping terminates), constructible, has any property, iterates as empty,
 * coerces to the string "stub", and is never mistaken for a DOM node or an array.
 */
function makeStub(name: string, depth = 0): any {
  const cache = new Map<PropertyKey, unknown>();
  return new Proxy(stubTarget, {
    apply: () => (depth < 2 ? makeStub(`${name}()`, depth + 1) : undefined),
    construct: () => ({}),
    get(fn, key) {
      if (key === 'prototype') return fn.prototype;
      if (key === Symbol.toPrimitive) return () => 'stub';
      if (key === Symbol.iterator) return function* () {};
      if (typeof key === 'symbol' || key === 'then' || key === 'nodeType' || key === 'name') return undefined;
      if (key === 'length') return 0;
      let value = cache.get(key);
      if (value === undefined) cache.set(key, (value = makeStub(`${name}.${String(key)}`, depth)));
      return value;
    },
    set: () => true,
    has: (_fn, key) => key === 'prototype',
    ownKeys: () => ['prototype'],
    getOwnPropertyDescriptor: (fn, key) => (key === 'prototype' ? Reflect.getOwnPropertyDescriptor(fn, key) : undefined),
  });
}

function runModule(body: string): void {
  // oxlint-disable-next-line no-new-func
  const fn = new Function('__dom', '__stub', body) as (d: unknown, s: unknown) => void;
  const dispose = createRoot((d) => {
    fn.call(undefined, dom, makeStub);
    return d;
  });
  dispose();
}

/** Our own runtime error reports (effects, drains, cleanups, list rows) — unlike dev lint messages, these mean something threw. */
const RUNTIME_ERROR = /Error in effect|entry failed|onCleanup failed|row mapper|keyFn/;

/**
 * Fixtures whose own source throws when it is executed as a program against stubs: the compiler output
 * is right, the fixture is just not a runnable module. Each entry must match the exact message and
 * say why. `insertChildren`: `const children = <div/>; … {children()}` calls a DOM node.
 */
const FIXTURE_USER_ERRORS: Record<string, RegExp> = {
  insertChildren: /children is not a function/,
};

describe.each([false, true])('compiler acceptance (dev=%s)', (dev) => {
  for (const name of fixtures) {
    it(`${name}: every import exists in frameact/dom and the compiled module runs`, () => {
      const { body, domImports } = toFunctionBody(compileFixture(name, dev));
      for (const imported of domImports) {
        expect(typeof (dom as Record<string, unknown>)[imported], `frameact/dom.${imported}`).toBe('function');
      }
      const errors: string[] = [];
      const error = vi.spyOn(console, 'error').mockImplementation((...args: unknown[]) => {
        errors.push(args.map(String).join(' '));
      });
      const warn = vi.spyOn(console, 'warn').mockImplementation(() => {});
      const log = vi.spyOn(console, 'log').mockImplementation(() => {});
      try {
        runModule(body);
      } finally {
        error.mockRestore();
        warn.mockRestore();
        log.mockRestore();
        dom.clearDelegatedEvents();
        document.body.textContent = '';
      }
      expect(
        errors.filter((message) => RUNTIME_ERROR.test(message) && !FIXTURE_USER_ERRORS[name]?.test(message)),
      ).toEqual([]);
    });
  }
});

it('covers the full fixture set of the pinned compiler', () => {
  expect(fixtures.length).toBe(17);
  expect(fixtures).toContain('attributeExpressions');
  expect(fixtures).toContain('components');
});
```

**Known decisions an implementer must not "fix":**
- Directives are dispatched from `setAttribute(el, 'use:<name>', value)` by name (registry); there is no `_$use` in rc.14 output. A directive receiving a function treats it as an accessor and, when it runs under an owner, creates its own mutation effect (compute returns a fresh `{ v }` box; the apply compares with the DOM); a function that arrives inside an effect apply (no owner) gets a DEV `console.error` hint plus a one-shot write, never an effect; receiving a plain value it just writes.
- The controlled-input check is a `document`-level listener registered after `delegateEvents(['input'])` — never an element-level listener or a microtask (both would run before the delegated user handler).
- `insert`'s outer compute returns the `INNER_OWNED` sentinel when it created a nested effect; the nested effect is created inside the compute on purpose (owned by it) and its first apply runs synchronously there.
- Primitives stay raw through `normalize`; text nodes are materialised in `insertExpression`, reusing positional text nodes.
- `className(node, value, prev)` ignores `prev` semantically: the element-held applied set is authoritative. `class` and `classList` are separate channels; `class:x` is tracked by neither. A token applied by two of them is removed when either drops it — keep them disjoint.
- `For order="manual"` does not touch the DOM itself and does not use a `DocumentFragment`; it returns the DOM-ordered array and `reconcileArrays` does the rest.
- `createComponent` wraps the component in a named scope **only in DEV**; production is `untrack(() => Comp(props))`.
- `readShallow` is the identity (no proxies); `claimElement` is the identity (no link-claim consumer).
- `insertExpression` renders array items that are not nodes after normalization (functions with parameters, plain objects) as empty text with a DEV warning instead of throwing from `insertBefore`; `MountableElement` excludes `Document`.
- `For order="manual"` reads `each()` tracked in its transform; do not turn it back into `untrack(each)` — an `orderKey` change at unchanged list positions would then never move the row.
- Lowercase `on*` attributes refuse strings (sink) and functions (no-op) instead of writing them; `javascript:` URLs are dropped. Both are `console.error`/`warn` in DEV, silent in prod.
- Dev diagnostics are `console.error`, not throws (the acceptance fixtures compile `className=`, `onclick={code}` and similar).
