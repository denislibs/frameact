how it renders · in six frames
01 · signals, not a VDOM
Graph now.
DOM on the frame.
set() marks dependents dirty immediately. Nothing touches the DOM until the next rAF tick.
const [count, setCount] = createSignal(0)const label = createMemo(() => `${count()} unread`) createMutationEffect( () => label(), // compute · pure (v) => el.textContent = v // apply · on frame)
02 · one pass per frame
Three writes.
One commit.
Writes batch between ticks. On the tick the graph settles once and every DOM binding is applied once, in order.
setCount(1)setCount(2)setCount(3) // graph: count → label, recomputed once// DOM: el.textContent = "3 unread", once
03 · measure → mutate
Reads first.
Writes second.
Effects arrive in any order. The scheduler runs every layout read before the first DOM write, so layout is computed once per frame, never thrashed.
createMeasureEffect( () => list.scrollHeight, // read layout (h) => setHeight(h))createMutationEffect( () => height(), (h) => spacer.style.height = h // write DOM)
04 · forced reflow
Must read after a write?
Say so.
A forced reflow is an explicit measurement slot after mutate, with its own write slot after it. One extra layout, on purpose, still before paint. Rare by design.
requestMutation(() => { list.prepend(...older) // write requestForcedReflow(() => { const top = anchor.offsetTop // read, mid-frame return () => list.scrollTop += top // write after })})
05 · heavy-animation gating
Animation first.
Updates land after.
While a blocking animation runs, frame work is held back — whole frames, never half. When it ends, everything lands in one pass.
beginHeavyAnimation() // panel slides in, 50 mssetMessages(next) // store keeps flowing…setScrollTop(y)setDraft(text)endHeavyAnimation() // …and commits here
06 · stricterdom
Break a phase,
get named.
In dev, the DOM API itself is guarded. A write during measure is caught at the call site and attributed to the effect that did it.
createMeasureEffect( () => el.getBoundingClientRect(), (r) => el.style.width = r.width + 'px' // ← write in measure)
Fine-grained signals. One commit per frame.
